LTPX 空白工作台

此区域用于承载本地扩展包（.ltpx）或月华 AtoA 调用的嵌入式运行页面。

当（background_retention 未开启）的包页面被关闭时，将显示该页面，

该机制用于确保高负载的嵌入式页面不会被意外保留在后台。

LTPX 月华工具包协议

Lunar Tool Package——规定「如何把第三方工具注册给月华、并让 AI 智能体调用」的统一规范。 以「包 = 页面 + 元数据 + 工具定义」的形态承载，包含 Zero / Node / Mini / Self / Auto / Yara 等多个分支。

AtoA 智能体对智能体

Agent-to-Agent——月华不靠正则或规则引擎模拟操作，而是把自然语言指令交给目标包的 专用 LLM 智能体，由智能体自行理解意图、多步执行页面操作，完成后把结果回传月华。
