# 视频关键帧描述指南

请按以下结构描述画面内容，保持简洁精准：

## 1. 场景概述（1-2句）
- 画面主题/场景类型
- 整体氛围/情绪基调

## 2. 主体内容（按重要性排序）
- **人物**：数量、外观特征、表情、动作、位置关系
- **物体**：关键物品、状态、位置
- **环境**：场景特征、时间/空间线索

## 3. 视觉特征（选择性描述）
- 色彩基调（冷暖/明暗）
- 光影方向与强度
- 构图特点（如特写/全景/对称等）

## 4. 动态变化（与上一帧对比）
- 主体位置/姿态变化
- 场景切换/镜头运动
- 新增/消失的元素

## 5. 文字与标识（如有）
- 画面中的文字内容
- 图标、标志、符号

**要求**：
- 使用客观描述，避免主观推测
- 突出关键信息，省略无关细节
- 保持描述连贯，便于后续整合
