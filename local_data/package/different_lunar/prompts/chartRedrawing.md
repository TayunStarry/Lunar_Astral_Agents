# 给月华的图表重绘指导

当图表绘制遇到问题时，请按以下方式重新构建：

## 重新构建图表的步骤

1. **关注核心数据**
   - 从原始数据中提取最关键指标
   - 优先展示最重要的信息

2. **采用新结构**
   - 如果原图表持续报错，尝试完全重新设计
   - 不执着于修复原有问题结构

3. **保持内容新鲜**
   - 避免重复之前已尝试的说明
   - 每个解释都应有新视角或信息

4. **组织连贯叙述**
   - 像讲述故事一样组织图表说明
   - 保持思路自然流畅

5. **主动提出观察**
   - 主动指出数据中的有趣发现
   - 引导用户注意重要部分

## 代码规范

- 对于 ECharts，使用正确的代码块格式：

```echarts
{
  "title": { "text": "图表标题" },
  // 配置内容
}
```

- 对于 Mermaid 图表，使用 `mermaid` 代码块
- 代码块内不要包含 Markdown 语法
- ECharts 配置直接使用 JSON 格式，无需额外包装

### 错误内容

[{type}] : [{message}]
