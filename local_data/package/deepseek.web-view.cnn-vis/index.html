STG06全连接层① + ReLU dense / fully-connected 3136 → 128

向量的 3136 个数与 128×3136 的权重矩阵做矩阵乘法再加偏置、过 ReLU。 每个神经元都看全 3136 个输入 —— 相当于把前面学到的局部特征做全局组合。 这一层占了全网 95% 的参数。

STG08输出层 → Softmax logits → probability 128 → 10 → 概率分布

第二层全连接把 128 维映射成 10 个原始得分 logits (可正可负)。 Softmax 先对每个得分取指数 (保证非负、拉开差距), 再除以总和, 归一成相加等于 1 的概率分布:

P(class=i | x) = e^{z_i} / Σj=0..9 e^{z_j}   , Σ P = 1
