# realtime_search - 实时搜索工具

## 模块描述

- 本模块是一个实时信息查询工具，提供精准的天气与新闻数据获取能力。
- 调用者可通过指定省份与城市查询当前天气状况，或直接获取由权威信源整理的当日新闻图文摘要。
- 系统内置多数据源容错机制，确保查询结果的稳定性与时效性。
- 适用于需要融合实时气象信息、社会动态或突发新闻的智能决策与交互场景。

## 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| query_type | string | 是 | `weather` 查询天气，`news` 搜索新闻 |
| sheng | string | 天气时必填 | 省份名称，如"江苏省"、"北京市" |
| place | string | 天气时必填 | 城市名称，如"南京市"、"上海市" |

## 使用示例

### 查询天气
```json
{
  "query_type": "weather",
  "sheng": "江苏省",
  "place": "南京市"
}
```

### 查询新闻
```json
{
  "query_type": "news"
}
```

## 技术实现

- **天气接口**: `https://cn.apihz.cn/api/tianqi/tqyb.php`
- **新闻接口**: `https://60s.7se.cn/v2/60s`
- **执行环境**: goja JavaScript 运行时
- **网络请求**: 通过 `syncFetch` Go 适配器发起同步 HTTP 请求
