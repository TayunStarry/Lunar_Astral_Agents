ASCII FPV  楼宇穿越

全部画面由彩色 ASCII 字符排列而成 · 非真 3D 渲染

W / S 减小 / 增加俯仰角（±45° 限幅）
A / D 滚转角速率控制（±45° 限幅）
方向键 视角偏移（水平转头 / 俯仰视角，不影响飞行）
Z / X 加速 / 减速（10 ~ 50 m/s）
R 坠机后重生
[ ] 字符密度（分辨率）
H / C / P HUD 开关 / 碰撞开关 / 暂停
Y 角度限制切换（有限 ±45° ⇄ 无限·可回环）
L 自动回正开关（松手回平 / 纯 acro 保持）
E 一键回正（按一下自动回平到水平）
- + 灵敏度调节（0.5 ~ 2.5）
— — Xbox 手柄 — —
左摇杆 姿态（有限）/ 速率（无限）——推多少动多少
右摇杆 视角偏移（水平转头 / 俯仰视角，不影响飞行）
RT / LT 线性油门：越深越快 / 越深越慢
A B X 重生 / HUD / 碰撞
菜单键 暂停（正面右上角，三条横线图标）
Y 角度限制切换（有限 ±45° ⇄ 无限·可回环）
Back 自动回正开关（正面左上角，两个方块图标）
左摇杆按下 一键回正（按一下自动回平到水平）
十字键上下 灵敏度调节（0.5 ~ 2.5）
LB RB · 十字键左右 字符密度
滚转 45° 时偏航角速度线性到达 90°/s，构成协调转弯。
灰蓝色 # 为楼房（琥珀色为亮着的窗户），绿色 & 为树木，灰色 = 与黄色虚线为道路，天空为黑底。
