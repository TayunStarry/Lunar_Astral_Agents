# 星月智能（Lunar Astral Agents）

> 纯本地化的桌面 AI 智能体平台，AI 推理全部在本机完成，零 Python 依赖。

---

## 一、功能介绍

**星月智能**是一个运行在 Windows 桌面上的本地 AI 智能体平台，模型推理与数据处理全部在本机完成，无需云端服务。平台由两位人格智能体驱动：

- **月华** —「月亮的光华」，AI 桌面智能体核心，掌管多模态对话、语音表达、图像生成与前端交互。
- **琉璃** —「如水晶般澄澈」，工具集扩展系统，掌管文件管理、知识库/记忆库、截图标注与扩展包运行。

月华以温柔智慧照亮对话空间，琉璃以澄澈纯粹夯实工具基石；二者可互相调用，让用户在同一个平台内完成对话、检索、整理与二次创作。由于模型、知识与记忆都保存在本地，平台适合重视隐私、需要离线使用，或希望长期沉淀个人知识的用户。

## 二、使用方法

1. **准备运行环境**：使用 64 位 Windows 10 21H2 及以上系统，确认已安装 WebView2 Runtime（Windows 11 通常自带）；如需更快的推理速度或语音、图像能力，可另行安装 NVIDIA CUDA 运行库、FFmpeg 与 Vulkan 运行时（均为可选）。
2. **获取程序**：下载发行版本（含主程序与运行所需目录），或按构建说明自行构建得到主程序。
3. **启动程序**：运行主程序，控制台以全屏方式显示系统界面，并自动打开月华与琉璃两个前端窗口。
4. **开始对话**：在月华窗口输入文字即可对话；可上传图片或视频、开启语音朗读、生成图像、发起网络搜索。
5. **扩展使用**：在琉璃面板使用文件管理、知识库、记忆库与截图功能，或安装扩展包为月华增加新的工具能力。
6. **退出程序**：在控制台内选「退出程序」（快捷键 `b`）或按 `Ctrl+C`，系统会依次关闭各子系统。

构建与详细运行方式见 [10 运行配置与安全](local_data/references/10-运行配置与安全.md)。

## 三、功能特性

| 特性 | 说明 |
|------|------|
| 多模态对话 | 支持文字、图片、音视频等多种输入形式的对话交互 |
| 语音合成 | 将回复合成为自然语音，支持音色、语速等效果调整 |
| 图像生成 | 依据文字描述生成图像，可调节尺寸、步数与显存策略 |
| 富文本渲染 | 对话中的 Markdown、图表、公式与代码可结构化呈现 |
| 网络搜索 | 通过内置检索智能体获取网络信息并汇总摘要 |
| QQ 群聊适配 | 可将月华接入 QQ 群聊，按配置响应群消息 |
| 知识库 / 记忆库 | 在本地沉淀知识与对话记忆，支持检索与复用 |
| 统一资源句柄 | 文本 / 图片 / 动图 / 音频 / 链接共用一套编号，可长期引用 |
| 全屏控制台 | 将日志、运行状态与运维功能收敛到单一终端界面 |
| 纯本地推理 | 模型推理在本机完成，数据不出本机 |
| 零 Python 依赖 | 全平台以 Go 与 C/C++ 实现，运行时无需 Python 环境 |

## 四、运行参数

平台核心运行参数（端口与启动开关）如下；模型、图像、语音、搜索等各类参数统一见 [10 运行配置与安全](local_data/references/10-运行配置与安全.md)，引擎参数见附录 A / 附录 B。

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| 基础端口（启动开关 `-basic-port`） | 平台基础端口：月华消息终端与琉璃桌面（`/desktop/`）共用同一端口 | 36789 | 仅在被占用时修改 |
| 模型端口（`-model-port`） | 模型服务端口（llama-server，含语音识别预设） | 基础端口 + 1（36790） | 通常无需修改 |
| 代理端口（`-proxy-port`） | 代理监听端口 | 基础端口 + 5（36794） | 通常无需修改 |
| 启动开关 `-developer` | 开发模式，日志不限流 | 关闭 | 仅排障时开启 |

运行前置条件（运行参数相关）：

| 项目 | 要求 | 说明 |
|------|------|------|
| 操作系统 | Windows 10 21H2+ / Windows 11，x64 | 仅支持 64 位 Windows，不支持 32 位、Linux 与 macOS |
| WebView2 Runtime | ≥ 109.0 | 桌面嵌入式浏览器，Windows 11 已预装 |
| CUDA Toolkit | 12.x / 13.x | GPU 加速推理（可选） |
| FFmpeg | ≥ 5.0 | 音视频格式转换（可选） |
| Vulkan SDK | ≥ 1.3 | GPU 推理加速（可选） |

## 五、常见排故

| 现象 | 可能原因 | 处理办法 |
|------|----------|----------|
| 程序无法启动或闪退 | 运行环境不完整、模型文件缺失，或被安全软件拦截 | 核对运行环境是否齐全，确认模型文件完整，放行程序后重试 |
| 提示找不到模型 | 模型未放入指定目录，或配置中的模型路径有误 | 按 [10 运行配置与安全](local_data/references/10-运行配置与安全.md) 检查模型路径与预设 |
| 窗口空白或无法打开 | 未安装 WebView2 Runtime | 安装 WebView2 Runtime 后重新启动程序 |
| 端口被占用 | 默认端口已被其它程序占用 | 使用启动开关 `-basic-port` 更换基础端口，或关闭占用端口的程序 |
| 首次启动很慢 | 首次启动需加载并初始化模型 | 等待初始化完成；后续启动会明显加快 |

跨篇问题可在 [系统阅读指南](local_data/references/README.md) 的能力地图中按主题定位。
