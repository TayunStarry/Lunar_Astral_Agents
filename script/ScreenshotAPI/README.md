# ScreenshotAPI 模块功能概述

## 功能概述

ScreenshotAPI 模块负责屏幕捕获和截图编辑功能，包括屏幕捕获核心功能、多种绘图工具支持、颜色和线条粗细调整、历史记录管理和截图保存等功能。

## 主要功能

### 1. 屏幕捕获核心功能

- 支持选择屏幕或窗口进行捕获
- 支持开始/停止捕获
- 支持将捕获的视频帧绘制到画布

### 2. 多种绘图工具支持

- 矩形工具
- 画笔工具
- 直线工具
- 圆形工具
- 文本工具
- 箭头工具

### 3. 颜色和线条粗细调整

- 支持多种颜色选择
- 支持线条粗细调整
- 支持实时预览

### 4. 历史记录管理

- 支持撤销操作
- 支持历史记录的保存和恢复
- 支持清空历史记录

### 5. 截图编辑和标注

- 支持在截图上进行各种编辑
- 支持添加文本和图形
- 支持调整线条颜色和粗细

### 6. 截图保存和下载

- 支持将截图保存到服务器
- 支持批量处理
- 支持生成带时间戳的文件名

### 7. 共享视觉内容

- 支持将截图与文本消息结合发送
- 支持创建共享视觉
- 支持与其他模块集成

### 8. 自适应画布大小调整

- 支持画布大小调整
- 支持窗口大小变化时重新调整画布
- 支持不同屏幕尺寸的适配

### 9. 工具选择和状态管理

- 支持工具的选择和切换
- 支持工具状态的管理
- 支持工具的初始化和配置

## 核心类

### `ToolSelector` 类

工具选择器类，用于管理绘图工具的选择和状态。

### `HistoryManager` 类

历史记录管理类，用于管理绘图操作的历史记录，支持撤销操作。

### `ScreenshotCore` 类

屏幕捕获核心功能类，负责屏幕捕获、截图保存和下载等功能。

### `DrawingTools` 类

绘图工具功能类，负责各种绘图工具的实现和管理。

## 核心函数

### `screenshotCore.startCapture()`

开始捕获屏幕，请求用户选择屏幕或窗口，将媒体流绑定到video元素。

### `screenshotCore.captureScreen()`

捕获当前视频帧并切换到编辑模式，将视频流中的当前帧绘制到主画布，停止媒体流。

### `screenshotCore.downloadImage()`

下载合并后的截图，将主画布与绘图画布叠加后生成PNG文件并上传至服务器。

### `drawingTools.startDrawing(event)`

开始绘制，记录当前鼠标位置。

### `drawingTools.draw(event)`

绘制中，根据当前工具类型和鼠标位置绘制图形。

### `drawingTools.stopDrawing(event)`

结束绘制，完成图形绘制并保存到画布。

### `createSimpleVisual()`

创建共享视觉内容，从输入框获取内容，将截图与文本消息结合发送。
