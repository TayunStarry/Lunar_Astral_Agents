🌙 Lunar Astral Agents (月华)

版本 4.0.0 MIT 许可证 Go 语言

月华 是一个本地智能 AI 少女助理系统，基于 Go 语言开发，提供完整的 AI 对话、图像生成、语音合成等功能。该项目采用模块化架构设计，集成了 llama.cpp 推理引擎、Live2D 虚拟角色显示以及多种 AI 模型服务。

🏗️ 技术架构

✨ 功能特性

1. AI 对话系统

  • 多模型支持: 支持嵌入模型、多模态视觉模型、扩散模型等多种 GGUF 格式模型
  • 实时响应: 基于 WebSocket 的实时消息推送
  • 上下文管理: 支持聊天历史记录和上下文窗口管理
  • OpenAI 兼容 API: 提供与 OpenAI API 兼容的接口格式

2. 图像生成

  • 扩散模型生成: 支持基于 stable-diffusion.cpp 的图像生成
  • 图生图模式: 支持以现有图像为基础生成新图像
  • 任务队列系统: 异步任务处理，支持多任务排队
  • 负面提示词: 支持负面提示词以优化生成效果

3. TTS 语音合成

  • Qwen3-TTS 集成: 支持 Qwen3 系列语音合成模型
  • 代理转发: 提供 TTS 请求代理服务

4. QQ 集成 (bridge_adapter)

  • NapCat WebSocket 连接: 与 QQ NapCat 服务集成
  • 群组消息监听: 支持指定群组的触发词监听
  • 消息双向转发: 实现 QQ 与月华系统的消息互通

5. Live2D 虚拟角色

  • 实时渲染: 使用 Pixi.js 和 Live2D Cubism 4 渲染
  • 表情动作: 支持多种表情和动作切换
  • 桌面级渲染: 高性能 WebGL 渲染管线

📦 安装步骤

  1. 克隆项目: git clone <repository_url>
  2. 安装依赖: cd LunarCore && go mod download && npm install
  3. 准备模型文件: 将 GGUF 模型文件放置在 local_data/models/ 目录下
  4. 构建项目: cd LunarCore && go build -o Lunar-Astral-Agents.exe .
  5. 运行服务: ./Lunar-Astral-Agents.exe

Base URL: http://localhost:{port} (默认端口 36789)  |  数据格式: JSON  |  字符编码: UTF-8

🚀 性能优化建议

  1. GPU 加速: 确保 NVIDIA GPU 驱动和 CUDA 已正确安装
  2. 显存管理: 合理设置 --n-gpu-layers 参数，建议为模型总层数的 2/3
  3. 上下文长度: 根据可用显存调整 ctx-size 参数，8192 是性能与效果的平衡点
  4. 队列限制: 系统默认最大队列长度为 3
  5. 分辨率选择: 较低分辨率 (512x512) 生成速度更快
  6. 采样步数: 20-30 步是效果与速度的平衡点

⚠️ 已知限制

功能限制: 仅支持 GGUF 格式模型 · 主要针对 Windows 平台优化 · TTS 需要独立 Qwen3-TTS 服务 · QQ 集成需要 NapCat 服务
性能限制: 默认单请求处理 · 多模型同时运行需约 12GB+ 显存 · 扩散生成队列容量有限

🛡️ 潜在风险

风险类型 风险描述 缓解措施
隐私风险 对话数据存储在本地 敏感场景使用本地部署
资源耗尽 恶意请求导致系统崩溃 添加请求限流和认证
模型安全 生成不当内容 添加内容过滤层
端口冲突 多实例运行导致端口冲突 使用 -clear-port 参数
内存泄漏 长时间运行内存持续增长 定期重启服务
