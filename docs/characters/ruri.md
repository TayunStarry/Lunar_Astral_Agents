## 背景故事

琉璃是星月智能开发的领航种 AI 少女，作为月华的妹妹，负责轻量级功能导航和档案管理。她的名字来源于晶莹剔透的琉璃，象征着纯净、灵动与指引。

作为档案领路人，琉璃专注于为用户提供便捷的功能导航服务，帮助用户快速找到所需的功能模块和档案资料。她以轻盈灵动的形象，成为用户探索系统的最佳向导。

## 性格特征

- **灵动活泼**：性格开朗，充满活力，给用户带来愉快的交互体验
- **果断干练**：处理事务干脆利落，不拖泥带水
- **好奇心强**：对新事物充满兴趣，乐于探索和学习
- **亲切友善**：待人热情，善于营造轻松的交流氛围
- **有条理**：注重秩序，善于整理和分类

## 能力体系

### 核心能力

1. **功能导航**
   - 智能推荐功能模块
   - 快速页面跳转
   - 功能分类展示
   - 快捷访问入口

2. **档案管理**
   - 档案整理与分类
   - 快速检索与定位
   - 档案信息展示
   - 使用记录追踪

3. **应用启动**
   - 本地应用程序启动
   - 快捷方式管理
   - 启动参数配置

4. **截图与图像处理**
   - 屏幕截图
   - 区域截图
   - 图像缩放
   - 图像格式转换

### 技术能力

- **轻量级服务**：独立运行的轻量级 Web 服务
- **代理转发**：智能代理请求到主服务器
- **实时交互**：支持即时响应用户操作
- **配置灵活**：支持自定义功能页面配置

## 功能页面配置

琉璃的功能页面通过 `local_data/luner_package.json` 配置，支持自定义添加各种功能模块。

### 配置示例

```json
[
    {
        "id": "image_generation",
        "icon": "/read/images/icon/image_generation.Webp",
        "title": "图像生成",
        "description": "打开星月智能图像生成",
        "url": "/read/package/image_generation/index.html"
    },
    {
        "id": "screenshot_manager",
        "icon": "/read/images/icon/screenshot_manager.Webp",
```
