## 一、功能介绍

琉璃（钛宇-琉璃）是星月智能平台面向用户的工具集扩展系统，负责把「让 AI 帮你操作电脑」这件事所需的工具集中到一处。它提供文件管理、知识库、记忆库、截图标注、网络检索等常用工具界面，并内置桌面智能体、网络搜索智能体、插件引擎，以及轻量的语音合成与语音识别能力；同时通过扩展包机制（LTPX 应用市场）让第三方或自建工具能被月华调用。琉璃与月华分工协作：月华负责思考与对话，琉璃负责执行与承载工具，需要调用 AI 时由琉璃把请求转发给月华后端。适用于文件整理、资料入库与检索、截图标注、扩展包安装与管理，以及把桌面操作、网络搜索等任务交给 AI 完成的场景。

## 二、使用方法

1. **打开琉璃面板**：启动星月智能主程序后，控制台会自动打开琉璃前端窗口（标题为「星月智能 - 琉璃」）；关闭窗口不退出程序，可在控制台重新打开。面板汇集文件管理、知识库、记忆库、截图、扩展包等入口。
2. **使用文件管理**：在文件界面浏览本地目录，可上传、下载、删除、移动、编辑、预览文件，并创建或解压 ZIP 归档。
3. **知识库操作**：在知识库界面执行查询与写入（数据存于本地 SQLite），用于沉淀可被 AI 检索的文本资料。
4. **记忆库操作**：在记忆库界面初始化实例、管理集合、增删查消息与文档，用于长期记忆的向量检索。
5. **截图标注**：选择显示器或区域截图，配合画板对截图进行标注，并可缩放图片、转换图片格式。
6. **配置编辑**：在配置界面按分组查看与修改运行参数（如 `web_search`、`release`），保存后按需重启生效。
7. **内置智能体与扩展包调用**：对月华下达自然语言指令，即可经工具路由调用内置桌面智能体（`window_operate`）、网络搜索智能体（`web_search`）或扩展包；也可在应用市场安装、导出、删除扩展包，或从 URL / ZIP / 本地文件创建新的扩展包模块。

## 三、功能特性

| 特性 | 说明 |
|------|------|
| 文件管理 | 本地文件浏览、上传、下载、删除、移动、编辑、预览，以及 ZIP 归档创建与解压 |
| 知识库 | 本地 SQLite 存储，支持查询与写入的文本知识库 |
| 记忆库 | 向量记忆库：实例初始化、集合管理、消息与文档的增删查与重建 |
| 截图标注 | 多显示器截图与区域截图，配合画板标注，并可缩放、转换图片格式、提取视频关键帧 |
| 内置 Auto-LTP | 桌面操作智能体（`window_operate`）：理解界面并代为操作桌面程序 |
| 内置 Web-LTP | 网络搜索智能体（`web_search`）：真实浏览器检索并汇编检索报告 |
| 内置 StarLTP / YaraLTP | 插件引擎（LTP9 / LTP3）：加载并运行扩展包内的插件 |
| 内置 Kokoro TTS | 本地语音合成引擎，支持多音色与发音字典 |
| 语音识别 | 接入月华 Qwen3-ASR 引擎，将语音转写为文字 |
| LTPX 应用市场 | 安装、导出、删除扩展包，并从 URL / ZIP / 本地创建扩展包模块 |
| 月华服务管理 | 检测月华服务状态并一键启动 |
| 其他工具 | 随机背景图、扩展程序加载器、外部模型 API 代理转发等 |

## 四、运行参数

琉璃参数位于 `local_data/lunar_config.json`。以下为常用项，完整参数总表见 [08 构建、运行与配置](08-构建运行与配置.md)。

**网络搜索智能体（`web_search`）**

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `web_search.save_screenshots` | 检索截图是否落盘保存 | `false` | 需要留档时改真 |
| `web_search.screenshot_dir` | 截图保存的相对目录 | `multimedia/captures` | 保持默认 |
| `web_search.max_pages` | 进入结果页逐页分析的页数上限（硬上限 10） | `3` | 3~5 之间按需调整 |
| `web_search.max_results` | 结果页解析的检索结果条数 | `15` | 保持默认 |
| `web_search.results_scroll_captures` | 搜索页滚动截图张数 | `3` | 保持默认 |
| `web_search.page_scroll_captures` | 每个结果页滚动截图张数上限 | `10` | 保持默认 |
| `web_search.summary_max_chars` | 单页摘要硬切断字符数（上限 4096） | `4096` | 保持默认 |
| `web_search.max_run_seconds` | 单次检索总时长软上限（秒），超时以已采集信息收尾 | `360` | 网络较慢时可适当调大 |

**发布通道（`release`）**

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `release.gitee_owner` / `release.gitee_repo` | Gitee 仓库归属与名称 | 出厂已填 | 发布自己的更新包/市场包时改为自己的仓库 |
| `release.gitee_token` | 发布令牌 | 空（发布时在控制台手动输入） | 不落盘，按需输入 |
| `release.backup_keep` | 更新保留的备份份数 | `3` | 保持默认 |
| `release.include` / `release.exclude_dirs_with` | 打包包含目录与排除规则 | 见示例 | 需要时调整 |
| `release.package_dir` | 扩展包目录 | `local_data/package` | 保持默认 |

**内置服务端口**

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| 服务端口（`-basic-port`） | 月华与琉璃共用同一服务端口；琉璃桌面挂载于该端口的 `/desktop/` 路径，无独立端口 | `36789` | 被占用时用启动参数 `-basic-port` 更换 |
| 模型服务端口（`-model-port`） | 琉璃的 AI 请求经月华后端（同源 `/v1`）转发到模型服务 | 基础端口 + 1（`36790`） | 保持默认 |

> 搜索智能体与扩展包运行细节见 [09 LTPX 协议 —— 月华工具包](09-LTPX协议-月华工具包.md)。

## 五、常见排故

| 现象 | 可能原因 | 处理办法 |
|------|----------|----------|
| 琉璃面板打不开 | 服务端口（默认 36789）被占用，或未安装 WebView2 | 用启动参数 `-basic-port` 更换服务端口后重启；确认已安装 WebView2 |
| 知识库无法查询 | 知识库实例未初始化，或查询内容有误 | 确认知识库已初始化，检查查询内容后重试 |
| 截图失败 | 目标窗口已最小化或受保护，或区域超出范围 | 避免最小化目标窗口，重新框选区域，或改用全屏／指定显示器截图 |
| 内置语音合成无输出 | 引擎未初始化，模型目录缺失 | 确认 Kokoro 模型目录存在，并查看初始化错误日志 |
| 语音识别异常 | 月华后端不可达，识别模型未就绪 | 确认月华服务正在运行，语音识别由其提供；必要时重启月华后重试 |
| 扩展包加载失败 | 包信息缺失、注入脚本未就绪，或执行中窗口被关闭 | 确认该包能正常打开，在扩展包界面重新加载，依据界面提示定位并重新安装 |
