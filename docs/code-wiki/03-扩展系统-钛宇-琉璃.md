# 03 扩展系统——钛宇-琉璃（crystal_astral）

> [🏠 文档地图](README.md) | [◀ 上一章](02-核心系统-钛宇-月华.md) | [下一章 ▶](04-公共子系统.md)

工具集扩展系统，提供文件管理 / 知识库 / 记忆库 / 截图标注 / AI 代理转发等下游工具界面，并内置 LTPX 扩展包运行时（页面智能体、桌面智能体、网络搜索智能体、LTP3/LTP9 插件引擎）。AI 请求经代理路由转发到月华后端（`localhost:36789`）。LTPX 协议与调用链路详见 [09·LTPX 协议](09-LTPX协议-月华工具包.md)。

## 2. 启动与路由

### 2.1 启动流程（main.go / create.go）

```
main.go
  └── 解析参数 → 固定端点(*GeneralConfig.EnginePort，默认 36792) → StartServer
        ├── 同步绑定端口（被占用 → 播放 cartoon-fail.mp3 并退出）
        ├── 初始化知识库/记忆库（实例 + 默认集合 lunar_messages）
        ├── 图像任务处理器 StartTaskProcessor
        ├── StudioHub 集线器 + /ws
        ├── YaraLTP.Init（LTP3 引擎装载与对账循环）
        ├── BridgeLTP9（LTP9 引擎装载与宿主通道注入）
        ├── 注册 SystemEndpoints + proxyAwareHandler
        └── 打开 WebView 窗口，等待信号或窗口关闭后优雅退出
```

### 2.2 代理感知路由（create.go / variable.go）

`proxyAwareHandler.ServeHTTP` 依据 `proxyPrefixes` 决定转发给反向代理（`getProxyHandler` → `http://localhost:36789`）还是本地静态文件服务。

**需代理的路径前缀**（`variable.go`）：`/v1/`、`/write/message`、`/write/videourl`、`/tts`、`/tts/stream`、`/generate`、`/voices`、`/dict`。

## 3. 关键模块

### 3.1 handler.go —— 代理转发与服务管理

| 函数 | 职责 |
|------|------|
| `getProxyHandler` | 配置反向代理，目标 `http://localhost:36789`（月华后端） |
| `yuehuaCheckHandler` | 检测 `127.0.0.1:36789` 是否可用（月华存活检测） |
| `yuehuaStartHandler` | 启动 `Lunar_Astral.exe`（拉起月华服务） |
| `loadApplicationHandler` | 启动外部 .exe / .ps1 / .bat |
| `chatProxyHandler` / `modelsProxyHandler` | OpenAI 格式对话/模型列表代理 |

### 3.2 module_create.go —— 模块创建与智能体脚本

- `POST /api/module/create`：从 URL、本地路径（exe/ps1/bat/lnk）或 ZIP 创建扩展包（`local_data/package/<名称>/`），可自动生成元数据并注入 Mini-LTP 智能体。
- `POST /api/module/inspect`：检查模块来源。
- 下发 `/mini-ltp-agent.js`、`/self-ltp-agent.js`、`/shared-input.js`（嵌入资源）。

### 3.3 ws.go —— WebSocket 集线器

- **StudioHub**：主循环处理客户端注册、注销与广播（引擎命令桥接核心）。
- **StudioEngineHandler**：`POST /write/engine` 将引擎命令广播给所有本地 WebSocket 客户端。
- 心跳参数：写等待 10s、Pong 等待 90s、Ping 周期 30s、单消息上限 10MB。

### 3.4 内置智能体引擎（agent/）

| 目录 | 工具名/标签 | 职责 |
|------|------------|------|
| `AutoLTP/` | `window_agent`（LTP8/Auto-LTP） | Windows 桌面操作智能体：多角色编排（提示词编纂者 → 软件启动者 → 执行循环：视觉理解者 + UIA 理解者 + 任务规划者 + 单操作执行者 + 进度书记者），每角色独立上下文与工具白名单；视觉 + UIA 双路理解界面、`Invoke/Value/SelectionItem` 直接操作、坐标/键鼠兜底；逐角色 trace 落盘 `local_data/logs/auto_ltp_trace.log`，截图归档 `local_data/images/moment`。入口 `Run(instruction)` |
| `WebLTP/` | `web_search`（Web-LTP） | 网络搜索智能体：月华自然语言指令 → 模型提炼检索词 → 真浏览器（`BrowserClient.WebViewSession` 顶层窗口，不受嵌入限制）完成必应搜索 → 结果页滚动截图 → 回到页顶 → 依次进入前 N（≤10，指令「前N个」可覆盖）个结果页逐页滚动截图（≤10 张/页）与 DOM 情报摘要（`body.innerText` + 首屏截图互印证，硬切断 ≤4096 字符）→ 回到搜索引擎页 → 汇编「月华打开了什么页面、看到了什么内容」口吻报告。业务完成自动关窗；窗口意外关闭以已采集信息收尾。配置在 `lunar_config.json` 的 `web_search` 字段（截图落盘/页数/截图张数/摘要长度/总时长，每次运行热读取）。入口 `Run(instruction)` |
| `StarLTP/` | LTP9 引擎 | 插件引擎（goja 沙箱，入口 `execute.js`，标签 `LTP9`）：全同步事件模型、`permissions.key` 权限强绑定、跨包调用与前端智能体调度。详见 [09 §7](09-LTPX协议-月华工具包.md) |
| `YaraLTP/` | `yara_ltp`（LTP3 引擎） | 插件引擎（goja 沙箱，入口 `index.js`，标签 `LTP3`）：hook/event/command 事件容器与 WS 总线分发。详见 [09 §6](09-LTPX协议-月华工具包.md) |

月华经 `/ltpx/call`（`tool=window_agent` / `tool=web_search` + `instruction`）调用内置智能体，路由于 [ltpx_remote.go](../../crystal_astral/ltpx_remote.go)；二者均以固有工具身份随 `/ltpx/tools` 聚合进 `use_the_program` 暴露。

### 3.5 内置语音引擎

- **kokoro_tts/**：纯 Go + ONNX Runtime 的 Kokoro-82M-v1.1-zh 合成引擎（模型目录 `{LocalDir}/models/Kokoro-82M-v1.1-zh`）。首请求惰性初始化，含中文 G2P 前端、变调连读、发音字典、多音色加权混合（`mix`）；初始化错误写入 `{LocalDir}/logs/kokoro_init_error.log`。
- **qwen_asr/**：与独立程序 `subsystem/qwen_asr` 同源的纯 C 引擎，经 cgo 链接内置 OpenBLAS 静态库，模型路径取 `*GeneralConfig.AsrModel`，以 `POST /asr` 暴露。

### 3.6 前端 assets/

原生 HTML/CSS/JavaScript 毛玻璃风格 UI（标题 `『星月智能 - 琉璃』`）。主要界面：扩展包网格视图、琉璃助手对话、模块创建（URL/ZIP）、分页配置编辑器、呼叫月华、LTPX 包执行覆盖层（iframe + 状态岛）、拖拽导入。AI 请求经同源 `/v1` 代理转发至月华。

页面智能体脚本：`mini_ltp_agent.js`（Mini-LTP 通用页面操作）、`self_ltp_agent.js`（Self-LTP 自主循环）、`shared_input.js`（共享 DOM/键鼠/截图原语，`window.SharedInput`）、`ltpx_welcome.html`（空闲欢迎页）。

| 方法 | 端点 | 说明 |

## 5. 运行与常见问题

### 5.1 编译与运行

```powershell
cd d:\Lunar_Astral_Agents\crystal_astral
.\build.ps1
```

编译产物：仓库根目录 `Crystal_Astral.exe`。运行：`.\Crystal_Astral.exe`。

琉璃使用**固定端点** `*GeneralConfig.EnginePort`（默认 `basic-port + 3` = 36792，可通过 `-engine-port` 覆盖），WebView 窗口 1500×1050。端口被占用时：`StartServer` 同步绑定失败并返回错误，主程序播放失败音效 `local_data/audios/cartoon-fail.mp3`（winmm MCI）后以退出码 1 关闭进程。编译需 CGO（内置 qwen_asr C 引擎 + OpenBLAS）。

### 5.2 常见问题

**琉璃和月华有什么区别？** 月华是 AI 智能体核心系统（角色对话、TTS、文生图），琉璃是工具集扩展系统（文件管理、知识库/记忆库、截图、图片处理、AI 代理、LTPX 包运行时）。琉璃的 AI 请求经代理转发到月华后端。

**端口固定且被占用怎么办？** 可先释放占用端口，或通过 `-engine-port <新端口>` 指定其它端口后重新启动。

**如何调用外部模型 API？** 使用 `/proxy/chat` 端点，传入 `base_url`、`api_key`、`model` 和 `messages` 即可转发到任意兼容 OpenAI 格式的 API 服务。
