# 星月智能 · 用户手册门户

> 本目录是星月智能的**用户手册**：面向使用者，只讲功能、操作、参数与排障，不含代码、实现细节与项目结构说明。每篇文档统一按「功能介绍 / 使用方法 / 功能特性 / 运行参数 / 常见排故 / 引用跳转」六个模块组织。

---

## 一、功能介绍

星月智能（Lunar Astral Agents）是一个纯本地化的桌面 AI 智能体平台，AI 推理全部在本机完成，零 Python 依赖。平台由两位人格智能体驱动：月华负责多模态对话、语音表达与前端交互；琉璃负责文件管理、知识库与记忆库、截图标注与扩展包运行。本手册按使用主题分篇，帮助用户快速上手，并完成日常操作、参数调整与故障排查。

本手册覆盖：平台总览、月华、琉璃、基础功能与服务、引擎与运维工具、前端资源与扩展包、LTPX 工具包、安装运行与配置、文本推理参数、图像生成参数与调优、控制台、图片标签与多模态窗口。

## 四、运行参数

平台核心运行参数（端口与启动开关）速查，完整参数与配置分组见 [08 安装、运行与配置手册](08-构建运行与配置.md)：

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| 基础端口（启动开关 `-basic-port`） | 平台基础端口：月华消息终端与琉璃桌面（`/desktop/`）共用同一端口 | 36789 | 仅在被占用时修改 |
| 模型端口（`-model-port`） | 模型服务端口（llama-server，含语音识别预设） | 基础端口 + 1（36790） | 通常无需修改 |
| 代理端口（`-proxy-port`） | 代理监听端口 | 基础端口 + 5（36794） | 通常无需修改 |
| 启动开关 `-developer` | 开发模式，日志不限流 | 关闭 | 仅排障时开启 |
