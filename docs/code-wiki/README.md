## 一、这是什么

星月智能（Lunar Astral Agents）是一个运行在 Windows 桌面的**纯本地 AI 智能体平台**：模型推理、记忆存储与工具执行都在本机完成，不需要云端账号，也不依赖 Python 环境。

平台由两位人格智能体驱动：

- **月华**：与你对话的智能体。能看文字、图片、视频，会画图、会唱歌、会自己刷视频与做创作，也管着长期记忆。
- **琉璃**：工具与承载层。负责桌面面板、文件、知识库、记忆库、截图与扩展包。

两者共用同一个服务端口，可以同时打开；你用自然语言提要求，由月华判断该自己处理还是交给专项智能体或扩展包。

## 四、功能一览

| 能力 | 说明 |
|------|------|
| 多模态对话 | 文字、图片、动图、视频混合输入，先理解再回应 |
| 语音表达 | 三种本地语音引擎，支持参考音频克隆音色 |
| 图像生成 | 文生图、图生图、角色立绘、合照，可 4 倍超分 |
| 联网检索 | 真实浏览器检索并汇总成带来源的报告 |
| 长期记忆 | 三类记忆（文本 / 图像 / 音频）自动归组、语义检索 |
| 自主学习式生活 | 空闲时自己看视频、逛论坛、做创作、整理记忆 |
| 统一句柄 | 六类资料共用 `@类型码.序号`，可锚定章节或行区间 |
| 扩展包 | 安装即用的工具页，声明工具后可被 AI 调用 |
| 本地执行 | 文件、压缩包、截图、脚本都在本机完成 |
| 全屏控制台 | 日志、实况、运维、更新与退出集中在一处 |
| 纯本地推理 | 数据不出本机，默认只监听回环地址 |
