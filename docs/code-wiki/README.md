# 星月智能 · 系统阅读指南

> 这套文档写给第一次接触项目的人。它不按代码目录组织，也不做源码导览，而是按「先知道能做什么，再理解每件事怎么发生」的顺序展开：每个能力都讲清解决什么问题、什么时候触发、有哪些角色参与、数据怎么流动、失败会怎样。
>
> 建议按顺序读；已经带着问题来的读者，可以直接从下面的能力地图跳进去。

---

## 三句话理解这个系统

1. **它是一个跑在本机的 AI 智能体平台。** 模型推理、记忆存储、文件与媒体处理都在本机完成，默认只监听回环地址，不依赖云端账号。
2. **它有两个面向。** 「月华」是有人格、有情绪、有生活、有长期记忆的对话主体；「琉璃」是工具与承载人格，负责桌面、文件、资源库、扩展包与执行。
3. **能力不是孤立按钮。** 一次对话可能调用搜索、观影、绘画、文件操作或扩展包；这些能力产出的资料、作品和经历，又会进入资源体系与记忆，反过来影响下一次对话和生活。

## 术语表

- **智能体**：一次模型推理的独立执行者，有稳定的 ID、角色名、提示词、工具目录与失败归属。全系统共 30 个。
- **链**：负责「什么时候、按什么顺序、调哪个智能体」的流程编排层，不自己拼模型请求。
- **心愿**：月华自己记下的待办意图，带优先级与可选截止时间；结算结果会反馈到心情，但不保存长期完成历史。
- **Tick**：常驻调度节拍。对话、后勤、外部应答、创作、演绎、生活都注册在同一个调度器上，同一时刻只推进一条链的一个原子步骤。
- **句柄**：资料的统一编号，形式为 `@类型码.序号`，可进一步锚定章节或行区间。
- **资源中枢**：让智能体按类型、关键词或记忆语义检索已有资料的统一入口。
- **扩展包**：放在资源库里的独立页面与工具声明，安装后可被月华按需调用。

## 文档约定

- 每篇开头有「读这一篇能回答什么」，长文有本篇导航，文末有「继续阅读」，保证阅读路径连续。
- 交叉引用指向具体文件的具体标题，不使用「详见某模块」这类无法跳转的写法。
- 机制优先：只在一句话能定位实现时提代码位置，不贴大段代码、不逐函数解释。
- 旧版按模块编号的文档已被本套文档替换；已经删除的机制不会以「历史沿革」的形式保留。
