## 4.1 general_config —— 全局配置中枢

> 被所有 Go 模块引用。零外部依赖、纯数据提供者、并发安全。

### 工作原理：双层配置

1. **命令行参数（flag）** —— 第一优先级
2. **`lunar_config.json`** —— 第二层，按字段增量覆盖默认值；例外：`server.developer` 与 `server.allow_diffusion` 两个布尔值在配置文件存在时以文件值为准

### 关键文件与函数

| 文件 | 职责 |
|------|------|
| `init.go` | 核心实现：过滤测试参数 → `flag.Parse()` → 读取 JSON → 覆盖全局配置变量 |
| `allow.go` / `engine.go` / `image.go` | 功能开关 / 推理引擎路径 / 图像参数 |
| `model.go` / `path.go` / `port.go` | 模型服务 / 路径 / 端口配置 |
| `system.go` / `webview.go` | 系统运行时状态与 WebView 窗口参数 |

#### 端口体系（port.go）

端口以 `BasicPort`（默认 36789）为锚点，构建递增范围体系：

| 变量 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `BasicPort` | `*int` | `36789` | 基础 HTTP 服务端口（锚点） |
| `ModelPort` | `*int` | `BasicPort+1` = `36790` | llama.cpp 模型服务端口 |
| `EnginePort` | `*int` | `BasicPort+3` = `36792` | 引擎服务端口（琉璃固定端点） |
| `ProxyPort` | `*int` | `BasicPort+5` = `36794` | 代理转发端口 |

- `ModelPortMap`（`map[string]int`）运行时动态维护 `模型名 → 端口号` 映射，由 `ModelMapMutex`（`sync.RWMutex`）保护。

#### 路径配置（path.go）

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `LocalDir` | `local_data` | 本地数据根目录 |
| `KnowledgeDBPath` | `{LocalDir}/database/knowledge.db` | SQLite 知识库文件 |
| `MemoryDBDir` | `{LocalDir}/database/memory` | 向量记忆库目录 |
| `CertFile` / `KeyFile` | `{LocalDir}/certs/localhost(-key).pem` | HTTPS 代理 TLS 证书路径 |

#### 模型配置矩阵（model.go）

模型配置分为**三类角色**（`agent` 核心智能体 / `memory` 记忆库 / `search` 智能搜索），每类各含嵌入与多模态两组服务，每组由 `Model`（模型名）+ `URL`（API 地址）+ `Key`（密钥）组成：

| 角色 | 嵌入服务 | 多模态服务 |
|------|---------|-----------|
| 核心智能体 | `AgentEmbeddingModel/URL/Key` | `AgentMultimodalModel/URL/Key` |
| 记忆库 | `MemoryEmbeddingModel/URL/Key` | `MemoryMultimodalModel/URL/Key` |
| 智能搜索 | `SearchEmbeddingModel/URL/Key` | `SearchMultimodalModel/URL/Key` |

默认模型名为 `system-embedding`（嵌入）与 `system-multimodal`（多模态），默认 API 地址为 `http://127.0.0.1:36789/v1`（同源 v1 端点），默认 `Key` 为空串。

#### 运行与使用方式

- 指定基础端口启动：`.\Lunar_Astral.exe -basic-port 36800`
- 开发模式（不限流日志）：`.\Lunar_Astral.exe -developer`
- 禁用扩散图像生成：`.\Lunar_Astral.exe -allow-diffusion=false`
- 配置文件 `lunar_config.json` 放置在 `{LocalDir}/` 下（默认可执行文件同目录的 `local_data/`）

#### 常见问题

- **lunar_config.json 放在哪里？** `{LocalDir}/` 目录下，默认 `<exe所在目录>/local_data/lunar_config.json`。
- **配置修改后需要重新编译吗？** 不需要。`lunar_config.json` 在每次启动时重新读取，命令行参数同样无需重新编译。

## 4.2 browser_client —— WebView 窗口 + 会话管理 + IP 发现

### 职责

桌面 WebView 嵌入式窗口管理、**后端可驱动的多实例 WebView 会话**、系统浏览器回退、本地 IP 自动发现、单例管理。

### 关键文件与函数

| 文件 | 职责 |
|------|------|
| `webView.go` | `StartWebViewBrowser(url, initJS)`：锁定 OS 线程 → 等待清理 → 创建单例 WebView → 应用窗口样式 → 注入初始化 JS → 等待后端服务就绪 → 导航 URL → 运行事件循环 → 清理资源 |
| `session.go` | `WebViewSession` 多实例会话管理器：`OpenWebViewSession / Navigate / EvalJSON / WaitReady / Close`。Eval 结果经 `Bind("__lunarReport")` 回调回传（UI 线程 → 缓冲通道 → 调用方），跨线程操作经 `Dispatch` 投递；会话注册表支持按 ID 查找与「最近会话」复用，用户关窗自动注销 |
| `session_windows.go` | `WindowRect()`：user32 `GetWindowRect` 获取会话窗口物理像素矩形（供区域截图） |
| `session_capture_windows.go` | `ClientScreenshot()`：`PrintWindow(PW_CLIENTONLY\|PW_RENDERFULLCONTENT)` 截取窗口客户区内容（BGRA→RGBA），**与窗口遮挡状态无关**（最小化除外） |
| `session_other.go` | 非 Windows 平台的桩实现 |
| `execute.go` | `OpenBrowser` / `OpenSystemBrowser` / `OpenBrowserWithReturnButton` / `GetLocalIP` |
| `windowstyle_windows.go` | Windows 窗口图标与标题栏样式（user32 / dwmapi） |

#### 启动决策树

```
OpenBrowser(url)
    │
    ├── IsWebViewSupported() == true
    │   └── go StartWebViewBrowser(url, "")   ← 嵌入式 WebView
    │       ├── runtime.LockOSThread()        ← GUI 线程绑定
    │       ├── createWebView()               ← 单例创建
    │       ├── waitForServer(url)            ← TCP 轮询等待后端就绪
    │       └── w.Run()                       ← 阻塞事件循环
    │
    └── IsWebViewSupported() == false
        └── OpenSystemBrowser(url)            ← 系统浏览器
```

WebView 采用**单例模式**：`webviewMutex`（`sync.Mutex`）保护共享状态（单例实例、防重入标记、关闭通道、清理完成信号）；`CloseWebView()` 可从任意 goroutine 安全调用。`OpenBrowserWithReturnButton(url, mainURL)` 额外注入一枚悬浮「返回主页」按钮（琉璃窗口内嵌月华页面时使用）。

#### WebView 会话（多实例模型）

与单例窗口不同，`WebViewSession` 面向「后端程序化驱动」场景（Web-LTP 网络搜索智能体、`/webview/*` 端点、前端扩展包深读联动）：

- 每会话独立 OS 线程（`LockOSThread`）+ 独立 webview 实例 + 独立事件循环；会话注册表按 ID 索引，`LatestWebViewSession()` 返回最近创建的存活会话；
- `EvalJSON(script, timeout)`：脚本经 `(function(){ … })()` 包装后 `Dispatch` 到会话 UI 线程 `Eval` 执行，返回值 `JSON.stringify` 后经绑定回调回传；`WaitReady(prevURL, timeout)` 轮询 `readyState` 并识别导航提交（URL 变化或进入 loading）；
- 用户关闭窗口 → `Run()` 返回 → 自动 `Destroy` 并从注册表注销；意外关闭可通过 `IsAlive()` / `ClosedCh()` 感知。

#### IP 发现优先级

`GetLocalIP(preferredNetworks []string)` 遍历所有网络接口并分级选择最佳局域网 IP：

| 优先级 | 匹配网段 | 说明 |
|--------|---------|------|
| 最高 | 用户指定网段 | `preferredNetworks` 参数指定 |
| 次优 | `192.168.x.x` | 常见家庭/企业网段 |
| 第三 | `10.x.x.x` | 私网 A 类 |
| 第四 | `172.16–31.x.x` | 私网 B 类 |
| 第五 | `169.254.x.x` | 链路本地 |
| 最低 | 其他公网地址 | — |

过滤规则：跳过虚拟接口（vEthernet、Hyper-V、Docker、VirtualBox、VPN 等）、未启用接口与环回接口；找到最高优先级 IP 立即返回。

#### 导出函数表

| 函数 | 说明 |
|------|------|
| `OpenBrowser(url string)` | 入口函数：优先 WebView，回退系统浏览器 |
| `OpenBrowserWithReturnButton(url, mainURL string)` | WebView 启动并注入返回主页按钮 |
| `OpenSystemBrowser(url string)` | 跨平台系统浏览器启动 |
| `StartWebViewBrowser(url, initJS string)` | WebView 启动（需在专用 goroutine 中调用） |
| `CloseWebView()` | 安全关闭 WebView 窗口 |
| `WebViewClosed() chan struct{}` | 返回关闭通知通道（用于等待窗口关闭） |
| `IsWebViewSupported() bool` | 检查平台是否支持 WebView |
| `IsWebViewRunning() bool` | 检查 WebView 是否正在运行 |
| `GetLocalIP(preferredNetworks []string) (string, error)` | 获取最佳本地 IP |
| `OpenWebViewSession(url, title string, w, h int)` | 创建后端可驱动的 WebView 会话 |
| `GetWebViewSession / LatestWebViewSession / CloseWebViewSession` | 会话查找 / 最近复用 / 关闭 |

#### 运行与使用方式

`browser_client` 作为库被宿主程序（钛宇-月华、钛宇-琉璃、qwen_asr）调用，在需要展示前端页面时打开 WebView 窗口；`WebViewSession` 则被琉璃的 `/webview/*` 端点与 Web-LTP 智能体用于「真浏览器」检索与深读（见 [03 §4.11](03-扩展系统-钛宇-琉璃.md)、[09 §5.4](09-LTPX协议-月华工具包.md)）。

依赖：**WebView2 Runtime**（WebView 嵌入式窗口，Win10/11 通常已预装）；**系统默认浏览器**（WebView 不可用时回退目标）。

#### 常见问题

- **WebView 窗口无法启动怎么办？** ① 确认已安装 WebView2 Runtime；② 检查窗口尺寸配置是否合法；③ WebView 不可用时自动回退到系统浏览器。
- **如何修改 WebView 窗口样式？** 通过 `general_config` 的 WebView 参数（标题、尺寸、图标、标题栏色）调整，相对图标路径按「可执行文件所在目录 → 当前工作目录」顺序解析。

## 4.3 file_manager —— 文件 + 知识库/记忆库 + 扩展包

### 功能清单

#### SQLite 知识库（KnowledgeDB）

- 数据库文件：`{LocalDir}/database/knowledge.db`；连接参数：WAL 模式、`busy_timeout=10000ms`、连接池（10 最大 / 5 空闲 / 5 分钟生命周期）、`PRAGMA synchronous=NORMAL / cache_size=10000 / foreign_keys=ON`。
- **调用方式为原生 SQL 执行**：`POST /knowledge/`，请求体 `{"sql": "...", "params": [...], "db": "knowledge"}`，由 `module.ExecuteSQLOn` 直接执行。以 `SELECT` / `PRAGMA` / `EXPLAIN` / `WITH` 开头的语句按读处理，其余按写处理。
- **可选数据源 `db`**：空或 `knowledge` → 知识库 `knowledge.db`（默认）；`web_search_cache` → 网络搜索页面摘要缓存 `{LocalDir}/database/web_search_cache.db`（Web-LTP 的派生缓存，独立文件，懒加载连接，文件在首次网络搜索后由 Web-LTP 创建）。其他取值报错。
- 请求方（前端/插件）自行拼接 SQL 与参数；`params` 占位符传参避免注入。

```json
{
  "sql": "SELECT * FROM users WHERE name LIKE ? ORDER BY name LIMIT ?",
  "params": ["%li%", 10],
  "db": "web_search_cache"
}
```

#### 向量记忆库（MemoryDB）

- 存储目录 `{LocalDir}/database/memory/<集合名>/`：`metadata.json`（集合元数据）+ 分片 JSON（`documents_%04d.json` / `images_%04d.json` / `tags_%04d.json`）。
- 写入采用临时文件 + 原子重命名；启动后检测外部修改并自动重载；嵌入向量经 `general_config` 模型配置生成。

#### 文件安全机制

所有路径经 `filepath.Clean(filepath.Join(config.LocalDir, 请求路径))` + `strings.HasPrefix(完整路径, config.LocalDir)` 校验防路径遍历；文件名经 HTTP 头 `X-File-Name` Base64 传递，`DecodeFileName()` 解码后检查 `./`/`../`，不覆盖模式自动追加时间戳；并发文件锁用 `sync.Map` 存储每路径一个 `*sync.Mutex`。

#### 常见问题

- **知识库和记忆库有什么区别？** **知识库**（KnowledgeDB）是普通 SQLite 数据库，适合结构化数据的 SQL 增删改查；**记忆库**（MemoryDB）基于嵌入向量的语义记忆存储，适合自然语言消息的语义检索，支持图片记忆与集合管理。

## 4.6 lunar_decoder —— 月球编码（文件加密编解码器）

**中文译名：月球编码**。轻量级文件加密/编解码模块（包 `lunardecoder`，仅用标准库）。对文件二进制数据执行**密钥驱动的确定性可逆变换**，用于数据的加密混淆与还原。编码产物恒为 Base64 可打印字符集（`A-Z a-z 0-9 + / =`）内的文本，可安全存入 JSON / 文本传输场景。该变换亦作为 LTP3/LTP9 权限密钥的加密基元使用（见 [09](09-LTPX协议-月华工具包.md)）。

### 单轮加密管线

```
原始二进制
  → RLE 游程编码（控制字节 rleSeed 由 8 组操作派生）
  → 规范扩散（Feistel-CBC，16 字节块 × 8 子轮，IV/子密钥由轮密钥派生）
  → Base64(RFC 4648) 编码为文本
  → 8 组字符变换（ApplyTransform，0..7 正向）
  → 上下文窗口滑移（SlideRotate，环形滚动）
```

解码按严格逆序：反向滑移 → 逆字符变换（7..0）→ Base64 解码 → 逆向扩散 → RLE 解码。**多轮密钥**时后一轮以前一轮结果为输入，解码逆序逐轮还原。

### 密钥体系（key.go）

- **密钥字符集**为 65 字符 `asciiOrder`（`+/0123456789=ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz`）；空密钥或含字符集外字符（含多字节）返回 `ErrInvalidKey`。
- **按每 16 字符拆分为一轮**：超过 16 字符的密钥拆成多轮（每轮对前一轮结果重复加密）；不足 16 字符的轮用圆周率小数补齐（d 个字符从第 `(d-1)*20+1` 位起取，如 1 字符补前 15 位 `141592653589793`）。
- **每轮 16 字符拆 8 组**（每组一个控制位 + 一个执行次数位）：控制位取值 `v`（数字取数字值、符号取字符集编码号）得 `Op = v % 10`，`v/10` 叠加到次数位；执行次数位直接取字符集编码号并与整十倍数相加。
- `int16` 整数密钥取 16 位**无符号幅度**参与分组。

### 规范扩散层（diffuse.go）

对字节流做**密钥约束的 Feistel-CBC 扩散**，使单比特改动扩散到整段密文（雪崩）：

- 16 字节块 CBC 链：加密为「明文与前一块密文异或 → Feistel 正向 8 子轮」，解密为「Feistel 逆向 → 与前一块密文异或还原」。
- 子密钥 `feistelSubkeys`（8 组 × 8 字节）与 IV `feistelIV` 均由轮密钥的字符值异或种子派生；轮函数 `feistelF` 用 `*2654435761` 黄金比例乘法累加做非线性混合。
- **尾部处理**：不足一块的剩余字节与前一块密文派生的字节流异或（加密/解密对称）。
- 空输入返回空，不改变长度；相同密钥与数据产出稳定密文（确定性）。

### 字符变换与滑移

**8 组字符变换**（`transform.go`，作用于 Base64 字符集；`decode=true` 逆序执行逆操作）：

| 类型 | 目标范围 | 操作 |
|------|---------|------|
| 0/1 | 数字 0-9 | 向后/向前循环位移 |
| 2/3 | 字母 a-zA-Z | 向后/向前循环位移 |
| 4/5 | 符号 +、/、= | 向后/向前循环位移 |
| 6/7 | 全 65 字符 | 反向排序表转换（`reverseMap`，自逆）+ 循环位移 |
| 8/9 | 全 64 字符（不含 `=`） | 与下一位字符的字符集索引异或 + 循环位移 |

> 操作 8/9 的相邻异或作用于 64 字符 Base64 索引上（两个 6 位索引异或结果仍是 6 位），保证产物不越出字符集；填充 `=` 作为边界原样保留，末位不参与异或以保证严格可逆。

**上下文窗口滑移**（`slide.go`）：编码链路末阶段将密文环形滚动。方向按 8 组 `groupValue=Op*10+Count` 的奇偶统计判定——奇多于偶向前，否则向后；滑移次数按 65 基数解析轮密钥对密文长度取模（`SlideAmount`）。

### 公开 API

**类型与错误**

| 类型 | 说明 |
|------|------|
| `FileData` | `Name string` 文件名（原样保留）+ `Data []byte` 数据 |
| `Group` | `Op int`（0-9 操作类型）+ `Count int`（执行次数） |
| `Round` | `Key string`（对齐 16 字符轮密钥）+ `Groups [8]Group` |
| `ErrNilData` / `ErrInvalidKey` / `ErrInvalidBase64` / `ErrInvalidRLE` | 各类非法输入错误 |

**函数清单**

| 函数 | 说明 |
|------|------|
| `EncodeFiles(files []FileData, key int16)` / `DecodeFiles(...)` | 整数密钥编解码（多轮依次套叠/逆序还原） |
| `EncodeFilesWithKeyString` / `DecodeFilesWithKeyString` | 任意长度密钥字符串编解码（≤16 位自动圆周率补齐、>16 位拆多轮） |
| `KeyGroups(key int16)` / `KeyGroupsFromString(keyStr)` | 返回密钥**首轮**派生的 8 组操作 |
| `KeyRounds(key int16)` / `KeyRoundsFromString(keyStr)` | 返回全部加密轮 |
| `ApplyTransform(s []byte, groups [8]Group, decode bool) []byte` | 按 8 组操作变换字节串 |
| `SlideSpecFromGroups(groups [8]Group) SlideSpec` | 统计 8 组奇偶并确定滑移方向 |
| `SlideAmount(keyValue string, length int) int` | 以 65 基数解析密钥字符并取模，得到滑移次数 |
| `SlideRotate(s []byte, direction, amount)` | 环形滚转（双射）；`SlideNone`/`amount==0`/空串为恒等 |
| `ReverseDirection(direction SlideDirection) SlideDirection` | 返回相反滑移方向（解码用） |

### 使用方式

```go
import decoder "LunarSubsystem/LunarDecoder"

```

### 注意事项

- 模块定位为**加密混淆**：算法为自研可逆变换（密钥驱动 RLE + Feistel-CBC 扩散 + 字符变换 + 滑移），无密码学库依赖；用于本地数据保护与混淆场景，如需高强度加密请配合标准库 `crypto` 使用。
