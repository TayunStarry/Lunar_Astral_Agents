## 4.1 general_config —— 全局配置中枢

> 被所有 Go 模块引用。**零外部依赖、纯数据提供者、并发安全。**

### 工作原理：双层配置

1. **命令行参数（flag）** —— 最高优先级
2. **`lunar_config.json`** —— 第二层，按字段增量覆盖默认值

### 关键文件与函数

| 文件 | 职责 |
|------|------|
| `init.go` | 核心实现：过滤测试参数 → `flag.Parse()` → 读取 JSON → 覆盖全局配置变量（模型、agent/memory/search、server 开关等） |
| `allow.go` / `engine.go` / `image.go` | 各配置分组 |
| `model.go` / `path.go` / `port.go` | 模型 / 路径 / 端口配置 |
| `system.go` / `webview.go` | 系统与 WebView 配置 |

> `lunar_config.json` 示例结构：`models`（asr/diffusion/variational/prompt_analysis）、`server`（bridging_* 桥接）、`agent`/`memory`/`search`（各域 embedding/multimodal 模型分流）。

#### 端口体系（port.go）

端口以 `BasicPort`（默认 36789）为锚点，构建递增范围体系：

| 变量 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `BasicPort` | `*int` | `36789` | 基础 HTTP 服务端口（锚点） |
| `ModelPort` | `*int` | `36790` | llama.cpp 模型服务起始端口 |
| `ProxyPort` | `*int` | `36794` | 代理转发端口 |
| `MinPort` | `*int` | `36784` | 端口范围下界 |
| `MaxPort` | `*int` | `36804` | 端口范围上界 |

- `ModelPortMap`（`map[string]int`）运行时动态维护 `模型名 → 端口号` 映射，支持在该范围内同时运行多个模型服务实例，由 `ModelMapMutex`（`sync.RWMutex`）保护。

#### 模型配置矩阵（model.go）

模型配置分为**三类角色**（`agent` 核心智能体 / `memory` 记忆库 / `search` 智能搜索），每类各含嵌入与多模态两组服务，每组由 `Model`（模型名）+ `URL`（API 地址）+ `Key`（密钥）组成：

| 角色 | 嵌入服务 | 多模态服务 |
|------|---------|-----------|
| 核心智能体 | `AgentEmbeddingModel/URL/Key` | `AgentMultimodalModel/URL/Key` |
| 记忆库 | `MemoryEmbeddingModel/URL/Key` | `MemoryMultimodalModel/URL/Key` |
| 智能搜索 | `SearchEmbeddingModel/URL/Key` | `SearchMultimodalModel/URL/Key` |

默认模型名为 `system-embedding`（嵌入）与 `system-multimodal`（多模态），默认 API 地址为 `http://127.0.0.1:36789/v1`（同源 v1 端点），默认 `Key` 为空串 `""`。

#### 引擎级模型路径表（model.go/path.go）

默认指向 `{LocalDir}/models/` 下文件：

| 模型变量 | 默认值 |

## 4.2 browser_client —— WebView 窗口 + IP 发现

### 职责

桌面 WebView 嵌入式窗口管理、系统浏览器回退、本地 IP 自动发现、单例管理。

### 关键文件与函数

| 文件 | 职责 |
|------|------|
| `webView.go` | `RunWebView` 主流程：锁定 OS 线程 → 等待清理 → 创建单例 WebView → 等待后端服务就绪 → 导航 URL → 运行事件循环 → 清理资源 |
| `execute.go` | JS 执行桥接 |
| `type.go` / `variable.go` | 类型与变量 |

#### 启动决策树

```
OpenBrowser(url)
    │
    ├── IsWebViewSupported() == true
    │   └── StartWebViewBrowser(url)  ← 嵌入式 WebView
    │       ├── runtime.LockOSThread()   ← GUI 线程绑定
    │       ├── waitForServer(url)       ← TCP 轮询等待后端就绪
    │       ├── createWebView()          ← 单例创建
    │       └── w.Run()                  ← 阻塞事件循环
    │
    └── IsWebViewSupported() == false
        └── OpenSystemBrowser(url)     ← 系统浏览器
```

WebView 采用**单例模式**：`webviewMutex`（`sync.Mutex`）保护共享状态（单例实例 `webviewInstance`、防重入标记 `webviewRunning`、外部关闭通道 `webviewClosedCh`、清理完成信号 `webviewCleanupDone`）；`CloseWebView()` 可从任意 goroutine 安全调用。

#### IP 发现优先级

`GetLocalIP(preferredNetworks []string)` 遍历所有网络接口并分级选择最佳局域网 IP：

| 优先级 | 匹配网段 | 说明 |
|--------|---------|------|
| 最高 | 用户指定网段 | `preferredNetworks` 参数指定 |
| 次优 | `192.168.x.x` | 常见家庭/企业网段 |
| 第三 | `10.x.x.x` | 私网 A 类 |
| 第四 | `172.16–31.x.x` | 私网 B 类 |
| 第五 | `169.254.x.x` | 链路本地 |
| 最低 | 其他公网地址 | — |

过滤规则：跳过虚拟接口（vEthernet、Hyper-V、Docker、VirtualBox、VPN）、未启用接口（`FlagUp == 0`）与环回接口（`FlagLoopback`）；找到最高优先级 IP 立即返回（短路优化）。

#### 导出函数表

| 函数 | 说明 |
|------|------|
| `OpenBrowser(url string)` | 入口函数：优先 WebView，回退系统浏览器 |
| `OpenSystemBrowser(url string)` | 跨平台系统浏览器启动 |
| `StartWebViewBrowser(url string)` | WebView 启动（需在专用 goroutine 中调用） |
| `CloseWebView()` | 安全关闭 WebView 窗口 |
| `WebViewClosed() chan struct{}` | 返回关闭通知通道（用于等待窗口关闭） |
| `IsWebViewSupported() bool` | 检查平台是否支持 WebView |
| `IsWebViewRunning() bool` | 检查 WebView 是否正在运行 |
| `GetLocalIP(preferredNetworks []string) (string, error)` | 获取最佳本地 IP |

#### SQLite 知识库（KnowledgeDB）

**初始化配置**：WAL 模式、`busy_timeout=10000ms`、连接池（10 最大 / 5 空闲 / 5 分钟生命周期）、`PRAGMA synchronous=NORMAL / cache_size=10000 / foreign_keys=ON`。

**操作类型表**（`ExecuteKnowledgeRequest`，请求体 `KnowledgeRequest{Operations, Transaction}`、返回 `BatchResult{Success, Results, TotalTime, Operations}`）：

| 分类 | 操作类型 | SQL 生成 |
|------|---------|---------|
| 数据操作 | `insert` | `INSERT INTO table (cols) VALUES (...)` |
| | `update` | `UPDATE table SET ... WHERE ...` |
| | `delete` | `DELETE FROM table WHERE ...` |
| | `select` | `SELECT * FROM table WHERE ... ORDER BY ... LIMIT ...` |
| 表操作 | `create` | `CREATE TABLE IF NOT EXISTS table (columns, constraints, indexes)` |
| | `drop` | `DROP TABLE IF EXISTS table` |
| | `truncate` | `DELETE FROM table` |
| 信息操作 | `tables` | 查询 `sqlite_master` |
| | `structure` | `PRAGMA table_info(table)` |
| | `count` | `SELECT COUNT(*) FROM table` |

事务内任一操作失败立即回滚。

**WHERE 操作符表**（MongoDB 风格，经 `sanitizeIdentifier` 防注入：移除 `; ' " \ -- /* * / ( ) [ ]`，SQL 关键字自动前缀 `_`）：

| 操作符 | SQL 转换 | 示例 |
|--------|---------|------|
| `$eq` | `= ?` | `{"age": {"$eq": 25}}` |
| `$ne` | `!= ?` | `{"status": {"$ne": "deleted"}}` |
| `$gt` | `> ?` | `{"age": {"$gt": 18}}` |
| `$gte` | `>= ?` | `{"age": {"$gte": 18}}` |
| `$lt` | `< ?` | `{"age": {"$lt": 60}}` |
| `$lte` | `<= ?` | `{"age": {"$lte": 60}}` |
| `$like` | `LIKE ?` | `{"name": {"$like": "%test%"}}` |
| `$in` | `IN (?, ?, ...)` | `{"role": {"$in": ["admin","user"]}}` |
| 默认 | `= ?` | `{"id": 123}` |

**知识库请求 JSON 示例**：

```json
{
  "operations": [
    {
      "type": "create",
      "table": "users",
      "columns": [
        {"name": "id", "type": "INTEGER", "primary_key": true},
        {"name": "name", "type": "TEXT", "not_null": true}
      ]
    },
    {
      "type": "insert",
      "table": "users",
      "data": {"name": "Alice"}
    },
    {
      "type": "select",
      "table": "users",
      "where": {"name": {"$like": "%li%"}},
      "order_by": "name ASC",
      "limit": 10,
      "offset": 0
    }
  ],
  "transaction": true
}
```

**文件安全机制**：所有路径经 `filepath.Clean(filepath.Join(config.LocalDir, 请求路径))` + `strings.HasPrefix(完整路径, config.LocalDir)` 校验防路径遍历；文件名经 HTTP 头 `X-File-Name` Base64 传递，`DecodeFileName()` 解码后检查 `./`/`../`，不覆盖模式自动追加时间戳；并发文件锁用 `sync.Map` 存储每路径一个 `*sync.Mutex`。

## 4.4 image_processor —— 图像生成 + 截图 + 关键帧

### 职责

封装 stable-diffusion.cpp（扩散图像生成）、FFmpeg（视频关键帧）、跨平台截图能力，作为共享库供月华/琉璃使用。

### 关键文件与函数（module/）

| 文件 | 职责 |
|------|------|
| `generate.go` | 扩散图像生成（调用 sd-cli） |
| `capture.go` / `capture_windows.go` / `capture_stub.go` | 多平台截图（多显示器/区域），`capture_test.go` 为测试 |
| `keyframe.go` | 视频关键帧提取（FFmpeg） |
| `screenshot.go` | 截图能力封装 |
| `type.go` / `variable.go` | 类型与变量 |

### 依赖

- 内部：`general_config`、`logger_general`
- 外部：`sd-cli.exe`、`ffmpeg`、`kbinani/screenshot`、`lxn/win`

#### HTTP 端点表

> 由宿主程序（钛宇-琉璃 crystal_astral）注册。

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/generate` | 扩散图像生成（异步任务） |
| GET | `/generate/wait` | 轮询 / 等待生成任务完成 |
| POST | `/keyframe` | 视频关键帧提取 |
| POST | `/capture` | 统一截图（auto/window/fullscreen/display/region） |

| `normalizeFormat(format string) string` | 归一化格式名称（jpg/jpeg → jpeg） |

（`capture_windows.go` 在 Windows 平台用 Win32 `GetWindowDC`+`BitBlt` 实现焦点窗口捕获；`capture_stub.go` 非 Windows 平台返回「窗口截图仅在 Windows 平台可用」错误；`screenshot.go` 提供 `GetDisplays` / `screenshotAllDisplaysOptimized` / `ResizeImage` / `ToRGBA` / `ResizeToFit`。）

**CaptureRequest 字段说明**：

| 字段 | 说明 |
|------|------|
| `mode` | `auto` / `window` / `fullscreen` / `display` / `region`，缺省 `auto`；auto 焦点窗口优先、失败降级全屏 |
| `display_index` | `mode=display` 时生效，`-1` 表示全部 |
| `offset_x` / `offset_y` / `width` / `height` | 窗口相对精准区域（`mode=auto/window`，且 width>0 与 height>0 时启用） |
| `region_x` / `region_y` / `region_w` / `region_h` | 绝对屏幕坐标区域（`mode=region`） |
| `format` | `png` / `jpg`，缺省取 general_config |
| `quality` | JPEG 质量 1–100，缺省取 general_config |
| `scale` | 可选缩放：`"0.5"` 或 `"800,600"` |

## 4.5 logger_general —— 彩色终端日志

### 职责

轻量级彩色终端日志模块：分级日志、ANSI 颜色、开发模式控制、子模块标注、线程安全、零外部依赖。

#### 公开 API 函数表

**配置函数**

| 函数 | 说明 |
|------|------|
| `SetDevMode(v bool)` | 设置开发模式开关（Info 级别仅在开发模式下输出） |
| `SetOutput(w *os.File)` | 重定向日志输出到指定文件 |

**日志输出函数**

| 函数 | 签名 | 级别 | 说明 |
|------|------|------|------|
| `Info` | `Info(module, format string, v ...interface{})` | Info | 普通信息（仅开发模式） |
| `SubInfo` | `SubInfo(module, sub, format string, v ...interface{})` | Info | 带子模块的普通信息 |
| `Warn` | `Warn(module, format string, v ...interface{})` | Warn | 警告信息 |
| `SubWarn` | `SubWarn(module, sub, format string, v ...interface{})` | Warn | 带子模块的警告信息 |
| `Error` | `Error(module, format string, v ...interface{})` | Error | 错误信息 |
| `SubError` | `SubError(module, sub, format string, v ...interface{})` | Error | 带子模块的错误信息 |
| `Fatal` | `Fatal(module, format string, v ...interface{})` | Fatal | 致命错误（输出后调用 `os.Exit(1)`） |

**参数说明**：`module`（string，模块名，如 `"ProxySvr"`）、`sub`（string，子模块名，如 `"Cert"`）、`format`（string，`fmt.Sprintf` 格式串）、`v`（`...interface{}`，格式化参数）。

#### 日志级别与颜色表

| 级别 | 颜色 | 输出条件 | 说明 |
|------|------|---------|------|
| **Info** | 青色 (`\033[36m`) | 仅开发模式 | 调试信息，生产环境自动静默 |
| **Warn** | 黄色 (`\033[33m`) | 始终输出 | 警告信息，非致命异常 |
| **Error** | 红色 (`\033[31m`) | 始终输出 | 错误信息，需要关注 |
| **Fatal** | 粗体红 (`\033[1;31m`) | 始终输出 | 致命错误，输出后调用 `os.Exit(1)` |

#### 日志输出格式说明

```
[模块名] → 消息内容                        ← Info（青色）
[模块名][WARN] → 消息内容                   ← Warn（黄色）
[模块名][ERROR] → 消息内容                  ← Error（红色）
[模块名][FATAL] → 消息内容                  ← Fatal（粗体红，随后退出）
```

带子模块的格式：

```
[模块名]-[子模块名] → 消息内容              ← SubInfo
[模块名]-[子模块名][WARN] → 消息内容         ← SubWarn
[模块名]-[子模块名][ERROR] → 消息内容        ← SubError
```

> `Fatal` 输出后 `os.Exit(1)` 终止进程。`sync.RWMutex` 保护开发模式标志，并发安全。
