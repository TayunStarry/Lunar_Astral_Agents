## 4.1 general_config —— 全局配置中枢

> 被所有 Go 模块引用。**零外部依赖、纯数据提供者、并发安全。**

### 工作原理：双层配置

1. **命令行参数（flag）** —— 最高优先级
2. **`lunar_config.json`** —— 第二层，按字段增量覆盖默认值

### 关键文件与函数

| 文件 | 职责 |
|------|------|
| `init.go` | 核心实现：过滤测试参数 → `flag.Parse()` → 读取 JSON → 覆盖全局配置变量（模型、agent/memory/search、server 开关等） |
| `allow.go` / `engine.go` / `image.go` | 各配置分组 |
| `model.go` / `path.go` / `port.go` | 模型 / 路径 / 端口配置 |
| `system.go` / `webview.go` | 系统与 WebView 配置 |

> `lunar_config.json` 示例结构：`models`（asr/diffusion/variational/prompt_analysis）、`server`（bridging_* 桥接）、`agent`/`memory`/`search`（各域 embedding/multimodal 模型分流）。

## 4.2 browser_client —— WebView 窗口 + IP 发现

### 职责

桌面 WebView 嵌入式窗口管理、系统浏览器回退、本地 IP 自动发现、单例管理。

### 关键文件与函数

| 文件 | 职责 |
|------|------|
| `webView.go` | `RunWebView` 主流程：锁定 OS 线程 → 等待清理 → 创建单例 WebView → 等待后端服务就绪 → 导航 URL → 运行事件循环 → 清理资源 |
| `execute.go` | JS 执行桥接 |
| `type.go` / `variable.go` | 类型与变量 |

## 4.3 file_manager —— 文件 + 知识库/记忆库 + 扩展包

### 功能清单

本地文件 CRUD、ZIP 归档、预览、整理、SQLite 知识库、向量记忆库（JSON 文件存储）、扩展包管理。

### module / server 双目录结构

| 层 | 说明 |
|----|------|
| `module/` | 业务逻辑层 |
| `server/` | HTTP 服务层 |

### 核心文件职责（module/ 与 server/ 同名配对）

| 文件 | 职责 |
|------|------|
| `read.go` / `save.go` | 文件读写 |
| `delete.go` / `move.go` | 删除 / 移动 |
| `filelist.go` | 目录文件列表 |
| `download.go` / `archive.go` | 下载 / ZIP 归档 |
| `organize.go` | 文件整理 |
| `preview.go` | 文件预览 |
| `embedding.go` | 向量嵌入 |
| `knowledge.go` | SQLite 知识库 |
| `memory.go` | 向量记忆库（JSON 文件存储） |
| `hash_rename.go` | 哈希重命名 |
| `background.go` | 后台任务 |

## 4.4 image_processor —— 图像生成 + 截图 + 关键帧

### 职责

封装 stable-diffusion.cpp（扩散图像生成）、FFmpeg（视频关键帧）、跨平台截图能力，作为共享库供月华/琉璃使用。

### 关键文件与函数（module/）

| 文件 | 职责 |
|------|------|
| `generate.go` | 扩散图像生成（调用 sd-cli） |
| `capture.go` / `capture_windows.go` / `capture_stub.go` | 多平台截图（多显示器/区域），`capture_test.go` 为测试 |
| `keyframe.go` | 视频关键帧提取（FFmpeg） |
| `screenshot.go` | 截图能力封装 |
| `type.go` / `variable.go` | 类型与变量 |

### 依赖

- 内部：`general_config`、`logger_general`
- 外部：`sd-cli.exe`、`ffmpeg`、`kbinani/screenshot`、`lxn/win`

## 4.5 logger_general —— 彩色终端日志

### 职责

轻量级彩色终端日志模块：分级日志、ANSI 颜色、开发模式控制、子模块标注、线程安全、零外部依赖。

### 公开 API（README）

| 函数 | 用途 |
|------|------|
| `SetDevMode` / `SetOutput` | 开发模式 / 输出目标设置 |
| `Info` / `SubInfo` | 普通 / 子模块信息日志 |
| `Warn` / `SubWarn` | 普通 / 子模块警告 |
| `Error` / `SubError` | 普通 / 子模块错误 |
| `Fatal` | 致命错误（退出） |
