# 04 基础功能与服务手册

> [🏠 手册门户](README.md) ｜ [◀ 上一模块](03-扩展系统-钛宇-琉璃.md) ｜ [下一模块 ▶](05-独立AI引擎与运维工具.md)

## 一、功能介绍

公共子系统是月华与琉璃共享的底层基础服务集合，覆盖全局配置、嵌入式浏览器窗口、本地文件与知识库/记忆库、多模态素材预处理、终端日志、文件编解码以及图片格式与模型元数据工具等领域。它们通常不直接提供独立的功能界面，而是为月华、琉璃及各独立引擎统一提供配置读取、窗口展示、文件读写、素材转码与日志输出等能力，让上层智能体无需重复实现这些通用机制。当你在月华里对话、让琉璃检索网页、上传图片或视频、整理记忆库时，背后都由这些基础服务支撑。

## 二、使用方法

**窗口的打开与关闭**

1. 当前端页面需要展示时，宿主程序会自动打开嵌入式浏览器窗口（WebView）；若系统不支持 WebView，会自动改用系统默认浏览器打开同一地址。
2. 直接点击窗口关闭按钮即可关闭；关闭后若有新的展示需求，系统会重新打开窗口或新建会话。

**编辑全局配置**

1. 找到程序目录下的 `local_data/lunar_config.json`。
2. 按分组填写需要覆盖的字段（分组包括 `models`、`system`、`agent`、`diffusion`、`bridging`、`tts`、`web_search`、`release`），留空字段保持默认值。
3. 保存后重启程序生效；命令行的启动参数优先级高于配置文件。

**文件与知识库/记忆库的日常操作**

1. 上传或保存文件：在前端页面选择文件，系统会写入 `LocalDir`（默认为程序目录下的 `local_data/`）的对应相对路径。
2. 浏览、预览、移动、删除、整理与归档：通过页面的文件管理入口完成，删除与移动支持目录级操作。
3. 使用知识库：以结构化方式对本地数据库执行查询与增删改查，适合表格类数据。通用知识库为 `knowledge.db`；`/knowledge/` 端点的 `db` 也可填领域名（`archive` / `media` / `web` / `text` / `character`）直接访问对应领域库，或指定其它已存在的数据库文件作为数据源。
4. 使用记忆库：集合是内容自动归入的语义分组，启动时一次性加载全部集合；查询只指定返回类型（文本/图像/音频），不指定集合名。支持按 ID 读取、逐条列举、分页浏览集合文档、重建向量与清空集合。

**数据库分域**

SQLite 按领域分文件，一张表只属于一个库，避免同一业务在两个库之间来回读写：

| 库文件 | 领域 | 表 |
|--------|------|----|
| `knowledge.db` | 通用知识库（用户/插件自建表，`/knowledge/` 与 LTP9 `database.*` 默认库） | 由用户与插件决定 |
| `archive.db` | 统一资源名录（句柄、元数据、文档段落结构） | `resources` / `resource_sections` |
| `media.db` | 媒体派生数据（动图/视频/音频理解摘要、视觉副本簿记） | `video_summary` / `vision_cache` |
| `web.db` | 网络检索缓存（页面摘要） | `web_ltp_page_cache` |
| `text.db` | 文本内容索引（文件 → 分块集合） | `file_mapping` |
| `character.db` | 自定义角色库（绘图角色档案） | `painter_characters` |

升级自旧版本时，启动会自动把原先塞在 `knowledge.db` 的内建表、以及 `archive.db` 的视觉缓存迁入对应领域库；迁移前整库备份到 `{LocalDir}/backup/database/`，旧表迁移完成后删除。

记忆库的归组规则：启动时确保一批默认分组存在，并为每个分组用集合名生成嵌入向量；内容入库时先计算内容向量，与全部集合名向量比较后存入最相关的一组。检索时对全部集合一起查询，仅返回调用方指定的数据类型。月华的对话记忆检索固定取文本类型，表情包发送固定取图像类型。

记忆库图片实体统一存放在 `multimedia/memory/<分组名>/`，与生成图、截图、背景图隔离；删除条目、清空分组或删除分组时，会同步清理没有其它记忆条目引用的媒体文件。旧版 `multimedia/<分组名>/` 的图片在加载时自动迁移到新目录。

**统一资源归档层（资源名录 / 内容仓库 / 记忆库三层）**

月华引用的所有资料（文本文件、图片、视频、音频、表格）都由公共子系统的资源归档层承载，职责分为三层：

1. **资源名录**：记录每份资料的句柄（`@D`/`@I`/`@V`/`@A`/`@T`）、类型、标题与文档结构。序号持久化且永不复用。
2. **内容仓库**：保存资料原文；相同内容只保留一份。超出配额时按保留等级与最久未用回收原文，目录行随实体一并移除，失效句柄不滞留。
3. **记忆库**：只存"经历"（对话回合、工具往返），不再存文档切片。

收录走统一入口：本地上传的文件只登记不复制，渠道（QQ 等）仅给链接的资源由系统下载后落盘，同一内容无论来源只存一份。

**素材处理入口**

1. 截图：可捕获焦点窗口、整屏、指定显示器或屏幕区域，输出格式与质量可调。
2. 音视频：上传的音频会自动转为 16kHz 单声道 WAV；视频会自动提取关键帧并本地化，长视频按段处理。
3. 动态图：上传多帧动图会自动转码为慢放视频，交由感知者角色理解。
4. 图像生成：需要生成图片时由扩散引擎生成，可选择超分辨率放大。

**查看日志**

1. 程序运行中会在终端实时输出彩色日志，排查问题时开启开发模式可获得更完整、不限流的输出。
2. 需要留存日志时可将输出重定向到文件。

## 三、功能特性

| 特性 | 说明 |
|------|------|
| 全局配置 | 统一读取命令行参数与 `lunar_config.json`，向所有模块提供一致的配置来源 |
| WebView 窗口与会话管理 | 嵌入式窗口展示前端页面，支持多实例会话、区域截图、窗口样式定制与系统浏览器回退 |
| 文件管理 | 本地文件增删改查、移动、下载、预览、整理、哈希重命名与 ZIP 归档 |
| 静态资源服务 | 经 `/file/read/package/` 为前端页面提供共享资源 |
| 知识库 | 本地结构化数据库，支持查询、增删改查与多数据源切换 |
| 统一资源归档 | 资源名录 + 内容仓库 + 配额回收，文本/图片/视频/音频/表格共用一套句柄 |
| 记忆库 | 基于向量的语义记忆：启动加载全部集合、内容自动归组、按类型查询、按 ID/逐条列举与重建 |
| 多模态素材转码 | 截图、音视频本地化、关键帧提取、动态图转慢放视频 |
| 日志 | 分级彩色终端日志，按模块限流，支持开发模式 |
| 月球编码 | 文件加密混淆与还原的确定性可逆变换，产物为可打印文本 |
| 图片格式与 GGUF 元数据工具 | png/jpeg/webp 图片互转，以及 GGUF 模型元数据解析 |
| 辅助工具 | NapCat 消息监听调试工具与 LTP3/LTP9 权限密钥生成工具 |

## 四、运行参数

配置项主要来自 `lunar_config.json` 的 `system`、`models` 等分组，以及部分命令行开关与图像/编解码参数。

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `system.developer` | 开发模式，输出全部且不限流的日志（对应命令行开关） | `false` | 排查问题时临时开启 |
| `system.allow_lan` | 允许局域网内的设备访问服务 | `false` | 需要局域网访问时设为 `true` |
| `system.insecure_tls` | 跳过插件网络请求的 TLS 证书校验 | `false` | 仅在自签名环境调试时开启 |
| `system.console_log` | 将控制台输出镜像落盘到 `local_data/logs/console.log` | `false` | 仅在需要离线排查时开启 |
| `models.*` | 扩散、VAE、提示词精炼、超分等辅助模型的路径 | `{LocalDir}/models/` 下的文件 | 更换模型时修改对应路径 |
| `system.character_renderer` | 前端角色渲染方式，可选 `bedrock` 或 `live2d` | `bedrock` | 按前端页面需要选择 |
| `system.live2d_model` | 选择 Live2D 渲染时使用的模型标识 | 空 | 改用 `live2d` 时一并配置 |
| 图片格式参数 | 默认图片格式与 JPEG 压缩质量 | `jpg` / `90` | 需要更高画质时提高质量 |
| FFmpeg 路径 | 指定 FFmpeg 可执行文件位置 | 空（使用系统 PATH） | 音视频处理失败时显式指定 |
| 知识库路径 | 通用知识库（用户/插件自建表）位置（`-knowledge-db`） | `{LocalDir}/database/knowledge.db` | 一般无需修改 |
| 资源目录路径 | 统一资源句柄目录数据库位置（`-archive-db`） | `{LocalDir}/database/archive.db` | 一般无需修改 |
| 媒体派生库路径 | 媒体理解摘要与视觉副本簿记位置（`-media-db`） | `{LocalDir}/database/media.db` | 一般无需修改 |
| 网络检索缓存路径 | 网页摘要缓存位置（`-web-db`） | `{LocalDir}/database/web.db` | 一般无需修改 |
| 文本索引库路径 | 文本文件内容索引位置（`-text-db`） | `{LocalDir}/database/text.db` | 一般无需修改 |
| 角色库路径 | 自定义角色档案位置（`-character-db`） | `{LocalDir}/database/character.db` | 一般无需修改 |
| 资源仓库配额 | 内容仓库容量上限 MB、单资源上限 MB、回收周期分钟（`-archive-quota-mb` / `-archive-max-blob-mb` / `-archive-gc-interval-min`） | 2048 / 20 / 30 | 磁盘紧张时下调配额；回收不影响句柄可用性 |
| 月球编码密钥 | 文件编解码所用密钥 | 无默认 | 不写入配置，由调用方传入 |

配置的完整分组与字段说明详见 [08 构建、运行与配置](08-构建运行与配置.md)。

## 五、常见排故

| 现象 | 可能原因 | 处理办法 |
|------|----------|----------|
| 配置不生效 | 文件位置不对、字段写在错误分组、修改后未重启 | 确认配置文件位于 `{LocalDir}/lunar_config.json` 且字段归属正确；重启程序；注意命令行参数优先级更高 |
| 窗口白屏或无法启动 | 未安装 WebView2 Runtime、页面加载失败 | 安装 WebView2 Runtime；WebView 不可用时系统会自动回退系统浏览器；确认后端服务已就绪 |
| 文件读写失败 | 路径越界、目录权限不足、文件被占用 | 确认操作路径位于 `LocalDir` 内；关闭占用文件的程序；检查目录读写权限 |
| 知识库/记忆库异常 | 数据库被占用或损坏（`knowledge` / `archive` / `media` / `web` / `text` / `character`）、嵌入模型服务不可达 | 关闭占用进程；确认嵌入模型路由可访问；数据库损坏时可用 `{LocalDir}/backup/database/` 下的迁移备份恢复；必要时重建集合 |
| 音视频转码失败 | 未安装 FFmpeg、格式不支持 | 安装 FFmpeg 或指定 FFmpeg 路径；确认输入格式受支持 |
| 日志缺失或颜色不显示 | 非开发模式下按模块限流、终端不支持 ANSI 颜色 | 开启开发模式获得完整日志；使用 Windows Terminal 或 PowerShell 7+ 等支持 ANSI 的终端 |
