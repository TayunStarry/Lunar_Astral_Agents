## 一、这是什么

这一篇解决「从拿到程序到跑起来」的全部问题：需要什么系统环境、怎么启动、第一次怎么配置模型、出错时先看哪里。按顺序照做即可，不需要理解内部结构。

---

## 二、核心用途

- **一次装好**：明确列出必需与可选的运行环境。
- **快速启动**：三种启动方式与端口说明。
- **模型就位**：告诉你去哪里放模型、改哪个文件。
- **自助排障**：常见启动问题一眼定位。

## 三、使用方法

### 3.1 环境要求

| 项目 | 要求 | 说明 |
|------|------|------|
| 操作系统 | Windows 10 21H2 及以上 / Windows 11，64 位 | 不支持 32 位、Linux 与 macOS 运行 |
| WebView2 Runtime | 已安装（Win11 通常自带） | 前端窗口必需；缺失会白屏 |
| 磁盘空间 | 视模型而定，通常需数十 GB | 模型文件体积较大 |
| 显存 | 建议 8GB 以上 | 直接影响出图尺寸与速度 |
| CUDA（可选） | 12.x / 13.x | GPU 加速推理 |
| FFmpeg（可选） | 5.0 以上 | 音视频转码 |
| Vulkan（可选） | 1.3 以上 | 另一种 GPU 后端 |

### 3.2 获取程序

发行版目录通常包含：

| 文件 / 目录 | 说明 |
|-------------|------|
| `Lunar_Astral_Agents.exe` | 主程序 |
| `Lunar_Update_Applier.exe` | 更新器（更新时自动拉起） |
| `local_data/` | 本地数据根目录：配置、模型、记忆、扩展包、素材 |
| `local_data/models/` | 模型目录（发行版可能需另行下载） |

### 3.3 启动

| 方式 | 操作 |
|------|------|
| 正常启动 | 双击 `Lunar_Astral_Agents.exe`，进入全屏控制台，并自动打开月华与琉璃窗口 |
| 开发模式 | 追加 `-developer`，日志不限流 |
| 指定端口 | 追加 `-basic-port 36800`，端口冲突时使用 |

首次启动较慢，需要加载模型与初始化数据，请耐心等待。

### 3.4 首次使用

1. 月华窗口首次打开会询问「希望月华如何称呼您？」，输入后缓存在浏览器本地，电脑端与手机端共用。
2. 在输入框发一句话，确认对话可用。
3. 打开琉璃窗口，确认桌面卡片正常显示。
4. 如需语音、绘图、搜索，按下面「模型配置」补齐模型。

### 3.5 退出

- 控制台主菜单选「退出程序」（快捷键 `b`），或按 `Ctrl+C`。
- 关闭月华 / 琉璃窗口**不会**退出程序；控制台会继续运行，可在「前端页面」屏重新打开。

### 3.6 端口

| 端口 | 用途 | 默认 |
|------|------|------|
| 基础端口 | 月华消息终端、琉璃桌面（`/desktop/`）、API 共用 | `36789` |
| 模型端口 | 本地模型服务（llama-server，含语音识别预设） | 基础端口 + 1（`36790`） |
| 代理端口 | 局域共享代理 | 基础端口 + 5（`36794`） |

端口冲突时用 `-basic-port` 换一组，其余端口自动跟随。

### 3.7 模型配置

**文本与多模态模型**：编辑 `local_data/models/models.ini`

| 段 | 用途 |
|----|------|
| `primary_reasoning` | 多模态对话模型（`model` 主模型 + `mmproj` 视觉投影） |
| `text_embedding` | 嵌入模型（`model`，需开启嵌入输出） |
| `audio_transcriber` | 语音识别模型（`model` + `mmproj` 音频编码器） |

**图像生成模型**：编辑 `local_data/config/painter.json` 的顶层方案键（如 `turbo` / `quality`），成组配置扩散模型、VAE、提示词分析模型与超分模型。`default_scheme` 指定默认启用哪一套。

**语音合成模型**：把模型与运行库直接平铺到 `local_data/models/broadcaster/`（三套引擎共用该目录，不再分子目录），并在 `tts.engine` 选择 `Qwen` / `Kokoro` / `OmniVoice`。

改完配置后重启程序生效。

### 3.8 从源码构建

1. 准备：Go 1.26、GCC（MinGW-w64 或 TDM-GCC，CGO 需要）、rsrc（`go install github.com/akavel/rsrc@latest`）；编译语音引擎还需 CMake。
2. 在仓库根目录执行 `.\build.ps1`，会依次构建主程序与更新器。
3. 可选参数：`-TargetOS windows|linux|darwin`、`-TargetArch amd64|arm64`。
4. 构建前请先关闭正在运行的程序，否则输出文件会被占用。

## 四、控制台速查

控制台是程序唯一的界面形态，启动后进入全屏终端。宽屏时左侧常驻导航栏；任意屏按 `[` / `]` 切换上一屏 / 下一屏，`Esc` 回主菜单，`?` 查看当前屏键位帮助。

| 按键 | 入口 | 能做什么 |
|------|------|----------|
| `0` | 推理实况 | 查看思考 / 输出 / 工具调用流；可切换是否自动跟随 |
| `1` | 运行状态 | 运行环境、模型计量、前端窗口（`1`/`2`/`3` 重开月华 / 琉璃 / 资源库）；`i` / `x` 启停桌面操纵 |
| `2` | 系统日志 | 左右方向键切换 原始 / 警告 / 绘图 / 对话 / 生活 / 后勤 |
| `3` | 数据导出 | 导出原始日志、推理实况、各智能体上下文 |
| `4` | 工具列表 | 扫描并展示全部智能体的工具与说明 |
| `5` | 局域共享 | WSS → WS 反向代理，选择 IP 并可扫码接入 |
| `6` | 打包归档 | 按配置做 7z 分卷打包 |
| `7` | 端口释放 | 扫描端口范围并终止占用进程 |
| `8` | 资源更新 | 发布 / 拉取更新包（主程序 + 指定文件夹，覆盖后自动重启） |
| `9` | 退出程序 | 关闭控制台并优雅停止全部子系统 |

常用键位：

- 移动 `↑/↓`（或 `k`/`j`）；翻页 `Ctrl+U` / `Ctrl+D`；跳首尾 `Home/End`。
- 日志与列表：`f` 切换跟随，`c` 清空；上翻会自动暂停跟随，按 `End` 回到最新。
- 输入框聚焦时，`?`、`[`、`]` 等让位给正文输入。

**界面纯白 / 没有颜色**时按顺序排查：

1. 「原始日志」里搜 `[TUI] 配色档位:`，这一行会写明当前档位与判定依据。
2. 环境里存在 `NO_COLOR` 或 `CLICOLOR=0` 会禁用颜色，清掉即可。
3. 仍无色时显式指定 `LUNAR_TUI_COLOR`（取值 `dumb` / `16` / `256` / `truecolor`）。

## 五、功能特性

| 特性 | 说明 |
|------|------|
| 单文件主程序 | 前端资源、提示词、类型声明都内嵌在可执行文件内 |
| 控制台常驻 | 程序只有控制台一种形态，前端窗口可随时重开 |
| 端口联动 | 只改基础端口，模型与代理端口自动跟随 |
| 模型预设 | 用 `models.ini` 分段声明模型，切换模型只改段内路径 |
| 方案化绘图 | 绘图模型成套声明，启动时按 `default_scheme` 应用默认方案 |
| 覆盖式更新 | 更新器在程序退出后覆盖文件并重启，支持回滚 |

## 六、运行参数

### 6.1 启动参数（主程序）

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `-basic-port` | 基础服务端口 | `36789` | 端口冲突时更换 |
| `-model-port` | 模型服务端口 | 基础端口 + 1 | 一般无需改动 |
| `-proxy-port` | 代理监听端口 | 基础端口 + 5 | 一般无需改动 |
| `-developer` | 开发模式，日志不限流 | 关闭 | 排障时临时开启 |
| `-allow-lan` | 允许局域网访问 | 关闭 | 仅跨机部署时开启 |
| `-insecure-tls` | 插件网络跳过 TLS 校验 | 关闭 | 保持关闭 |
| `-allow-diffusion` | 允许扩散图像生成 | 开启 | 不绘图时可关闭 |
| `-allow-browser` | 允许打开系统浏览器 | 开启 | 一般保持开启 |
| `-sync-fetch-timeout` | 同步网络请求超时（秒） | `300` | 网络慢时调大 |
| `-local-dir` | 本地数据根目录 | `local_data` | 数据放其它盘时调整 |
| `-infer-engine` | 文本推理引擎可执行文件路径 | 模型目录下的默认路径 | 引擎放别处时调整 |
| `-visual-engine` | 绘图引擎可执行文件路径 | 模型目录下的默认路径 | 引擎放别处时调整 |
| `-tts-engine` | 语音合成引擎 | `Qwen` | 可选 Qwen / Kokoro / OmniVoice |
| `-tts-idle-unload-minutes` | 语音引擎闲置卸载阈值（分钟） | `5` | 显存紧张时调小 |
| `-client-character-renderer` | 前端角色渲染方式 | `bedrock` | 可选 bedrock / live2d / gif |
| `-archive-db` | 句柄库文件 | `local_data/database/handles.db` | 一般无需修改 |
| `-knowledge-db` | 通用知识库文件 | `local_data/database/knowledge.db` | 一般无需修改 |
| `-memory-db` | 记忆库目录 | `local_data/database/memory` | 一般无需修改 |

### 6.2 配置文件一览

| 文件 | 作用 |
|------|------|
| `local_data/config/general.json` | 公共配置：系统、Agent、语音、搜索、文献解析 |
| `local_data/config/painter.json` | 绘图配置：模型方案与扩散生成参数 |
| `local_data/models/models.ini` | 文本 / 嵌入 / 语音识别模型预设 |
| `local_data/config/release.json` | 发布仓库与令牌（私有，不入库） |
| `local_data/config/napcat.json` | QQ 桥接配置（私有） |
| `local_data/config/bilibili.json` | B 站偏好与互动次数（私有） |
| `local_data/config/forum.json` | 互助论坛配置（私有） |
| `local_data/config/labels.json` | 配置项的中文标签 |

配置优先级：命令行参数 > 配置文件 > 内建默认值。

## 七、常见问题

| 现象 | 可能原因 | 处理办法 |
|------|----------|----------|
| 双击无反应或闪退 | 缺少运行库、模型缺失，或被安全软件拦截 | 补齐 WebView2；确认模型完整；把程序加入白名单 |
| 前端窗口空白 | 未安装 WebView2 Runtime | 安装后重启 |
| 端口被占用 | 默认端口被其它程序占用 | `-basic-port` 换端口，或释放占用 |
| 提示找不到模型 | 模型未放入、路径写错，或段名不匹配 | 核对 `models.ini` 段与路径；重启 |
| 首次启动很慢 | 模型加载与数据初始化 | 等待完成；后续启动会更快 |
| 出图报显存不足 | 尺寸过大或未设显存预算 | 下调尺寸，设置 `sd_max_vram` |
| 语音没有声音 | 参考音频缺失、引擎未就绪 | 确认 `tts.ref_audio` 指向存在的文件 |
| 构建失败 | 缺 Go / GCC / rsrc / CMake，或程序在运行 | 补齐依赖；先关闭正在运行的程序 |
| 更新后启动异常 | 新版本与本地数据不匹配，或覆盖不完整 | 从 `.backup/<时间戳>/` 回滚，或重新拉取完整包 |
| 想换数据盘 | 数据默认在程序目录下 | 用 `-local-dir` 指向新目录后重启 |
