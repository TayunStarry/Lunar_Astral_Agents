# 09 安全机制

> [🏠 手册门户](README.md) ｜ [◀ 上一模块](08-智能体架构.md) ｜ [下一模块 ▶](10-快速部署.md)

---

## 一、这是什么

安全机制回答一个很实际的问题：**这套能看屏幕、能上网、能改文件的 AI，边界在哪里？**

星月智能默认把一切收在本机：模型推理不出网、服务只监听回环地址、脚本只能读写自己的目录、口令类配置单独存放且不进版本库。需要跨机或更高权限时，必须由你显式打开。

---

## 二、核心用途

- **数据不出本机**：对话、图片、记忆都在本地处理。
- **最小暴露**：默认只监听 `127.0.0.1`，局域网默认不可访问。
- **写入受限**：文件操作与脚本运行都被限制在指定目录。
- **凭证分离**：令牌、Cookie、账号信息不进主配置、不进版本库。
- **可回滚**：更新前备份，更新包带校验值。

---

## 三、使用方法

### 3.1 默认安全状态

| 项目 | 默认 | 说明 |
|------|------|------|
| 服务监听 | 仅本机回环 | 其它设备无法访问 |
| 插件网络证书校验 | 开启 | 不跳过 TLS 校验 |
| 桌面操纵 | 关闭，且不对 AI 暴露 | 只能人工在控制台启停 |
| 脚本运行时 | 仅内部创建 | 不扫描外部脚本、无权限清单 |
| 更新包校验 | 校验 SHA-256 | 与发布描述中的校验值比对 |

### 3.2 需要局域网访问时

1. 在 `local_data/config/general.json` 的 `system` 分组把 `allow_lan` 设为 `true`（或启动时加 `-allow-lan`）。
2. 重启程序，服务会绑定全部网卡。
3. 用控制台「局域共享」屏生成接入信息与二维码，手机扫码即可访问。
4. 不使用时请改回 `false`。

### 3.3 自签名 HTTPS 环境

局域网共享会在本机生成并复用自签证书。若你的插件或外部调用需要访问自签名服务，可临时把 `system.insecure_tls` 设为 `true` 跳过校验；**调试结束后请改回 `false`**。

### 3.4 配置文件与凭证放在哪

| 文件 | 内容 | 是否入库 |
|------|------|----------|
| `local_data/config/general.json` | 公共配置（系统、Agent、语音、搜索等） | 可入库 |
| `local_data/config/painter.json` | 绘图配置（模型方案与扩散生成参数） | 可入库 |
| `local_data/config/release.json` | 发布仓库与令牌 | **不入库**（已被忽略） |
| `local_data/config/napcat.json` | QQ 桥接地址、令牌、允许的账号与群 | **不入库** |
| `local_data/config/bilibili.json` | B 站偏好与互动次数 | **不入库** |
| `local_data/config/forum.json` | 互助论坛配置 | **不入库** |
| `local_data/database/` | 记忆、句柄库、角色库、生活状态 | 不入库 |

发布令牌可以留空：在控制台发布时手动输入，只用于本次请求，不落盘。

### 3.5 文件与脚本的边界

- **文件接口**：只能操作本地数据根目录（默认 `local_data/`）内的路径，绝对路径与越界路径会被拒绝。
- **脚本运行时**：每个运行实例有独立数据目录，相对路径被约束在其中；越界同样拒绝。
- **源文件保护**：句柄收录一律只读，不移动、不删除你的原始文件。

### 3.6 更新与回滚

1. 控制台「资源更新」屏拉取更新包。
2. 程序按发布描述里的 SHA-256 校验下载内容。
3. 覆盖前把旧文件备份到 `.backup/<时间戳>/`，保留份数由 `backup_keep` 决定（默认 3）。
4. 更新包恒含主程序：拉取后会关闭程序、由更新器覆盖并重启。
5. 需要回滚时，从 `.backup/` 对应时间戳目录取回旧文件。

### 3.7 循环输出监管

模型偶尔会陷入「复读」：把同一句话或同一段枚举无限重复下去，既浪费显存，也会把整轮回答拖住。程序在流式输出过程中实时检测，命中后直接中断本次请求：

- **思考与正文分开统计**，互不干扰；
- 每累计 1024 字检查一次：把这段文本切成 8 个 128 字的片段，计算相邻片段的**平均相似度**；
- 平均相似度超过阈值（默认 0.65）即判定为持续复读，立即中止本次生成；
- 流结束时再对最后 1024 字兜底判一次，避免结尾卡住而漏判；
- 不走流式的调用（文件编辑、部分外部请求）在整包解析后按同一规则静态判定一次。

所有会调用模型的 Go 智能体都受这条监管：核心人格（对话者 / 绘制者 / 演奏者 / 截图者）、网络搜索、哔哩观影、桌面操作、通讯桥接、互助论坛、自由创作、文件编辑、归档操作、通用应答、视觉理解、文献解析，以及智能修复自己。

正常内容不会被误伤：短暂的模板化枚举（例如连续几帧「同上一帧」）只影响一两个片段，会被平均值稀释；只有整段都在复读才会触发。

触发后这一次生成按失败处理，复读内容不会被当成回答发给你（月华会给兜底回复，其它智能体会按各自流程重试或跳过），日志里会留下中断记录。

三个参数都放在 `local_data/config/general.json` 的 `system` 分组，按实际效果微调即可：

| 参数 | 作用 | 默认 | 调整方向 |
|------|------|------|----------|
| `loop_node_runes` | 检查窗口长度（字） | `1024` | 调小更灵敏，但更容易误判 |
| `loop_segment_runes` | 窗口内单个片段长度（字） | `128` | 需小于窗口的一半，一般不动 |
| `loop_similarity` | 相邻片段平均相似度阈值（0~1） | `0.65` | 误判多就上调，漏判多就下调 |

### 3.8 上下文自动修复

模型报错有时不是模型坏了，而是**上下文坏了**：消息堆得太长、图片已失效无法解析、某条工具结果格式异常。这类故障会一直复现，直到上下文被清理。程序内置了一个专门的修复角色——**智能修复**：

1. **上报**：任一智能体执行失败时，把错误上报到故障队列。同一智能体只保留最新一条，队列上限 8 条。循环截断与主动取消不上报。
2. **排期**：后勤体系在 Tick 中取一条故障处理，一次只修一个，避免单轮过长。
3. **修复**：修复角色带着工具读取上下文（最近若干条或全部），再执行修复动作：
   - `trim`：只保留最近 N 条消息（默认 8 条），针对上下文超长；
   - `drop_images`：把上下文里的图片替换成占位文本，针对无法解析的图片；
   - `clear`：整体清空，最后手段；
   - `reset`：重置该智能体的记忆（只有提供该动作的目标才可用）。
4. **收尾**：单次修复最多 6 轮工具调用、每次模型调用 90 秒超时；同一故障最多尝试 2 次，仍失败则对同一智能体静默 5 分钟，避免越修越崩。

**每个 Go 智能体都是可修复目标**，按有没有跨轮上下文分成两类：

| 类型 | 智能体 | 可用动作 |
|------|--------|----------|
| 持有跨轮上下文 | 核心人格（对话者 / 绘制者 / 演奏者 / 截图者）、互助论坛 | `trim` / `drop_images` / `clear`（论坛为 `trim` / `reset`） |
| 按次执行 | 网络搜索、桌面操作、通讯桥接、自由创作、文件编辑、归档操作、通用应答、视觉理解、文献解析 | `reset`：清掉在途轮次、排队请求、最近记录与缓存 |

上报来源：核心人格由调度体系在体系执行失败时上报；网络搜索、桌面、桥接、创作、文件编辑、通用应答在各自运行入口上报；互助论坛在模型调用失败时上报；视觉理解、文献解析与归档操作共用模型调用层，重试仍失败时按实况角色标签映射回自己的 ID。观影由生活回合驱动、不再持有跨轮运行期状态，失败只记录日志。循环截断与主动取消不会上报，避免把保护行为当成故障。智能修复也把自己登记为目标，故障队列卡住时可整体 `reset`。

修复直接作用在该智能体的内存上下文或运行期状态上，下一次 Tick（或下一次调用）不会再带着坏状态启动。全过程在日志里带 `[智能修复]` 前缀，可在控制台「系统日志」查看。

### 3.9 主动清理数据

| 想清理 | 做法 |
|--------|------|
| 记忆条目 / 分组 | 记忆库工作台删除；图片会同步清理无引用实体 |
| 资源原文 | 调低 `-archive-quota-mb` 加速回收，或删除 `local_data/multimedia/` 下对应文件 |
| 生活状态 | 删除 `local_data/database/life/` 下对应文件，重启后按默认重建 |
| 全部本地数据 | 退出程序后删除 `local_data/` 中不需要的目录 |

## 四、功能特性

| 特性 | 说明 |
|------|------|
| 纯本地推理 | 模型与数据都在本机，不依赖云端 |
| 回环绑定 | 默认仅本机可访问 |
| 路径约束 | 文件接口与脚本运行时都被限制在各自数据目录 |
| 凭证隔离 | 令牌与账号类配置单独成文件，且不进版本库 |
| 令牌不落盘 | 发布令牌可在使用时临时输入 |
| 桌面操纵隔离 | 不进入 AI 工具链，只能人工启停 |
| 风险过滤 | 观影等联网行为会跳过命中风险的内容 |
| 循环输出监管 | 思考与正文分别检测，持续复读超过阈值立即中断本次生成 |
| 上下文自动修复 | 故障自动排队，由修复角色读取并裁剪 / 剔除图片 / 清空上下文 |
| 更新校验与备份 | SHA-256 校验 + 覆盖前备份，可回滚 |
| 子进程更新 | 主程序被占用时交由更新器在退出后覆盖 |

## 五、运行参数

| 参数 | 位置 | 说明 | 默认值 | 建议 |
|------|------|------|--------|------|
| `system.allow_lan`（`-allow-lan`） | 配置文件 / 启动参数 | 允许局域网访问引擎服务 | `false` | 仅跨机部署时开启 |
| `system.insecure_tls`（`-insecure-tls`） | 配置文件 / 启动参数 | 跳过插件网络请求的 TLS 校验 | `false` | 仅自签名调试时临时开启 |
| `-basic-port` | 启动参数 | 基础服务端口 | `36789` | 被占用时更换 |
| `-proxy-port` | 启动参数 | 局域共享代理端口 | 基础端口 + 5 | 一般无需修改 |
| `system.loop_node_runes` | 配置文件 | 重复输出检测的检查窗口长度（字） | `1024` | 调小更灵敏，但更易误判 |
| `system.loop_segment_runes` | 配置文件 | 窗口内单个片段长度（字） | `128` | 需小于窗口一半，一般不动 |
| `system.loop_similarity` | 配置文件 | 相邻片段平均相似度阈值（0~1） | `0.65` | 误判多上调，漏判多下调 |
| `release.backup_keep` | `config/release.json` | 更新覆盖前备份保留次数 | `3` | 需要更多回滚余地时调大 |
| `release.program_files` | `config/release.json` | 需要关程序再覆盖的主程序清单 | 出厂清单 | 决定更新是否重启 |

## 六、常见问题

| 现象 | 可能原因 | 处理办法 |
|------|----------|----------|
| 手机/其它电脑打不开 | 默认仅本机回环 | 开启 `allow_lan` 后用「局域共享」接入 |
| 浏览器提示证书不受信任 | 局域共享使用自签证书 | 属预期；在客户端信任该证书，或仅在本机使用 |
| 插件请求证书报错 | 目标站点使用自签名证书 | 临时开启 `insecure_tls`，用完改回 |
| 文件写入被拒绝 | 路径越出数据根目录 | 使用相对路径，写入 `local_data/` 内 |
| 脚本读写失败 | 路径越出沙箱数据目录 | 只在自己目录内读写 |
| 发布时报令牌错误 | 未输入令牌或权限不足 | 在发布向导输入有读写权限的令牌 |
| 更新后想回滚 | 新版本有问题 | 从 `.backup/<时间戳>/` 取回旧文件 |
| 回答说到一半突然中断 | 触发了循环输出监管 | 属保护行为；换个问法重试，误判频繁可上调 `loop_similarity` |
| 某能力连续报错、日志出现「智能修复」 | 上下文类故障，正在自动修复 | 等一两轮 Tick；仍失败可在控制台把该智能体上下文清空后重试 |
| 担心配置里的令牌泄露 | 令牌写进了可入库的文件 | 移到 `config/release.json` / `config/napcat.json`，并确认未被版本库跟踪 |
