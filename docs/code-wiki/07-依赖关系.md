## 一、功能介绍

本页是全手册的「参数速查 + 文档导航」枢纽，用于在不翻阅全文的情况下快速定位常用端口与关键配置，并找到对应的详细文档。当用户想调整某项运行行为、却不确定该改哪个参数、该看哪一篇时，可先在本页按用途检索，再跳转到详解章节。本页只收录用户可自行设置的端口与配置项，默认值用于快速对照，具体取值约定与调优建议以对应详解文档为准。

## 五、常见排故

| 现象 | 可能原因 | 处理办法 |
|------|----------|----------|
| 不确定某参数应去哪里配置 | 参数分散在多个分组中 | 先在本页对照表定位功能域，再进入「详见文档」列查阅 |
| 修改配置后未生效 | 未重启程序，或命令行参数覆盖了配置文件 | 修改后重启程序，并确认未同时使用命令行参数覆盖 |
| 端口冲突导致服务不可用 | 默认端口被其它程序占用 | 使用启动开关 `-basic-port` 更换基础端口，或释放被占用端口 |
| 参数取值不合预期 | 取值超出允许范围而回退默认 | 参照对应详解文档的取值约定重新设置 |
