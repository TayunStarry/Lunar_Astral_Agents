## 1. Go Module 依赖图

所有 Go 模块均位于 `d:\Lunar_Astral_Agents`，通过 `go.mod` 的 `replace` 指令引用同级 `subsystem/` 目录，共享 `GeneralConfig` 与 `LoggerGeneral`。

```
lunar_astral ─→ GeneralConfig, BrowserClient, FileManager,
                 LoggerGeneral, ImageProcessor, AgentSearch, Qwen3-TTS

crystal_astral ─→ GeneralConfig, BrowserClient, FileManager,
                  ImageProcessor, LoggerGeneral

agent_search ─→ FileManager, GeneralConfig, LoggerGeneral
qwen3_tts   ─→ GeneralConfig, LoggerGeneral
qwen_asr    ─→ BrowserClient, GeneralConfig, LoggerGeneral
environment_repair ─→ GeneralConfig
image_processor ─→ GeneralConfig, LoggerGeneral
file_manager ─→ GeneralConfig, LoggerGeneral        (基础)
browser_client ─→ GeneralConfig
```

> `logger_general`、`general_config` 为**零外部依赖**根节点，被全项目复用。

## 5. WebSocket 消息链路

```
后端 → BroadcastMessage → bridgeToQQ(NapCat) + 所有在线 WS 客户端
     (context/image 类型消息)
前端 ↔ ws_bridge.js → /write/engine → 琉璃 StudioHub → 广播本地面板
```

## 6. 静态资源加载约定

- 前端资源一律通过 `/file/read/package/` 加载，禁止 CDN。
- 标准依赖：`/file/read/package/standard_dependency/{script.js,styles.css}`。
- TS 智能体编译产物 `agentSystem.js` 通过 Go `embed` 内嵌于可执行文件，随主程序分发。
