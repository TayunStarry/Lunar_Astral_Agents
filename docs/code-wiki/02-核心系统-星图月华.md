# 02 核心系统——星图·月华（lunar_astral）

> [🏠 文档地图](README.md) | [◀ 上一章](01-项目架构总览.md) | [下一章 ▶](03-扩展系统-星图琉璃.md)
> 相关源文档：[lunar_astral/README.md](../../lunar_astral/README.md)

AI 桌面智能体核心系统，集成多模态对话、TTS 语音合成与图像生成。

---

## 1. 目录总览

| 目录 | 职责 |
|------|------|
| `adapters/` | Go↔JS 双向桥接层（goja 运行时），将 Go 能力暴露为 JS 可调用函数 |
| `model/` | 模型服务层，管理 llama-server 进程生命周期与请求代理 |
| `server/` | HTTP 服务层：路由注册、CORS、初始化编排、消息/图像处理 |
| `hierarchy/` | 前端资源容器（Go embed 嵌入）：智能体 JS、角色 Prompt、Web 界面 |
| `websocket/` | WebSocket 实时通信：连接管理、读写泵、广播推送 |
| `TypeScript/` | TypeScript 智能体源码，编译为 `agentSystem.js` 在 goja 中执行 |
| `learner/` | 学习者智能体，通过智能搜索（AgentSearch）执行网络搜索与记忆库检索 |
| `bridging/` | QQ 群聊适配器，NapCat ↔ 月华消息转发 |

**Go 子系统依赖**：`GeneralConfig`、`BrowserClient`、`FileManager`、`LoggerGeneral`、`ImageProcessor`、`AgentSearch`、`Qwen3-TTS`。

## 2. 启动时序

```
main.go
  └── server.InitializeServer()
        ├── LoggerGeneral.SetDevMode()        ← 初始化日志（调试模式）
        ├── registerHandlers()                ← 注册所有 HTTP 路由 + 启动图像任务协处理器
        ├── llama.Init()                      ← 启动 llama-server + 等待就绪（5 分钟超时）
        ├── initTTSEngine()                   ← 初始化 Qwen3-TTS 语音引擎
        ├── websocket.SetupWebSocketHandler() ← 注册 /ws、/ws/studio 端点
        ├── adapters.RunAgentContext()        ← 创建 goja 运行时并执行 agentSystem.js
        └── initBridgeAdapter()               ← 加载 NapCat 桥接配置并启动扫描
  ├── SetupSignalHandling()                   ← 系统信号监听
  ├── StartServerListener()                   ← 端口自动递增重试
  └── WaitForShutdown()                       ← 优雅关闭（系统信号或 WebView 关闭）
```

**优雅关闭顺序**（`server/manage.go`）：关闭 JS agent context → 桥接适配器 → llama.cpp → WebSocket → WebView → `http.Server.Shutdown`。

## 3. Go 后端模块

### 3.1 server/ —— HTTP 服务层

| 文件 | 职责 |
|------|------|
| `manage.go` | 服务器初始化与关闭编排（`InitializeServer` / `shutdownServer`） |
| `create.go` | `http.Server` 创建、端口监听（`:*BasicPort`）、**CORS 中间件** |
| `variable.go` | 路由注册表 SystemEndpoints、全局端点变量 |
| `handlers/message.go` | `/write/message` 消息批处理：追加到 `adapters.UnreadContext` 供智能体消费 |
| `handlers/proxy.go` | 通用代理请求 `/proxy`：构造 HTTP client、转发、JSON 化响应 |
| `handlers/ltpx.go` | LTPX 工具包动态加载 `/ltpx/load`：校验 `name/definition/js` 后调用 `LoadLTPXToolOnLoop` |

**CORS 中间件**（`create.go`）：为所有响应设置 `Access-Control-Allow-Origin/Methods/Headers`，对 `OPTIONS` 预检直接返回 200。

### 3.2 adapters/ —— goja 桥接层

| 文件 | 职责 |
|------|------|
| `create.go` | 创建 goja runtime，注册各适配器函数，执行 `agentSystem.js`，提供 `RunOnAgentLoop` |
| `bridge.go` | 基础桥接工具 |
| `file.go` | `saveFile()` / `readFile()` 文件读写 |
| `knowledge.go` | `knowledge()` 知识库操作 |
| `memory.go` | `memoryQuery()` 向量记忆库查询 |
| `network.go` | `url()` 网络请求 |
| `image.go` | `generateImage()` / `keyframe()` / `resizeImage()` 图像能力 |
| `message.go` | `UnreadContext` 未读消息队列 |
| `narrator.go` | 主演叙述者逻辑 |
| `screenshot.go` | `screenshotCapture()` 截图 |
| `ltpx.go` | LTPX 工具加载（注入 `GlobalConfig.LTPdefinition`，记录 `loadedTools`） |
| `agent-control.go` | 智能体控制 |
| `schedule.go` | 定时调度 |

### 3.3 model/ —— 模型服务层

| 文件 | 职责 |
|------|------|
| `llama/proxy.go` | llama-server 进程管理：构造 llama.cpp 启动参数、启动子进程、监控 stdout/stderr、就绪检测、请求代理 |
| `core.go` | 模型服务核心 |
| `type.go` / `variable.go` | 类型与变量集中管理 |

**llama-server 启动参数**：
```
llama-server.exe --models-preset local_data/models/models.ini \
  --flash-attn on --port <ModelPort> --parallel 1 --batch-size 2048 \
  --ubatch-size 1024 --cache-type-k q8_0 --cache-type-v q8_0 \
  --no-ui --sleep-idle-seconds 900   (# 含温度/采样等生成参数)
```

**模型预设**（`local_data/models/models.ini`）：
- `[system-multimodal]` — 多模态模型（`model` / `mmproj` 路径）
- `[system-embedding]` — 嵌入模型（`model` 路径）

**请求分派**（`proxy.go`）：根据 embedding / 云模型配置分流，否则反向代理到 `localhost:<model port>`。

### 3.4 websocket/ —— 实时通信

| 文件 | 职责 |
|------|------|
| `websocket.go` | `/ws` 升级、客户端注册、读写泵、`BroadcastMessage` 广播 |
| `type.go` / `variable.go` | 连接与消息类型定义 |

**广播流程**：序列化 `WSResponse` → 先 `bridgeToQQ` 转发到 QQ 群聊 → 再逐个发送到在线 WebSocket 客户端。

### 3.5 bridging/ —— QQ 群聊适配器

NapCat ↔ 月华消息转发。配置文件位于 `lunar_config.json` 的 `server` 分组：
- `bridging_type: "napcat"`
- `bridging_path: "ws://localhost:4567"`
- `bridging_token / bridging_target / bridging_keywords`（如「月华」@ 唤醒）

### 3.6 learner/ —— 学习者智能体

通过 `dispatch_learner` 工具接获研究任务后，调用智能搜索模块 `AgentSearch`（`AgentSearch.Search(query)`）统一执行网络搜索与记忆库检索，返回结构化的可读报告（网络搜索结果 / 记忆库查询结果）。报告经工具调用结果通道回传给对话者，不再依赖 `learner*.md` 提示词驱动。

## 4. TypeScript 智能体（编译为 agentSystem.js）

### 4.1 编译链路

```
TypeScript/*.ts → tsc (→ ../deliverable/) → rollup (iife) → hierarchy/assets/agentSystem.js
```

- `package.json`：`release.min` = `tsc && rollup -c`；`server.side` 编译 `TypeScript/index.ts` 并 rollup 为 `agentSystem.js`
- `tsconfig.json`：源目录 `./TypeScript`，仅编译 `./TypeScript/index.ts`

### 4.2 子模块结构与关键类

| 目录 | 关键类 / 函数 | 职责 |

| `control/delay.ts` / `limit.ts` / `plan.ts` | 控制模块 | 延迟、限额、规划控制 |

## 6. HTTP API 与 WebSocket 协议

路由统一注册于 `SystemEndpoints`（[server/variable.go](../../lunar_astral/server/variable.go)）。端到端端点与提供方总览见 [07-依赖关系 §4](07-依赖关系.md)。

### 6.1 HTTP 端点

| 路径 | 方法 | 功能 |
|------|------|------|
| `/v1/` | ANY | 智能体代理接口（转发到 llama.cpp，支持所有 HTTP 方法） |
| `/write/message` | POST | 消息写入队列 |
| `/write/videourl` | POST | 视频 URL 写入 |
| `/generate` / `/generate/wait` | POST / GET | 图像生成 / 等待生成结果 |
| `/extract/keyframes` | POST | 视频关键帧提取 |
| `/tts` | POST | TTS 语音合成 |
| `/memory/` | ANY | 记忆库管理（实例初始化/集合管理/消息增删查） |
| `/knowledge/` | POST | 知识库管理 |
| `/file/...` | 多种 | 文件读写/列表/下载/归档/扩展包管理 |
| `/api/engine/command` | POST | 智能体引擎命令转发 |
| `/proxy` | POST | 代理访问服务 |
| `/ltpx/load` `/ltpx/unload` `/ltpx/status` | POST/POST/GET | LTPX 工具包动态管理 |
| `/ws` | GET | WebSocket 连接升级 |

### 6.2 WebSocket 消息协议

| 消息类型 | `type` 值 | 内容 |
|---------|----------|------|
| 上下文消息 | `context` | AI 对话文本（`type`/`content`/`audio` 字段；子类型含 thinking、response、music、music_audio 等） |
| 图片消息 | `image` | 生成/上传的图片（`images` 数组） |
