## 一、功能介绍

月华（钛宇-月华）是星月智能平台的 AI 桌面智能体核心，负责在你的电脑上陪你聊天与干活。它以本地大模型为大脑，能同时看懂文字、图片和视频，并以语音与画面回应你：把 AI 的回复实时读出来、按你的描述画出图像、在对话里渲染 Markdown 表格、流程图、数据图表与数学公式，还能在你需要时替你联网检索资料。它既能作为独立桌面窗口使用，也能经 QQ 桥接接入群聊，让 AI 参与群内交流。适用于日常问答与闲聊、看图/看视频讨论、语音陪伴、AI 绘画、资料检索，以及把 AI 拉进 QQ 群协作等场景。

---

## 二、使用方法

1. **启动与打开窗口**：运行星月智能主程序后，控制台会自动打开月华前端窗口（标题为「[星月智能] : 钛宇-月华」）。该窗口即对话主界面；关闭窗口不会退出程序，可在控制台重新打开。
2. **文本对话**：在输入框输入文字并发送，月华会按你设定的身份（`agent.user_name`）称呼你并应答，对话历史保存在本地。
3. **图片 / 视频对话**：通过上传或在输入区粘贴，把图片、视频（含多帧动态图）交给月华。它会先描述看到的内容，再据此回应；较长的视频会自动分段解读，默认整文件模式，可切换为图片序列帧模式。
4. **语音朗读**：月华回复会自动合成语音并播放，也可对指定文本触发朗读。语音引擎、音色与语速由 `tts` 配置控制。
5. **文生图**：直接用自然语言描述想要的画面，月华会调用本地扩散模型生成图片并回传；也可提供参考图进行图生图。
6. **网络搜索**：对月华说「帮我查一下……」，它会调用内置网络搜索智能体，用真实浏览器访问搜索引擎与结果页，最后给出带页面操作过程的检索报告。
7. **QQ 群聊接入与唤醒**：在 `bridging` 配置好 NapCat 桥接并重启后，月华即可响应允许的私聊与群聊；当群内出现唤醒关键词（默认如「月华」）时，它会参与该轮对话。

## 三、功能特性

| 特性 | 说明 |
|------|------|
| 多模态对话 | 支持文本、图片、视频（含多帧动态图）混合输入，先理解内容再应答 |
| 实时 TTS | AI 回复自动转语音并播放，可选引擎、参考音频音色、语速等效果 |
| 文生图 | 基于本地扩散模型的文生图与图生图，支持先生成再按需超分 |
| 富文本渲染 | 对话内渲染 Markdown、Mermaid 流程图/时序图、ECharts 图表与 KaTeX 数学公式 |
| 网络搜索 | 由内置网络搜索智能体用真实浏览器检索，人工协作者可介入处理验证码、弹窗 |
| QQ 适配 | 经 NapCat 桥接接入 QQ 私聊与群聊，关键词唤醒后参与对话 |
| 多角色人设 | 提示词定义的人设：对话者、绘制者、演奏者、感知者、行动者、记忆者等 |
| 记忆 | 对话与资料经向量记忆库长期保存，供后续检索与回忆 |
| 统一资源句柄 | 文本/图片/视频/音频共用一套句柄（`@D`/`@I`/`@V`/`@A`），可长期引用、按段落定位 |

## 四、运行参数

月华参数位于 `local_data/lunar_config.json` 与模型预设文件 `local_data/models/models.ini`。以下为常用项，完整参数总表见 [08 构建、运行与配置](08-构建运行与配置.md)。

**身份与模型路由（`agent`）**

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `agent.user_name` | 用户显示名，月华以此称呼你 | 出厂示例「钛宇星光阁」 | 改成你自己的昵称 |
| `agent.multimodal_model` | 对话所用多模态模型，对应 `models.ini` 段名 | `system-multimodal` | 与 `models.ini` 实际段名保持一致 |
| `agent.multimodal_url` | 对话模型服务地址；填云端地址则转发云端 | `http://127.0.0.1:36789/v1` | 本地推理保持默认 |
| `agent.multimodal_key` | 云端模型访问密钥 | 空 | 仅在走云端路由时填写 |
| `agent.embedding_model` / `agent.embedding_url` / `agent.embedding_key` | 嵌入模型（记忆检索）路由 | 本地 `system-embedding` | 本地推理保持默认 |
| `agent.video_input` | 视频解读输入模式：`file`（整文件）或 `frames`（图片序列帧） | `file` | 云端 API 或不支持读本地视频的架构改 `frames` |

**聊天显存守卫（`chat`）**

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `chat.chat_vram_guard` | 聊天显存守卫总开关，可用显存不足时卸载本地模型释放缓存 | `true` | 保持开启 |
| `chat.chat_vram_guard_mib` | 触发守卫的可用显存阈值（MiB） | `1024` | 显存紧张时可上调 |
| `chat.chat_vram_guard_interval` | 守卫检查间隔 | `16` | 保持默认 |

**语音合成（`tts`）**

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `tts.engine` | 语音引擎：`Qwen` / `Kokoro` / `OmniVoice` | `Qwen` | 按机器性能选择 |
| `tts.ref_audio` | 参考音频路径（音色来源） | `./local_data/audios/lunar-template.wav` | 换音色即替换该文件 |
| `tts.voice` | 音色名（部分引擎可用） | 空 | 参考引擎的音色列表 |
| `tts.speed` | 语速倍率 | `1` | 在 0.8~1.2 之间微调 |
| `tts.seed` | 随机种子 | `0`（随机） | 需复现同一语音时固定 |
| `tts.disable_postproc` | 关闭音频后处理 | `false` | 保持默认 |
| `tts.idle_unload_minutes` | 空闲多久后卸载语音引擎（分钟） | `5` | 省显存可调小 |

**QQ 桥接（`bridging`）**

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `bridging.bridging_type` | 桥接类型，`napcat` 时启用 | `napcat` | 不使用 QQ 时不配置 |
| `bridging.bridging_path` | NapCat 的 WebSocket 地址 | `ws://localhost:4567` | 与 NapCat 配置一致 |
| `bridging.bridging_token` | 桥接鉴权令牌 | 空 | 与 NapCat 保持完全一致 |
| `bridging.bridging_users` | 允许私聊的用户 ID / 允许响应的群号列表 | 出厂示例若干 | 只填你希望 AI 参与的账号与群 |
| `bridging.bridging_group_keywords` | 群聊唤醒关键词 | 出厂示例「月华」 | 改成你习惯的唤醒词 |
| `bridging.bridging_group_trigger_probability` | 关键词命中之外的随机触发概率 | `0.3` | 想少被打扰就调低 |

**模型预设（`models.ini`）**

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `[system-multimodal]` | 多模态对话模型段（`model` 主模型 / `mmproj` 视觉投影） | 出厂已配 | 切换语言/视觉模型时改此段 |
| `[system-embedding]` | 嵌入模型段（`model`，`embeddings = true`） | 出厂已配 | 记忆检索用，一般不常改 |

> llama-server 的完整启动参数见 [10 llama.cpp 参数参考](10-llama.cpp-参数参考.md)；图像生成的尺寸/步数/采样器等策略见 [12 图像生成参数策略](12-图像生成参数策略.md)。

## 五、常见排故

| 现象 | 可能原因 | 处理办法 |
|------|----------|----------|
| 切换模型后对话仍走旧模型 | 模型文件未放入、`models.ini` 段路径未改或未重启 | 将 GGUF 模型放入 `local_data/models/`，编辑 `models.ini` 对应段后重启程序 |
| llama-server 启动失败、对话无响应 | 引擎可执行文件缺失、模型路径错误、端口被占用 | 确认引擎可执行文件与模型路径正确，释放模型端口，查看控制台 llama 日志 |
| TTS 无声或音色不对 | 参考音频不存在、引擎库未就绪、音色参数不适用 | 确认 `tts.ref_audio` 指向存在的音频文件，确认引擎库已就绪，必要时更换引擎或音色 |
| 文生图失败或显存不足 | 未开启扩散、尺寸过大、显存预算不足 | 确认 `diffusion.allow_diffusion` 为真；下调尺寸、开启显存守卫，参考 [12](12-图像生成参数策略.md) |
| 程序退出或窗口打不开（端口占用） | 月华默认端口（月华 36789 / 模型 36790）被占用 | 用启动参数 `-basic-port` 指定其它基础端口后重启，或先释放被占用端口 |
| 前端窗口无法加载界面 | WebView2 运行库缺失、窗口地址不可达 | 安装 WebView2 Runtime；确认月华服务已在本机端口正常运行 |
