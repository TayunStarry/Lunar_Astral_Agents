# 14 图片标签、文件引用与多模态窗口使用手册

> [🏠 手册门户](README.md) ｜ [◀ 上一模块](13-控制台TUI系统.md)

月华在对话中需要稳定地引用两类内容：**图片**用图片标签 `[图片.00x]`，**文本文件**用文件引用标签 `(#文件名.ext):`；多模态窗口负责管理图片的可见范围。本手册说明两者的注入与引用方式。

---

## 一、功能介绍

图片标签体系让月华在对话中稳定地引用每一张图片，文件引用标签体系让它稳定地引用每一份已导入的文本文件，多模态窗口则负责管理图片的可见范围。两套标签解决的问题一致——让模型在多轮对话里**认得并引用**同一份内容，无需重复上传。

- **图片标签 `[图片.00x]`**：每张进入对话的图片得到一个唯一标签，之后用该标签指代这张图。
- **文件引用标签 `(#文件名.ext):`**：每份被导入的文本文件以 `#文件名.ext` 为句柄；在消息里写出该引用，月华便会去该文件的内容里检索后再回答。
- **QQ 与本地共用一套编号**：从 QQ 合并转发进入的图片与对话上下文中的图片共用同一套图片标签空间；文本文件同样会被打包为可登记的引用块。
- **窗口内外闭环（图片）**：图片在窗口内时模型能同时看到真图与标签；离开窗口后自动降级为带描述的文字占位，引用不中断。
- **可复现的引用**：图片标签在同一次运行内有效，方便你在后续消息、工具调用与绘图请求里持续指向同一张图。

## 二、使用方法

### 2.1 向对话注入图片

1. 在对话中直接发送图片消息即可；系统会自动为图片登记标签，并在图片后附上裸标签文本（形如 `[图片.00x]`）作为可寻址句柄。
2. 从 QQ 合并转发进入的图片由系统自动登记标签，标签直接内嵌在转发正文里。
3. 工具（如截图）返回的图片同样会登记标签并附上旁注，窗口期内可按标签引用。

### 2.2 向对话导入并引用文本文件

1. **导入文件**：在对话中发送或导入文本类文件（Markdown、纯文本、JSON 以及主流编程语言源码等）。系统会解析文件内容并建立可检索的副本，随后推送一条通知 `[文件已导入] #文件名.ext`。
2. **载入引用**：点击消息里出现的文件图标（或通知中的引用），即可把该引用载入输入框上方，作为本次提问的引用。
3. **组合提问**：在引用之后写上你的问题（例如「这份配置该怎么改？」）。发送时，系统会把引用规范化为 `(#文件名.ext):` 前缀拼在你的文本之前。
4. **去重与移除**：同一引用重复载入会自动去重；不需要时可在输入框上方的图标条里单独移除。

> 仅受支持的文本类文件会被登记为引用；其它类型按普通文本呈现，不参与引用。

### 2.3 在对话中引用标签

- **引用图片**：想再次指向某张已发过的图片时，直接在消息里写入它的图片标签 `[图片.00x]`。
- **引用文件**：想就某份已导入的文件提问时，写入它的引用 `(#文件名.ext):`，并在其后写上具体问题。
- **有效期**：图片标签只在本次运行内有效，取不到即表示该图已过期，改用仍存在的标签；文件引用若指向未导入的文件，会被保留原样，需重新导入。
- 不要自己编造标签或文件名，只使用消息里真实出现过的引用。

### 2.4 在多模态窗口中查看与管理图片

- 查看可用图片：让月华列出当前可用标签（标签 / 描述 / 是否仍在窗口内），用于确认标签是否有效、定位目标图片。
- 查看图片内容摘要：按标签获取某张图的内容描述；占位文本里已有描述时通常无需获取，需要细节时可带针对性提问。
- 图片超分：按标签（或最近作品）对已有图片做超分辨率放大。
- 窗口范围：模型只能看到最近 20 张图片本身，更早的只以文字占位出现。

### 2.5 用图片作为绘图参考

1. 在含图消息里说明绘图意图（例如「把这张图改成雪景」），并指定要参考的图片标签。
2. 系统把该标签对应的源图准备为本次创作的参考图，并交给绘制者执行图生图。
3. 参考图是任务级状态：每次创作开工时重新绑定，不会跨任务沿用旧图。
4. 输出尺寸随参考图比例自动推导；改画风 / 换场景 / 大改构图的强度由绘制者按意图选择。

## 三、功能特性

| 特性 | 说明 |
|------|------|
| 图片标签命名 | 形式为 `[图片.00x]`，全局唯一且单调递增；序号超过 999 自然变为四位 |
| 文件引用命名 | 句柄为 `#文件名.ext`，正文书写格式为 `(#文件名.ext):`；仅识别带 `#` 的引用 |
| 文件导入登记 | 受支持的文本类文件被解析后建立可检索副本，并推送 `[文件已导入] #文件名.ext` 通知 |
| 文件引用查询 | 月华按引用之后的提问文本，在对应文件内容里检索并整理后再回答 |
| 引用载入与去重 | 点击消息中的文件图标即可把引用载入输入框；重复载入自动去重，可单独移除 |
| 占位描述（图片） | 图片离开窗口后降级为 `[图片.00x]（描述）`；描述为空时退化为纯标签，不写噪声文字 |
| 描述来源（图片） | 优先复用缓存中已有描述；没有时由视觉模型现场生成一句不超过 20 字的中文描述；取不到则留空 |
| 多模态窗口展示 | 模型直接看到最近 20 张图片本身；更早的以占位文本形式出现 |
| 图片缓存与共享 | 缓存容量 80、钉住上限 30；窗口内的图片被钉住防止淘汰 |
| 缓存不落盘 | 进程重启后图片编号从 1 重新开始，同一字面标签可能指向另一张图 |
| 图生图参考 | 按标签把缓存源图准备为图生图基座，输出尺寸随参考图比例推导，参考图属任务级状态 |
| 图片超分辨率 | 按标签或最近作品对已有图片放大 |

## 四、运行参数

图片标签与文件引用本身无需配置参数；与图片、多模态相关的配置项如下：

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `video_input` | 视频解读的输入方式：`file`（写入媒体目录后引用）或 `frames`（本地抽帧为图片序列） | file | 目标模型不支持本地文件引用时改用 frames |
| 多模态模型路由 | 多模态模型名称 / 服务地址 / 密钥 | 本地同源服务 | 需指向其它服务时修改 |

与图片、多模态相关的其余配置字段与含义见 [08-构建运行与配置](08-构建运行与配置.md)；标签与窗口的运行机制细节见 [02-核心系统-钛宇-月华](02-核心系统-钛宇-月华.md)。

## 五、常见排故

| 现象 | 可能原因 | 处理办法 |
|------|----------|----------|
| 图片不显示 | 源图地址失效、图片格式不受支持，或图片已超出窗口范围 | 重新发送图片获取新标签；确认格式受支持；确认该图仍在最近 20 张内 |
| 图片标签引用失效 | 标签只在本次运行内有效，或对应条目已被淘汰 | 列出当前可用标签并改用仍存在的标签 |
| 文件引用失效 | 该文件未被导入登记，或引用名称与真实文件名不符 | 重新导入文件，并使用通知里给出的准确引用名 |
| 点击文件图标无反应 | 引用不是有效句柄，或该条目未被登记 | 重新导入文件，用新生成的引用 |
| 引用文件后答非所问 | 文件未成功登记，或提问与文件内容不相关 | 确认已出现 `[文件已导入]` 通知；把问题写得更具体 |
| 导入文件内容不全 | 文本文件超过单次导入上限被截断 | 拆分文件后分别导入 |
| 动态图不能播放 | 动态图（GIF / APNG / 动态 WebP）在对话中按静态帧处理，窗口内不做动画播放 | 如需逐帧理解，改用序列帧输入方式；或转成静态图后发送 |
| 视频理解失败 | 输入方式与目标模型能力不匹配 | 把 `video_input` 在 file 与 frames 之间切换后重试 |
| 图片描述缺失 | 来源地址为空，或视觉模型调用失败 / 返回空 | 重新发送图片；或按标签发起一次描述请求 |
| 缓存占用过大 | 图片缓存不落盘且容量有限，历史图片会占用条目 | 无需手动清理；超限时系统自动淘汰最旧的未钉住条目；长期引用请改用文字描述 |
