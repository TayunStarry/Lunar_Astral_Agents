# 03 扩展系统——星图·琉璃（crystal_astral）

> [🏠 文档地图](README.md) | [◀ 上一章](02-核心系统-星图月华.md) | [下一章 ▶](04-公共子系统.md)
> 相关源文档：[crystal_astral/README.md](../../crystal_astral/README.md)

工具集扩展系统，以下游工具界面（文件管理 / 知识库 / 记忆库 / 截图标注 / AI 代理转发）服务用户。AI 请求经**智能路由**代理到月华后端（`localhost:36789`）。

---

## 1. 目录总览

| 文件 | 职责 |
|------|------|
| `main.go` | 程序入口：解析参数、生成 10000~40000 随机端口、调用 `StartServer` |
| `create.go` | 服务器创建：路由注册 + `proxyAwareHandler` 代理感知路由 |
| `handler.go` | 代理转发、GGUF 元数据解析、图片转换、月华服务启停 |
| `gguf.go` | GGUF 模型文件解析 |
| `convert.go` | 图片格式转换（单张/批量/列表） |
| `ws.go` | StudioHub WebSocket 集线器 + 引擎命令桥接 |
| `type.go` | 请求/响应类型定义 |
| `variable.go` | 全局变量 + `SystemEndpoints` 路由表 |
| `assets/` | 前端静态资源（毛玻璃风格 UI） |

**Go 子系统依赖**：`GeneralConfig`、`BrowserClient`、`FileManager`、`ImageProcessor`、`LoggerGeneral`。

---

## 2. 启动与路由

### 2.1 启动流程（main.go / create.go）

```
main.go
  └── 解析参数 → 随机端口(10000~40000) → StartServer
        ├── 初始化记忆库
        ├── 初始化图像任务处理器
        ├── StudioHub 集线器
        ├── 注册 /ws 与 SystemEndpoints
        └── proxyAwareHandler 包裹静态文件服务（代理感知路由）
```

### 2.2 代理感知路由（create.go / variable.go）

`proxyAwareHandler.ServeHTTP` 依据 `shouldProxy(path)` 决定转发给反向代理（`getProxyHandler` → `http://localhost:36789`）还是本地静态文件服务。

**需代理的路径前缀**（`variable.go`）：`/v1/`、`/write/message`、`/tts`、`/generate` 等。

---

## 3. 关键模块与函数

### 3.1 handler.go —— 代理转发与工具

| 函数 | 职责 |
|------|------|
| `getProxyHandler` | 配置反向代理，目标 `http://localhost:36789`（月华 llama-proxy） |
| `yuehuaCheckHandler` | 检测 `127.0.0.1:36789` 是否可用（月华存活检测） |
| `yuehuaStartHandler` | 启动 `Lunar_Astral.exe`（拉起月华服务） |
| GGUF 元数据解析 | 解析 GGUF 模型文件头部信息 |
| 图片转换 | 委托 convert.go 的图片格式转换 |

### 3.2 gguf.go —— GGUF 模型解析

Parse GGUF 模型文件，读取文件头、张量信息与可用的元数据字段，供模型浏览/测试。

### 3.3 convert.go —— 图片格式转换

支持单张 / 批量 / 列表三种模式的图片格式转换。

### 3.4 ws.go —— WebSocket 集线器

- **StudioHub**：主循环处理客户端注册、注销与广播（引擎命令桥接核心）。
- **WebSocket 升级与读写协程**：`/ws` 客户端连接被注册并广播。
- **StudioEngineHandler**：`/write/engine` 将引擎命令广播给所有本地 WebSocket 客户端。

### 3.5 前端 assets/

基于原生 HTML/CSS/JavaScript 的毛玻璃风格 UI，提供各工具面板界面。AI 请求经前端 `ws_bridge.js` / Http proxy 转发至月华。

---

## 4. 运行

编译产物 `Crystal_Astral.exe`；启动时随机选择端口，可被 `browser_client` 打开嵌入 WebView 窗口。通过智能路由将 `/v1/` 等 AI 请求转发至月华后端，同时直接服务文件/知识库/记忆库/截图等工具界面。
