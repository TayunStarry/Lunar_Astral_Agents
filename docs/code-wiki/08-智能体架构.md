## 一、这是什么

星月智能不是「一个万能模型」，而是**一组各司其职的智能体**。月华负责理解与表达，琉璃负责工具与承载，其余智能体各自处理检索、看图、读文档、修故障、刷视频等专项任务。

它们共享同一套本地模型服务，但各自有不同的提示词、工具和运行节奏。你只需要用自然语言提要求，由月华判断该交给谁做。

---

## 二、核心用途

- **分工**：把「说、画、唱、看、查、修」拆开，各自把一件事做好。
- **稳定**：专项智能体有固定的输入输出与超时，比让一个模型包办更可控。
- **可观测**：每个智能体都有独立的日志与上下文，可导出排查。
- **可扩展**：新增能力优先做成智能体或扩展包，不动核心对话链。

---

## 三、两位主智能体

### 3.1 月华（核心人格）

月华是与你直接对话的智能体，内部按角色拆分：

| 角色 | 负责 |
|------|------|
| 对话者 | 理解意图、调度工具、生成回复 |
| 绘制者 | 文生图、图生图、角色立绘、合照、超分 |
| 演奏者 | 歌曲生成、风格编排、音频产出 |
| 截图者 | 截取屏幕、识别区域并回传图片 |

记忆的入库与检索不是独立角色，而是后端流程，通过对话者的「回忆」类工具暴露。

### 3.2 琉璃（工具与承载）

琉璃是工具集扩展系统，负责：

- 桌面面板与扩展包加载；
- 文件管理、知识库、记忆库、截图标注等工具界面；
- 扩展包安装、导出、删除；
- 需要调用模型时，经统一端点转发给本地模型服务。

琉璃与月华共用同一个服务端口，琉璃桌面挂在 `/desktop/` 路径下。

## 四、专项智能体

| 智能体 | 职责 | 你怎么用到它 |
|--------|------|--------------|
| 响应者 | 承接外部推理请求，在主调度空档期依次处理 | 自动运行，无需操作 |
| 后勤修复 | 处理可自动修复的故障 | 自动运行，日志可见 |
| 网络搜索 | 真实浏览器检索与摘要 | 说「帮我查一下……」 |
| 视觉理解 | 看图、动图、视频切片 | 发图 / 发视频 |
| 文献解析 | 大文件轻量扫描与分片摘要 | 发大文档并提问 |
| 归档解析 | 压缩包结构、条目、模型元数据 | 发 zip / 7z 并提问 |
| 归档操作 | 创建、删除、新增、移除压缩包条目 | 说「把这个文件打进压缩包」 |
| 创作 | 生活事件中的写作与脚本创作 | 生活自动触发 |
| 文件编辑 | 自然语言驱动的文件读写、检索、置换、运行 | 说「把 a.md 第 2 行改成……」 |
| 哔哩观影 | 选片、观看、评论、写日记 | 说「去看看视频」 |
| 桌面操纵 | 理解界面并代为操作桌面程序 | 仅控制台人工启动 |
| 通讯桥接 | QQ 私聊与群聊接入 | 配置 NapCat 后自动连接 |
| 互助论坛 | 论坛浏览、发帖与互动 | 说「去论坛逛逛」 |
| 扩展包智能体 | 由扩展包自带的页面智能体 | 安装带智能体的包后直接调用 |

### 4.1 桌面操纵为什么不能直接叫

桌面操纵会真实移动鼠标、敲键盘，风险高于其它能力。因此它**不对月华工具链暴露**，只能在控制台「运行状态」屏人工启停；月华开始应答时会自动终止它，避免抢占桌面。

### 4.2 外部调用怎么接

外部程序或前端需要模型能力时，统一走两个端点：

| 端点 | 用途 |
|------|------|
| `/agent/chat/completions` | 多模态对话（非流式，模型名固定） |
| `/agent/embeddings` | 文本嵌入（模型名固定） |

调用方不能自选模型；请求由响应者智能体排队，在主调度空档期依次处理，避免与对话链抢显存。

## 五、私有脚本运行时

文件编辑与创作链需要执行脚本时，会在一个独立的 JavaScript 沙箱里运行：

- **入口约定**：脚本首行写 `//Engine: Lunar Harness`，并以 `exportFunction('main', main)` 注册入口；
- **可选能力**：`console`、定时器、`fetch` / `WebSocket`、`file`、`image`（读图 / 缩放 / 转码）、`video`（抽帧）、`memory`、`database`（单一共享库）、`encoding`、`hash`、`agent`（对话 / 搜索）、`http.download`（把远端文件落盘）；
- **运行时长**：默认 120 秒，可在调用时或首行用 `timeout=` 指定，范围 5~3600 秒；
- **隔离**：脚本只能读写自己的数据目录，越界路径会被拒绝；
- **用不到的能力不暴露**：该运行时没有权限清单、没有事件订阅、没有跨包调用，只保留单文件脚本实际用得上的能力。

类型声明按能力拆成多份随程序分发，AI 写脚本时会按需查阅对应模块，而不是一次读完全部。

## 六、观测与排障

| 入口 | 内容 |
|------|------|
| 控制台「推理实况」 | 思考、输出、工具调用的流式显示 |
| 控制台「系统日志」 | 原始 / 警告 / 绘图 / 对话 / 生活 / 后勤分类日志 |
| 控制台「工具列表」 | 扫描并展示全部智能体的工具与说明 |
| 控制台「数据导出」 | 导出原始日志、推理实况、各智能体上下文 |
| 琉璃桌面「配置」 | 查看分组配置 |

## 七、常见问题

| 现象 | 可能原因 | 处理办法 |
|------|----------|----------|
| 月华不回应但界面正常 | 模型服务未就绪、上下文异常，或外部请求占满队列 | 查看「系统日志 · 警告」与「对话」分类；确认模型服务在运行 |
| 某个专项能力没反应 | 对应智能体初始化失败，或前置条件不满足（未登录、未安装组件） | 查看对应分类日志，按提示补齐条件 |
| 想让月华操作桌面 | 桌面操纵不对外暴露 | 在控制台「运行状态」屏人工启停 |
| 外部程序调用报错 | 端点或模型名写错；或请求了流式 | 改用 `/agent/chat/completions`，不要指定模型名与 `stream` |
| 脚本运行超时 | 脚本执行超过运行时长 | 调大 `timeout`，或拆分任务 |
| 脚本读写文件被拒 | 路径越出沙箱数据目录 | 使用相对路径，只在自己目录内读写 |
