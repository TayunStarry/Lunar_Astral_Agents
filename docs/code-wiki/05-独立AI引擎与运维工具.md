## 5.1 agent_search —— 智能网络检索

`subsystem/agent_search/`。AI 驱动的网络搜索智能体：多引擎搜索 → 页面提取 → AI 摘要 → 记忆存储。

### 5 阶段流水线

| 阶段 | 说明 |
|------|------|
| Phase 1 记忆检索 | 查向量记忆库，AI 判定历史答案能否复用（新闻/天气强制走网络） |
| Phase 1.5 模式判定 | AI 决定「快速视觉搜索（纯截图）」还是「深度文本搜索」 |
| Phase 2 初始搜索 | AI 生成关键词 → 多引擎降级链（Bing→百度→搜狗）→ DOM 清洗 + 分页截图 → AI 摘要 |
| Phase 2.5+3 深度搜索 | 多轮补充搜索，嵌入向量去重（余弦相似度 > 0.85 拒绝），AI 评估充分性 |
| Phase 4 报告生成 | AI 整合摘要生成结构化报告 |
| Phase 5 记忆存储 | 结果以自然语言文本存入 `search_memory` 集合 |

### 关键文件与函数

| 文件 | 关键函数 | 职责 |
|------|------|------|
| `agent.go` | `InitSearch` / `Search` / `executeSearchPipeline` / `executeQuickSearchPipeline` / `ensureBrowserHealthy` | 主控编排（各 phase 函数） |
| `ai.go` | `callAI` / `callChatAPI` / `callEmbedding` / `generateKeywords` / `summarizeContent` / `judgeMemory` / `decideSearchMode` / `evaluateSufficiency` / `generateReport` | OpenAI 兼容 API 调用与各 AI 决策 |
| `browser.go` | `LaunchBrowser` / `CloseBrowser` / `executeSearch` / `parseBingResults` / `parseBaiduResults` / `parseSogouResults` / `ExtractPageContent` / `cleanDOMText` | Chromedp 浏览器控制与页面解析 |
| `memory.go` | `initMemoryCollection` / `lookupMemory` / `storeMemoryRecord` | 向量记忆库读写 |
| `monitor.go` | `monitorBrowserHealth` / `isCPUSustainedHigh` | 浏览器健康监控（gopsutil） |
| `screenshot.go` | `CapturePageScreenshots` | 页面截图 |
| `config.go` | `DefaultSearchConfig` / `ValidateSearchConfig` | 搜索配置 |

### 依赖

- 本地：`FileManager`、`GeneralConfig`、`LoggerGeneral`
- 外部：`chromedp v0.16.0`（浏览器）、`shirou/gopsutil/v3`（进程监控）、`golang.org/x/net`、`mattn/go-sqlite3`
- 测试入口：`cmd/search_test/`、`cmd/browser_test/`

## 5.2 qwen3_tts —— 语音合成

`subsystem/qwen3_tts/`。全本地化 Qwen3-TTS 引擎，三层异构架构：**Go HTTP 服务层 → C++ 推理引擎（DLL）→ GGML 张量计算库（多 GPU 后端）**。支持音色克隆（参考音频）与 LRU + singleflight 音频缓存。

### 推理管线

```
text_tokenizer (GPT-2 BPE 分词)
  → tts_transformer (Encoder + Cross-Attention)
  → audio_tokenizer_decoder (latent → PCM float32)
  → WAV 封装
```

### 关键文件与函数（Go 层）

| 文件 | 关键函数 | 职责 |
|------|------|------|
| `main.go` | — | 入口：读 `GeneralConfig` 端口/模型目录/参考音频，`InitTTSEngine` + `startServer` |
| `server.go` | `registerHandlers` / `startServer` / `waitForServerReady` | 注册 `/tts`、`/upload/`、`/health`，优雅关闭 |
| `module/generate.go` | `InitTTSEngine` / `SynthesizeText` / `EncodePCMToWAV` / `getOrExtractEmbedding` / `synthesizeWithCache` / `TTSHandler` | CGO 绑定 + TTS 合成 |
| `module/cache.go` | `NewTTSCache` / `ComputeCacheKey` / `GetOrCreateInflight` | LRU 缓存 + singleflight 防击穿 |
| `module/variable.go` | `ttsCache`（容量 64）/ `embedCache` | 全局状态 |
| `module/type.go` | `TTSCache` / `InflightCall` / `TTSEngine` | 类型定义 |

### C++ 引擎（cpp/src/）

- `qwen3tts_c_api.cpp/h`：C API 层，导出 `qwen3_tts_create`、`qwen3_tts_synthesize_with_embedding`、`qwen3_tts_extract_embedding_file`、`qwen3_tts_synthesize_streaming*` 等
- `tts_transformer` / `audio_tokenizer_encoder|decoder` / `gguf_loader` / `text_tokenizer`
- `cpp/ggml/`：完整 GGML 库（CUDA/Vulkan/Metal/SYCL/OpenCL/BLAS 多后端）

### 端

默认端口 `36789`（与月华 llama-proxy 同端口，TTS 作为同一服务暴露 `/tts`）。端点：`/tts`、`/upload/`、`/health`。

### 构建

`build.ps1` 3 阶段：Stage 1 `build_ggml.ps1`（编 GGML）→ Stage 2 `build_cpp.ps1`（编 C++ DLL，默认 `EnableVulkan=true`）→ Stage 3 `CGO_ENABLED=1` 编 Go。产物 `Qwen3_TTS_Lunar.exe` + `qwen3tts.dll`。可 `-SkipGGML/-SkipCPP/-SkipGo/-Clean` 分段。

## 5.3 qwen_asr —— 语音识别

`subsystem/qwen_asr/`。全本地化 Qwen3-ASR 引擎，**纯 C 推理引擎 + Go HTTP 服务 + WebView 前端**。支持 30 种语言、0.6B/1.7B 双模型自动检测、BF16 零拷贝权重、SIMD 加速（AVX2/AVX-512/NEON）。

### 推理管线

```
qwen_load_wav → qwen_mel_spectrogram (STFT + Mel filterbank)
  → qwen_encoder_forward (Conv2D Stem + 窗口注意力 Transformer)
  → 构建 ChatML prompt → qwen_asr_decoder 自回归解码 → BPE 分词器输出文本
```

### 关键文件与函数

| 文件 | 职责 |
|------|------|
| `main.go` | 入口：`New()` 初始化引擎、`NewAsrHandler()`、HTTP + BrowserClient WebView（648×960） |
| `asr.go` | CGO 桥接：`New`（`qwen_load`）/ `Close`（`qwen_free`）/ `TranscribeWavFile` / `TranscribeAudioBuffer` / `SetLanguage` / `SetPrompt` / `SupportedLanguages` |
| `handler.go` | `/asr`（32MB 上限，非 WAV 用 FFmpeg 转 16kHz/16bit/mono）、`/health`、`estimateConfidence` |
| C 引擎 | `qwen_asr.h/c`（`qwen_load/transcribe/transcribe_audio`）、`qwen_asr_audio.c`、`qwen_asr_encoder.c`、`qwen_asr_decoder.c`、`qwen_asr_tokenizer.h/c`、`qwen_asr_safetensors.h/c`（多分片 + mmap） |
| 内核 | `qwen_asr_kernels.c` + SIMD 分派（`_avx.c` / `_neon.c` / `_generic.c`）：`qwen_bf16_matvec_fused`、`qwen_argmax_bf16_range`、`qwen_causal_attention` 等 |

### 依赖 / 构建

- 本地：`BrowserClient`、`GeneralConfig`、`LoggerGeneral`；外部：`webview_go`、OpenBLAS（可选 `-DUSE_BLAS -fopenmp`）
- `build.ps1`：`CGO_ENABLED=1 -O3 -march=native -ffast-math` → `Qwen_ASR_Lunar.exe`
- 运行时环境变量：`PORT`、`QWEN_VERBOSE`、`QWEN_BF16_CACHE_MB`

## 5.4 environment_repair —— 运维工具箱

`subsystem/environment_repair/`。交互式终端菜单（1~5），四项功能。

### 功能与关键文件

| 功能 | 文件 / 函数 | 说明 |
|------|------|------|
| ① 资源补全修复 | `repair.go` `EnsureLocalData()` | `//go:embed embedded_data/*` 释放 audios/images/package 到 local_data，仅补缺失不覆盖 |
| ② 端口占用释放 | `release.go` `ExecutePortRelease()` 等 | PowerShell `Get-NetTCPConnection` 优先，回退 `netstat`；`taskkill /f` 终止；`verifyPorts` 验证 |
| ③ HTTPS 代理 | `proxy.go` `RunHTTPSProxy()` / `handleProxyRequest()` / `handleWebSocketProxy()` | HTTP 用 `httputil.NewSingleHostReverseProxy`；WS 走 TCP 隧道双向转发；自签名 RSA-2048 证书（含 SAN）持久化复用 + `corsMiddleware` |
| ④ 分卷打包归档 | `package.go` + `component/` | 列出 JSON 配置 → 加载 → 确认 → 7z 分卷 |

### component/ 子模块（分卷打包）

| 文件 | 职责 |
|------|------|
| `config.go` / `config_loader.go` | 打包配置结构与加载（`ArchiveConfig`：Import/Exclude/Archive/Output/Size/Level；排除规则支持 `*.ext`/`node_modules`) |
| `execute.go` / `create.go` | 主流程 + `createVolume`（7z -v{size}m -mx{level}） |
| `check.go` / `clean.go` | `find7zPath` 检测 / `cleanOldParts` 清理旧分卷 |
| `progress.go` | 解析 7z 输出渲染彩色进度条 |
| `source.go` / `utils.go` | 源路径处理 |

### 依赖 / 构建

- 依赖：`GeneralConfig`；外部工具：**7z（必需）**、rsrc、powershell/netstat/taskkill
- `build.ps1`：先 `Sync-EmbeddedData`（从 local_data 同步到 `embedded_data/`，确保 go:embed 生效），`CGO_ENABLED=1`，产物 `Environment_Repair.exe`（CLI 不隐藏控制台）
