# 05 引擎与运维工具手册

> [🏠 手册门户](README.md) ｜ [◀ 上一模块](04-公共子系统.md) ｜ [下一模块 ▶](06-前端资源库.md)

## 一、功能介绍

独立 AI 引擎与运维工具包含四项能力，它们既可独立运行，也可被主程序挂载使用：语音合成引擎负责把文字合成为自然语音；语音识别引擎负责把音频转写为文字；智能网络检索负责从互联网获取并理解实时信息；运维工具箱负责部署与排障中的资源补全、端口释放、代理与打包。四者分别补齐月华与琉璃在「说、听、查、修」上的能力，其中语音合成与识别直接服务于语音交互，网络检索用于获取实时信息，运维工具箱用于环境维护。

## 二、使用方法

**语音合成的启用与音色设置**

1. 将语音合成的 GGUF 模型放入 `{LocalDir}/models/Qwen3-TTS/`。
2. 在 `lunar_config.json` 的 `tts` 分组中设置引擎、参考音频、音色、语速、语言等参数。
3. 需要克隆音色时，准备一段 5–15 秒、16kHz 或 24kHz、单声道、PCM WAV 格式的参考音频。
4. 主程序会直接挂载语音合成能力并提供文本转语音；独立形态下启动程序后同样可通过其接口合成语音。

**语音识别的调用入口**

1. 独立程序：启动后自动打开窗口，可上传音频文件或使用浏览器录音，转写结果在窗口中展示。
2. 内嵌形态：琉璃内置同一识别引擎，向其接口提交音频即可获得转写文本。
3. 提交音频推荐使用 16kHz、16-bit、单声道、PCM WAV 格式，其它格式会自动转码。

**独立网络检索工具的启动**

1. 该工具是可独立编译的子系统，自带检索测试入口，当前无宿主接入。
2. 在检索测试入口直接运行即可发起一次检索并查看生成的报告。
3. 宿主侧的网络检索由琉璃内置的网页检索智能体承担，其真实浏览器链路支持人工介入（过人机验证、关闭弹窗广告）。

**运维工具箱的使用步骤**

1. 启动运维工具箱后会出现交互式菜单，用数字键选择功能。
2. 资源补全修复：释放内嵌资源中缺失的本地数据文件（仅补缺失、不覆盖已有文件）。
3. 端口占用释放：扫描并终止占用端口的进程，并自动验证释放结果。
4. HTTPS 代理服务：启动 HTTPS 到 HTTP 的反向代理，自动生成并复用 TLS 证书。
5. 分卷打包归档：按配置把指定目录打包为 7z 分卷压缩包，可用 7z 工具解压还原。
6. 选择退出以结束程序。

## 三、功能特性

| 特性 | 说明 |
|------|------|
| 语音合成引擎 | 全本地 Qwen3-TTS，支持 GGML 多 GPU 后端（CUDA/Vulkan 等）、音色克隆与音频缓存复用 |
| 统一效果参数 | 引擎、音色、参考音频、语速、语言、风格等各引擎共用的合成参数，不支持的参数自动忽略 |
| 语音识别引擎 | 全本地 Qwen3-ASR，支持多种语言、双模型规模自动检测与 SIMD 加速 |
| 网络检索流水线 | 多搜索引擎、页面内容提取、AI 摘要与相关性判定、报告生成与向量记忆存储 |
| 检索健康监控 | 监控浏览器资源占用，异常时自动重启浏览器 |
| 运维修复能力 | 资源补全、端口释放、HTTPS 代理与分卷打包四类维护功能 |

## 四、运行参数

**语音合成参数（`tts` 分组）**

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `tts.engine` | 使用的语音合成引擎 | Qwen | 按可用引擎选择 |
| `tts.ref_audio` | 音色克隆的参考音频路径 | `{LocalDir}/audios/lunar-template.wav` | 使用 5–15 秒清晰的单声道 WAV |
| `tts.ref_text` | 参考音频对应的文本 | 空 | 有则填写，有助于提升克隆效果 |
| `tts.voice` | 预设音色 | 空 | 不克隆音色时选择预设音色 |
| `tts.mix` | 多个音色的混合比例 | 空 | 需要合成混合音色时设置 |
| `tts.speed` | 语速 | 空 | 按听感调整 |
| `tts.lang` | 合成语言 | 空 | 与文本语言保持一致 |
| `tts.instruct` | 风格或情感指令 | 空 | 需要特定语气时设置 |
| `tts.seed` | 随机种子 | 空 | 固定种子可复现合成结果 |
| `tts.disable_postproc` | 是否关闭音频后处理 | `false` | 一般保持默认 |
| `tts.idle_unload_minutes` | 空闲多久后卸载合成引擎 | `5` | 显存紧张时调小 |

**语音识别**

语音识别由统一的模型服务承载（模型预设 `audio_transcriber`），不再由独立程序监听端口，因此没有独立的端口与缓存环境变量。

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| 识别模型名称（`-agent-asr-model`） | 使用的语音识别模型预设名 | `audio_transcriber` | 更换识别模型时修改 |
| 识别模型路径（`-asr-model`） | 识别模型所在目录 | 本地 Qwen3-ASR 目录 | 模型放到别处时修改 |

**检索与运维工具的可调项**

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| 检索模型路由 | 检索所用嵌入与多模态模型的名称及接口地址 | 同源本地 v1 端点 | 可独立指向其它服务 |
| 检索行为参数 | 每轮结果数、单页截图数、相似度阈值、单页超时等 | 见程序默认 | 按检索质量与性能需求调整 |
| 分卷打包配置 | 打包的导入、排除、输出、分卷大小与压缩级别 | 由配置读取 | 按打包需求调整 |
| 代理监听端口（`-proxy-port`） | 代理服务的监听端口 | 基础端口 + 5（36794） | 端口冲突时修改 |

更多配置说明见 [08 构建、运行与配置](08-构建运行与配置.md)，外部引擎的完整命令行参数见 [10 llama.cpp 参数参考](10-llama.cpp-参数参考.md) 与 [11 stable-diffusion.cpp 参数参考](11-stable-diffusion.cpp-参数参考.md)。

## 五、常见排故

| 现象 | 可能原因 | 处理办法 |
|------|----------|----------|
| 语音合成无声或爆音 | 模型文件缺失、参考音频格式不符、采样参数异常 | 确认 GGUF 模型已就位；改用 16kHz 单声道 WAV；调整语速与采样参数 |
| 语音识别异常或无结果 | 音频格式不支持、文件过大、模型未就位 | 转为 16kHz 单声道 WAV；确认未超过大小上限；确认模型目录包含所需权重文件 |
| 网络检索失败 | 浏览器不可用、页面超时、搜索页故障 | 确认 Edge/Chrome 可用；稍后重试；监控机制会自动重启浏览器 |
| 修复工具无权限或被占用 | 端口被系统进程占用、目标文件被主程序占用 | 以管理员身份运行；关闭占用程序后重试 |
| 分卷打包失败 | 未安装 7z 工具 | 安装 7z 后重试 |
