## 6.4 ws_bridge.js —— 统一通信客户端

引擎/工作室的通信客户端，**替代浏览器 BroadcastChannel**，解决跨页面/跨 iframe 通信。API 与 BroadcastChannel 一致（`name` / `readyState` / `onmessage` / `postMessage` / `close`）。

- **接收**：连接同源 `/ws`，后端无差别广播 `{type,data}`，客户端按频道名过滤；`onmessage` 未设前缓冲入站消息。
- **发送**：`postMessage` 走 `HTTP POST /write/engine`，后端本地广播 + 转发智能体侧。
- **其它**：支持 `?ws=host:port` 覆盖连接地址；自动重连（指数退避，最大 30s）；暴露为全局 `window.WsBridge`。

### 6.7.2 deepseek.anime-rubik-solver —— 魔方演示工坊

基于 Web 与 three.js 的三阶魔方完整应用：**二次元卡线渲染**、表面拖拽转层、**CFOP 与桥式（Roux 结构变体）两种自动求解**与分步演示。

| 能力 | 说明 |
|------|------|
| 3D 视觉 | `MeshToonMaterial` + 4 档阶梯渐变、圆角块体 + 反向壳墨线描边、粉彩天空背景 + 樱花粒子 + 柔和投影；视角自由旋转，待机漂浮动画 |
| 拖拽转层 | 按住表面拖动转动切片层，松手吸附最近 90°；轴向判定采用「触摸面自旋 vs 侧面层旋转」双候选投影打分；动画结束做网格吸附与朝向正交化，每次提交自动做 54 贴纸级视图↔模型一致性校验 |
| 自动求解 | 任意打乱/手动状态随时可解，计算在 Web Worker 中进行；求解完成自动进入分步演示 |
| 分步演示 | 播放/暂停、上一步/下一步、跳至结尾、阶段时间线、速度调节（0.4×–3×）、复原彩星动画 |

**求解算法**：两个引擎共享「受限迭代加深搜索内核 + 净安全宏库」架构。CFOP：十字 → F2L（安全弹出 + 受限插入 + 构型重掷）→ 末层统一收尾；桥式（Roux 变体）：左 1×2×3 → 右 1×2×3 → 中线棱（DF/DB）→ 顶层统一收尾。末层统一收尾引擎把顶层排布编码为双射精确的「缺陷向量」，以「净安全宏」为图边做启发式优先搜索，宏的净安全由位级审计自动保证，OLL/PLL 不依赖手工表格。

**正确性保障**（`tests/` 下 `node tests/xxx.mjs` 可独立运行）：`test-model.mjs` 与 Kociemba 官方置换表逐块校验 + 群论性质；`test-solver.mjs [N]` CFOP 随机浸泡（16/16 通过，平均 ~1.7s）；`test-roux.mjs [N]` 桥式随机浸泡（5/5 通过）。所有旋转映射由 3D 几何推导生成（无手抄置换表）；算法候选一律先模拟审计再入库。

**结构**：`index.html`（importmap 指向本地 three）+ `css/style.css` + `js/core/cube.js`（54 贴纸模型）+ `js/solver/`（搜索内核/算法库/末层引擎/cfop/roux）+ `js/view/`（场景/动画/拖拽）+ `js/player/player.js`（分步播放器）+ `js/worker/`（求解 Worker）+ `tests/`。

### 6.7.3 deepseek.cnn-vis —— CNN 手写数字识别推理终端

在浏览器里直观演示卷积神经网络 (CNN) 识别手写数字的全过程。模型为 PyTorch 训练（测试集准确率 99.31%），权重导出为本地数据文件，由纯 JavaScript 前向传播引擎执行——**零外部依赖、可完全离线运行**（双击 `index.html` 即可）。

**功能**：28×28 手绘板（MNIST 规范自动居中，回车即推理）、自研正交投影 3D 渲染器（输入→32 张特征图→池化→64 张→展平→FC→概率条，可拖拽旋转/点击联动）、卷积①/②动画、最大池化对比、展平色带、FC1 激活柱状图 + Dropout 模拟、Softmax 概率分布 + 温度滑杆。

**正确性保证**：`node test/parity.mjs` 将 MNIST 第 0 张图分别送入 PyTorch 模型与 JS 引擎逐层比对（conv1/pool1/conv2/fc1/logits/probs 最大绝对误差 1e-6 量级，预测一致）。

**结构**：`cnndemo/index.html` + `assets/`（style.css / engine.js 纯 JS 推理引擎 / viz3d.js 零依赖 3D 渲染器 / app.js / model_data.js 自动生成权重 / samples.js）+ `tools/`（export_weights.py、gen_golden.py）+ `test/`（parity.mjs、golden.json）。

> 说明：演示暴露每一层中间激活量且要求离线，故不用 TF.js（无法直接拆中间结果且需 CDN），改为等价纯 JS 实现 + 数值对拍验证。

### 6.7.5 deepseek.flood-guardian —— 洪灾模拟器（Flood Guardian）

基于**真实水力学的实时洪水演进仿真游戏**。原生 WebGL2 + 纯 JavaScript，零依赖、零构建，双击即玩。当前版本 v1.1.0，完整改动记录见包内 `CHANGELOG.md`，公式与参数来源见包内 `docs/RESEARCH.md`（约 50 条可点击参考文献）。
