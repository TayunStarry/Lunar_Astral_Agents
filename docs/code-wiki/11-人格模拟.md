## 一、这是什么

人格模拟让 AI 不像一个通用助手，而像一个**有固定身份、情绪和关系的人**。

星月智能内置两位人格：

- **月华**——温柔、稳定、愿意陪你长时间相处；会聊天、会画画、会唱歌、会自己过日子。
- **琉璃**——安静、精准、做事利落；负责找页面、管扩展包、看配置、做执行。

人格不是靠一句「请扮演」临时生成的，而是由固定的角色提示词、长期心情、对每个人的情感认知，以及生活经历共同支撑。

---

## 二、核心用途

- **稳定人设**：多轮对话后仍然是同一个人，不会越聊越跑偏。
- **情绪连续**：心情会随交流变化，并影响语气与行为。
- **关系积累**：对不同的人形成不同的好感取向。
- **可微调**：在不动核心设定的前提下补充你自己的偏好。

## 三、使用方法

### 3.1 称呼与身份

- 首次打开月华窗口会询问称呼，输入后保存在浏览器本地，电脑端与手机端共用。
- 想改称呼时，让月华「换个称呼叫我」即可。
- 月华把你当作对话者，不会自称 AI 或程序。

### 3.2 追加自己的设定

在 `local_data/config/general.json` 的 `agent` 分组里写：

```json
{
  "agent": {
    "append_settings": [
      "称呼用户为「老板」，语气可以更随意一点",
      "回答里尽量少用感叹号"
    ]
  }
}
```

- 每一项作为一行，附加到「月华 · 对话者」的提示词末尾。
- 留空或空数组时不追加任何内容。
- 建议只写**偏好与风格**，不要写与安全边界冲突的指令。

### 3.3 心情

月华有 11 种基础情绪：开心、愤怒、伤心、好奇、无聊、平静、厌倦、担忧、恐慌、满足、元气。

- 心情根据你的发言内容更新，带有稳定性权重，单句话不会让它大幅跳变。
- 心情会影响回复语气、生活事件选择与创作主题。
- 心情状态独立保存，重启后延续。

### 3.4 情感认知

- 月华对**每一个对话者**单独维护一份好感取向。
- 正向锚点：喜欢、信任、关心；负向锚点：讨厌、反感、冷淡。
- 没有明显信号时显示为「平淡」。
- 好感不是「刷次数」涨的，而是取决于交流中的态度与情绪强度。

### 3.5 外观与声音

| 项目 | 配置 | 说明 |
|------|------|------|
| 角色渲染 | `system.character_renderer` | `bedrock`（基岩版模型）、`live2d` 或 `gif`（动图） |
| Live2D 模型 | `system.live2d_model` | 选择 live2d 时指定模型基址 |
| 语音引擎 | `tts.engine` | `Qwen` / `Kokoro` / `OmniVoice` |
| 音色来源 | `tts.ref_audio` | 参考音频（5~15 秒、单声道 WAV 效果最好） |
| 语速 | `tts.speed` | Kokoro 可用，建议 0.8~1.2 |
| 风格指令 | `tts.instruct` | OmniVoice 可用，如「温柔、轻声」 |

### 3.6 两位人格的分工与切换

- 月华窗口在 `/`，琉璃桌面在 `/desktop/`，两个窗口可同时打开。
- 你不需要「切换人格」：找月华聊天，去琉璃桌面找工具。
- 需要月华调用工具时，直接用自然语言说；需要琉璃执行时，打开对应卡片或用对话让它转交。

## 四、功能特性

| 特性 | 说明 |
|------|------|
| 固定角色提示词 | 每个角色一份独立的提示词，行为边界稳定 |
| 角色拆分 | 对话者、绘制者、演奏者、截图者各自专注一类任务 |
| 心情模型 | 11 种情绪，带稳定性权重，跨会话保留 |
| 情感模型 | 双极好感取向，按对话者分别维护 |
| 生活经历 | 生活系统产生的经历会反过来影响人格表现 |
| 外观可换 | 基岩版与 Live2D 两种渲染方式 |
| 声音可换 | 三种语音引擎，支持参考音频克隆音色 |
| 设定可补 | 通过追加设定微调风格，不改动核心人格 |

## 五、运行参数

| 参数 | 位置 | 说明 | 默认值 | 建议 |
|------|------|------|--------|------|
| `agent.append_settings` | `config/general.json` | 追加设定，每项一行附加到对话者提示词末尾 | 空 | 只写偏好与风格 |
| `system.character_renderer` | `config/general.json` | 角色渲染方式：`bedrock` / `live2d` / `gif` | `bedrock` | 按前端资源选择；`gif` 优先读取 `models/webm/`（VP9 alpha），Safari/iOS 或播放失败时回退 `models/gif/` |
| `system.live2d_model` | `config/general.json` | Live2D 模型基址 | 空（引擎默认） | 使用 live2d 时填写 |
| `tts.engine` | `config/general.json` | 语音引擎 | `Qwen` | 按机器性能选择 |
| `tts.ref_audio` | `config/general.json` | 参考音频路径 | `local_data/audios/lunar-template.wav` | 换音色即替换该文件 |
| `tts.ref_text` | `config/general.json` | 参考音频对应文本 | 空 | OmniVoice 克隆时必填 |
| `tts.voice` | `config/general.json` | 预设音色 | 空 | Kokoro 用 |
| `tts.mix` | `config/general.json` | 多音色混合比例 | 空 | Kokoro 用 |
| `tts.speed` | `config/general.json` | 语速倍率 | `1.0` | Kokoro 取值 0.5~2.0 |
| `tts.lang` | `config/general.json` | 语言提示 | 空 | Kokoro：zh / en / auto |
| `tts.instruct` | `config/general.json` | 音色属性关键词 | 空 | OmniVoice 用 |
| `tts.seed` | `config/general.json` | 随机种子 | `0`（随机） | 复现同一语音时固定 |
| `tts.disable_postproc` | `config/general.json` | 关闭输出后处理 | `false` | 一般保持默认 |
| `tts.idle_unload_minutes` | `config/general.json` | 闲置多久卸载语音引擎（分钟） | `5` | 显存紧张时调小 |

内建人格状态（不可配置，供了解）：

| 项目 | 说明 |
|------|------|
| 心情标签 | 开心 / 愤怒 / 伤心 / 好奇 / 无聊 / 平静 / 厌倦 / 担忧 / 恐慌 / 满足 / 元气 |
| 好感标签 | 喜欢 / 信任 / 关心 / 讨厌 / 反感 / 冷淡 / 平淡 |
| 心情与好感状态 | 保存在 `local_data/database/life/`，重启延续 |
| 单次交流的影响 | 带稳定性权重，不会因一句话剧变 |

## 六、常见问题

| 现象 | 可能原因 | 处理办法 |
|------|----------|----------|
| 称呼没生效 | 浏览器缓存了旧值，或未在同一前端输入 | 重新输入称呼；强制刷新页面 |
| 追加设定没反应 | 字段写错分组、JSON 格式错误，或未重启 | 确认写在 `agent.append_settings`；校验 JSON；重启 |
| 人格越来越不像 | 追加设定里写了冲突指令，或上下文过长 | 精简追加设定；开新会话 |
| 心情一直不变 | 近期发言情绪信号不足 | 属正常；需要更明确的情绪表达 |
| 好感一直「平淡」 | 互动次数或极性未达阈值 | 需要多轮带明显态度的交流 |
| 角色模型不显示 | 渲染方式与资源不匹配 | 检查 `character_renderer` 与模型目录 |
| 语音音色不对 | 参考音频格式或引擎不支持该参数 | 用 5~15 秒单声道 WAV；换引擎或音色 |
| 语音很慢 | 引擎刚加载，或显存不足 | 等待首句合成；调小 `idle_unload_minutes` 之外的显存占用 |
