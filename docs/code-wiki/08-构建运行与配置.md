## 2. 快速开始

```powershell
# 1. 一键安装编译依赖
go install github.com/akavel/rsrc@latest   # Windows 图标编译工具

# 2. 一键编译全部（含环境检查，统一构建脚本位于 subsystem/，构建全部模块）
cd d:\Lunar_Astral_Agents\subsystem
.\build.ps1

# 3. 运行
.\Lunar_Astral.exe         # 月华核心
.\Crystal_Astral.exe       # 琉璃扩展
.\Qwen3_TTS_Lunar.exe      # 语音合成（如需独立）
.\Qwen_ASR_Lunar.exe       # 语音识别（如需独立）
.\Environment_Repair.exe   # 运维工具（CLI）
```

---

## 3. 单独编译

```powershell
# 核心系统——月华（含前端 TypeScript 编译）
cd d:\Lunar_Astral_Agents\lunar_astral
.\build.ps1

# 扩展系统——琉璃
cd d:\Lunar_Astral_Agents\crystal_astral
.\build.ps1

# 语音合成（3 阶段：GGML → C++ DLL → Go）
cd d:\Lunar_Astral_Agents\subsystem\qwen3_tts
.\build.ps1            # 可 -SkipGGML/-SkipCPP/-SkipGo/-Clean

# 语音识别
cd d:\Lunar_Astral_Agents\subsystem\qwen_asr
.\build.ps1

# 运维工具箱（自动同步 embedded_data）
cd d:\Lunar_Astral_Agents\subsystem\environment_repair
.\build.ps1
```

各 `build.ps1` 均为自包含脚本，内部自动处理前置步骤（rsrc 图标、TS 编译、CGO 参数等）。

### 双架构交叉编译

统一脚本与部分子脚本支持 `-TargetOS`（windows/linux/darwin）× `-TargetArch`（amd64/arm64）参数，但项目整体仅支持 Windows 运行。

## 4. 编译产物

产物统一输出到项目根 `d:\Lunar_Astral_Agents\`：

| 文件 | 系统 | 说明 |
|------|------|------|
| `Lunar_Astral.exe` | 钛宇-月华 | AI 桌面智能体主程序 |
| `Crystal_Astral.exe` | 钛宇-琉璃 | 工具集扩展程序 |
| `Qwen_ASR_Lunar.exe` | 语音识别 | 独立语音识别程序 |
| `Qwen3_TTS_Lunar.exe` | 语音合成 | 独立语音合成程序 |
| `Environment_Repair.exe` | 运维工具 | 交互式终端菜单 CLI（不隐藏控制台） |

补充：`qwen3_tts` 额外产出 `qwen3tts.dll`（C++ 推理引擎）；`lunar_astral` 的前端产物 `agentSystem.js` 经 Go embed 内嵌于可执行文件。

## 6. 双层配置架构

1. **命令行参数（flag）**——最高优先级（如 `-basic-port`、`-developer`）
2. **`local_data/lunar_config.json`**——按字段覆盖默认值

### lunar_config.json 关键分组

| 分组 | 字段 | 说明 |
|------|------|------|
| `models` | asr_model / diffusion_model / variational_model / prompt_analysis_model | AI 模型文件路径 |
| `server` | bridging_type / bridging_path / bridging_token / bridging_target / bridging_keywords | NapCat QQ 桥接 |
| `agent` / `memory` / `search` | embedding_model/url/key、multimodal_model/url/key | 各域模型分流（默认走 `http://127.0.0.1:36789/v1`） |

### 模型预设文件（models.ini）

各模型段配置对应模型路径：

| 段 | 说明 |
|----|------|
| `[system-multimodal]` | 多模态模型（`model` / `mmproj`） |
| `[system-embedding]` | 嵌入模型（`model`） |

---

## 7. 添加 / 切换模型

1. 将 GGUF 模型放入 `local_data/models/`。
2. 语言/嵌入模型：编辑 `local_data/models/models.ini` 对应段路径。
3. ASR/扩散等辅助模型：编辑 `lunar_config.json` 的 `models` 分组。
4. 重启程序生效。
