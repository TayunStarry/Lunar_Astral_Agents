# 08 安装、运行与配置手册

> [🏠 手册门户](README.md) ｜ [◀ 上一模块](07-依赖关系.md) ｜ [下一模块 ▶](09-LTPX协议-月华工具包.md)

## 一、功能介绍

本篇说明如何在一台机器上把星月智能装好、把它跑起来，以及如何通过参数与配置调整它的运行行为。它覆盖从「准备运行环境」到「构建出可执行程序」、再到「以不同方式启动程序并切换模型」的完整环节：使用者按本模块的步骤即可获得一套可运行的程序，并能在不改动代码的前提下，通过配置文件与命令行参数控制端口、显存策略、语音合成引擎、绘图行为等。它解决的问题是：让安装与调参有据可依，避免因环境缺失、端口冲突或配置写错导致程序无法启动、或行为与预期不符。

## 二、使用方法

### 1. 环境准备

| 项目 | 说明 |
|------|------|
| 操作系统 | Windows 10 21H2 或更高（64 位），Windows 11 更佳 |
| WebView2 Runtime | 前端窗口运行所必需，Windows 11 通常已预装 |
| Go | 1.24 或更高，用于构建主程序与各子系统 |
| Node.js + npm | 用于编译前端智能体脚本 |
| GCC（MinGW-w64 / TDM-GCC） | 供需要 CGO 的模块编译 |
| rsrc | 用于生成 Windows 图标资源 |
| CMake | 语音合成引擎 C++ 部分编译所需 |
| 可选：CUDA / FFmpeg / Vulkan | CUDA 加速推理、FFmpeg 处理音视频、Vulkan 作为 GPU 后端，按需安装 |

### 2. 一键构建

在项目根目录运行统一构建脚本 `build.ps1` 即可一次构建全部发行产物。该脚本可用参数选择目标平台与架构（`-TargetOS`：windows / linux / darwin；`-TargetArch`：amd64 / arm64），并会依次构建核心人格（月华 + 琉璃合并工程）、LTP9 权限密钥生成器、更新器三个产物。

### 3. 单独构建各程序

| 程序 | 构建方式 | 可选参数 |
|------|----------|----------|
| 核心人格 | 在核心人格构建目录运行其构建脚本，内部自动完成图标生成、前端脚本打包、推理引擎库按需构建与 CGO 编译等前置步骤 | 可强制重建语音引擎库，或跳过语音引擎库构建 |
| LTP9 权限密钥生成器 | 在密钥生成器目录运行其构建脚本 | 无 |
| 更新器 | 在更新器目录运行其构建脚本 | 无 |

### 4. 运行程序的三种方式

| 方式 | 操作 |
|------|------|
| 直接运行 | 启动主程序 `Lunar_Astral_Agents.exe`：进入全屏控制台，并自动打开月华、琉璃前端窗口 |
| 开发模式 | 为主程序附加 `-developer` 参数启动，日志不限流，便于排查问题 |
| 指定端口 | 为主程序附加 `-basic-port` 参数指定基础端口（如 36800），端口冲突时使用 |

### 5. 程序内退出方式

在控制台内按 `z` 或 `Ctrl+C` 退出，程序会优雅关闭全部子系统后再结束。全部前端窗口关闭不会退出程序，控制台常驻。

### 6. 添加 / 切换模型

1. 将模型文件（GGUF 格式）放入本地模型目录 local_data/models/。
2. 语言模型 / 嵌入模型：编辑模型预设文件 local_data/models/models.ini 中对应段的路径。
3. 语音识别、扩散等辅助模型：编辑配置文件 `local_data/lunar_config.json` 的 models 分组。
4. 重启程序使配置生效。

## 三、功能特性

### 统一构建

| 特性 | 说明 |
|------|------|
| 统一构建脚本 | 项目根的构建脚本可一次构建全部发行产物，并依次调用各子系统的构建脚本 |
| 子构建脚本自包含 | 各子系统的构建脚本自行处理图标、前端打包、CGO 参数等前置步骤 |
| 交叉编译 | 支持目标平台与架构选择（windows / linux / darwin × amd64 / arm64），实际运行目标为 Windows |
| 单一程序形态 | 程序仅有控制台（TUI）一种形态；月华与琉璃是控制台代为打开的前端窗口，窗口关闭不影响进程 |

### 产物清单

| 产物 | 说明 |
|------|------|
| 主程序 `Lunar_Astral_Agents.exe` | 核心人格主程序（控制台 TUI，月华 + 琉璃 + 运维功能合并工程） |
| 更新器 `Lunar_Update_Applier.exe` | 更新包含主程序时由主程序拉起，等待文件占用释放后覆盖并重启主程序 |
| 密钥生成器 `subsystem/LTP9Keygen.exe` | LTP9 权限密钥生成器 |
| 运行期旁挂 | 语音合成引擎库运行时动态加载；前端智能体脚本已内嵌于主程序，不单独分发 |

### 配置优先级

| 层级 | 说明 |
|------|------|
| 命令行参数 | 第一优先级 |
| 配置文件 `lunar_config.json` | 第二层，按字段增量覆盖默认值；`server.developer` 与 `diffusion.allow_diffusion` 例外——文件存在时以文件值为准 |

### 模型预设机制

| 特性 | 说明 |
|------|------|
| 预设文件 | `local_data/models/models.ini` 以多段形式声明模型服务，启动模型服务时按段传入 |
| 服务段 | 多模态模型段、嵌入模型段；段名与默认模型名（system-multimodal / system-embedding）对应 |
| 覆盖方式 | 段内可声明模型路径、投影文件，以及上下文长度、推测解码等参数 |

## 四、运行参数

### 命令行参数（主程序）

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `-basic-port` | 基础 HTTP 服务端口（Web 界面与模型服务锚点） | 36789 | 端口冲突时改为空闲端口 |
| `-model-port` | 模型服务基础端口 | 基础端口 + 1（36790） | 一般无需改动 |
| `-proxy-port` | 代理监听端口 | 基础端口 + 5（36794） | 一般无需改动 |
| `-developer` | 开发模式，日志不限流 | 关闭 | 排障时临时开启 |
| `-allow-lan` | 允许局域网访问引擎服务 | 关闭（仅本机回环） | 仅跨机部署时开启 |
| `-insecure-tls` | 插件网络跳过 TLS 证书校验 | 关闭 | 保持关闭以确保安全 |
| `-allow-diffusion` | 允许扩散图像生成 | 开启 | 不需要绘图时关闭以省资源 |
| `-allow-browser` | 允许打开系统浏览器 | 开启 | 一般保持开启 |
| `-sync-fetch-timeout` | 同步网络请求超时（秒） | 300 | 网络较慢时适当调大 |
| `-local-dir` | 本地数据根目录 | `local_data` | 数据放到其它盘时调整 |
| `-infer-engine` / `-visual-engine` | 文本推理引擎 / 绘图引擎可执行文件路径 | 本地模型目录下的默认路径 | 引擎放在别处时调整 |
| `-tts-engine` | 语音合成引擎 | Qwen | 可选 Qwen / Kokoro / OmniVoice |
| `-tts-idle-unload-minutes` | 语音引擎闲置卸载阈值（分钟） | 5 | 显存紧张时调小 |
| `-client-character-renderer` | 前端角色渲染方式 | bedrock | 可选 bedrock / live2d |

> 文本推理引擎的完整参数见 [10](10-llama.cpp-参数参考.md)，绘图引擎参数见 [11](11-stable-diffusion.cpp-参数参考.md)，图像生成的尺寸 / 步数 / 分片 / 显存策略见 [12](12-图像生成参数策略.md)。

### 配置文件 `lunar_config.json` 分组字段

> 配置文件放在本地数据目录下（默认 `local_data/lunar_config.json`），仅在字段非空时覆盖对应默认值。

**models 分组**

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `diffusion_model` | 扩散（文生图）模型文件路径 | 出厂配置指向本地模型 | 放入模型目录后填写路径 |
| `variational_model` | VAE 模型文件路径 | 出厂配置指向本地模型 | 与扩散模型配套 |
| `prompt_analysis_model` | 提示词分析模型路径 | 出厂配置指向本地模型 | 需要提示词精炼时配置 |
| `prompt_mmproj_model` | 提示词分析多模态投影模型路径 | 空 | **保持留空**：实测对出图零影响（像素级完全相同），传入只会多占约 1GB 内存 |
| `real_esrgan_model` | 4× 超分辨率模型路径 | 出厂配置指向本地模型 | 需要放大图像时配置 |

**server 分组**

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `developer` | 开发（调试）模式 | false | 排障时开启 |

| `insecure_tls` | 插件网络跳过 TLS 证书校验 | false | 保持关闭 |

**agent 分组**

| 参数 | 说明 | 默认值 | 建议 |

**统一资源归档命令行开关**（统一资源句柄，见 [14 统一资源句柄与多模态引用](14-统一资源句柄与多模态引用.md)）

**diffusion 分组**（详细调参见 [12](12-图像生成参数策略.md)）

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `allow_diffusion` | 是否允许运行扩散生成 | true | 文件存在时以文件值为准 |
| `image_vram_guard` | 画图前显存守卫开关 | true | 保持开启 |

| `sd_offload_to_cpu` | 权重内存卸载模式 | auto | 可选 auto / always / off |

| `pixel_budget_mp` | 图生图/合照按参考图比例推导尺寸的像素预算（百万像素，由绘制者读取） | 1.6 | 常规比例不受影响，超宽/超长画幅才需要调大 |

### 模型预设文件 `models.ini`

| 段 | 说明 |
|----|------|
| 多模态模型段 | 声明多模态模型路径与投影文件，可含上下文长度、推测解码等参数 |
| 嵌入模型段 | 声明嵌入模型路径并开启嵌入输出 |

段名与默认模型名（system-multimodal / system-embedding）对应，由月华启动模型服务时传入。

### 语音识别（模型预设）

语音识别由统一的模型服务承载，不再是独立监听的程序：`models.ini` 的 `system-asr` 段声明识别模型与音频编码器（`model` / `mmproj`），模型服务端口与其余推理共用（见上文命令行参数）；预设名由启动参数 `-agent-asr-model` 指定（默认 `system-asr`）。因此不存在独立的识别端口与缓存环境变量。

## 五、常见排故

| 现象 | 可能原因 | 处理办法 |
|------|----------|----------|
| 构建失败 | 缺少构建依赖（Go / Node / GCC / CMake / rsrc），或产物正被运行中的程序占用 | 按「环境准备」补齐依赖；先关闭正在运行的主程序再构建 |
| 前端窗口打不开 | 缺少 WebView2 Runtime | 安装 WebView2 Runtime 后重试 |
| 模型路径错误 / 模型不加载 | 模型文件未放入模型目录，或配置中的路径与实际不符 | 核对模型目录与配置中的路径；重启程序 |
| 端口被占用 / 启动失败 | 基础端口被其它进程占用 | 改基础端口后启动，或释放占用端口的进程 |
| 配置改动不生效 | 字段拼写错误、写在已失效的旧节，或未重启 | 核对分组与字段名，重启程序（命令行参数与配置文件均无需重新编译） |
| 图标资源缺失 | 未执行图标生成步骤，或图标文件缺失 | 重新构建以生成图标资源 |
| 改动前端后行为没变化 | 浏览器仍在运行旧页面 | 刷新页面一次 |
