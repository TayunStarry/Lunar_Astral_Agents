## 运行环境与启动

### 环境

- **操作系统**：Windows 10/11 为主；构建脚本也支持 Linux 与 macOS 目标，但窗口与桌面操纵能力以 Windows 为完整目标。
- **Go**：1.26 系列。
- **C 工具链**：CGO 需要 GCC（MinGW-w64 或 TDM-GCC），用于 SQLite、ONNX Runtime 等依赖。
- **WebView2**：Windows 前端窗口依赖 WebView2 运行时。
- **模型文件**：主模型、轻量模型、嵌入模型、图像生成、语音、音乐等按需放在模型目录；缺少某个模型只会影响对应能力。

### 编译

在仓库根目录执行：

```powershell
.\subsystem\lunar_harness\build.ps1
```

脚本会依次：编译图标、关闭正在运行的主程序、按需构建语音引擎库、生成端点自述文档、用 CGO 编译，最终在仓库根目录产出 `Lunar_Astral_Agents.exe`。

可选参数：

| 参数 | 作用 |
|------|------|
| `-WithTTS` | 强制重建语音引擎库 |
| `-SkipTTS` | 跳过语音引擎库构建 |
| `-TargetOS` / `-TargetArch` | 指定目标平台与架构 |

### 启动

直接运行仓库根目录的可执行文件。启动时按顺序做四件事：

1. **单实例闸门**：默认端口已被占用时直接提示「已有一个星月智能在运行」，避免两个实例互抢模型端口。
2. **装配子系统**：传输层、人格层、引擎层、HTTP 服务。
3. **打开前端**：非开发者模式下自动打开月华消息终端与琉璃桌面；开发者模式不自动弹窗，可在控制台手动唤起。
4. **进入控制台**：全屏 TUI 承载日志、运行状态、智能体实况与运维功能；关闭控制台会优雅关闭全部子系统。

## 端口与访问

| 端口 | 用途 |
|------|------|
| `36789` | Web 服务：前端页面与 API |
| `36790` | 模型服务：llama-server 的 OpenAI 兼容接口 |
| `36794` | Web 服务代理口，界定端口范围 |

默认只监听回环地址，本机浏览器访问即可。需要局域网访问时，必须在配置中显式允许，并自行承担风险：系统没有面向公网的账号体系，暴露到局域网等于把对话、文件与扩展包接口交给同网段所有人。

不要把代理端口填成模型服务端口。两者撞车时，系统发往模型的请求会打到代理上，表现为 TLS 握手失败、连接重置、嵌入请求 EOF，最终导致记忆库不可用。

## 模型与配置

### 模型目录

模型按用途分目录放置，常见包括：

| 目录 | 用途 |
|------|------|
| `primary_reasoning` | 主对话与复杂推理 |
| `light_reasoning` | 轻量判断、分类、快速应答 |
| `text_embedding` | 记忆与检索的向量化 |
| `painter` / `stable_diffusion.cpp` | 图像生成 |
| `music_generation` | 音乐事件生成 |
| `broadcaster` | 语音合成引擎与音色 |
| `audio_transcriber` | 语音转写 |
| `live2d` | 角色渲染资源 |

缺少主模型时对话不可用；缺少绘画、音乐、语音模型只影响对应能力，其他功能仍可运行。

### 配置文件

配置文件位于 `local_data/config/`，主要文件：

| 文件 | 管什么 |
|------|--------|
| `general.json` | 端口、局域网开关、开发者模式、模型与路径等通用配置 |
| `painter.json` | 绘画引擎、比例、风格、超分等 |
| `bilibili.json` | B 站登录态、观影预算、评论与分享策略 |
| `forum.json` | 互助论坛地址、账号、启用开关、互动策略 |
| `napcat.json` | QQ 桥接地址、令牌、白名单、群触发策略 |
| `archive.json` | 归档与压缩包策略 |
| `labels.json` | 标签与显示名 |
| `layout.json` | 琉璃桌面卡片布局 |
| `release.json` | 更新通道与备份策略 |

多数配置在控制台或前端设置里修改后即可生效；涉及端口、模型路径、CGO 依赖的改动需要重启主程序。修改前建议备份，尤其是 `napcat.json` 与 `bilibili.json` 里的登录态。

## 数据目录

`local_data/` 是运行数据的根目录：

| 目录 | 内容 |
|------|------|
| `config` | 配置文件 |
| `models` | 模型与引擎库 |
| `documents` | 文档、创作、演绎产物 |
| `multimedia` | 图片、视频、动图等资源 |
| `audios` | 音频与语音 |
| `database` | 知识库、记忆库等 SQLite 数据，以及心愿、心情与好感的 JSON 状态（`database/life/wish_chain.json`） |
| `package` | 扩展包 |
| `cache` | 可重建的缓存 |
| `cert` | 本地证书 |
| `logs` | 运行日志与导出文件 |
| `runtime` | 运行时状态 |
| `unknown` | 未分类的临时资源 |

`cache`、`runtime` 可以清理；`database`、`documents`、`multimedia`、`package` 不要随意删除，它们承载记忆、作品和扩展包。

## 控制台速查

控制台是运维与观察入口，常用屏幕：

| 屏幕 | 能做什么 |
|------|----------|
| 运行状态 | 查看服务、模型、前端窗口状态；手动唤起月华/琉璃 |
| 智能体实况 | 看当前推理由谁执行、调用了什么工具、是否重试或中断 |
| 工具列表 | 查看各智能体注册的工具目录 |
| 后勤修复 | 导出指定智能体的上下文、查看失败记录、触发状态修复 |
| 数据导出 | 导出原始日志与智能体上下文，便于排查 |
| 代理 | 配置本地代理端口，查看端口占用提示 |
| 桌面操纵 | 人工启动桌面任务，查看七段执行过程 |
| 更新 | 检查更新、下载、安装与回滚 |

桌面操纵没有对话入口，只能在这里启动；这是刻意的隔离，不是遗漏。

## 安全边界

系统按「本地优先、能力分级」设计：

| 边界 | 规则 |
|------|------|
| 网络 | 默认只监听回环地址；局域网访问需显式开启，且没有公网账号体系 |
| 模型调用 | 只能经过统一推理基座，调用必须出现在推理实况里，不允许静默调用 |
| 桌面操纵 | 只能由控制台人工启动；对话开始自动停止；轮次与停滞都有上限 |
| 文件 | 源文件只读收录，不移动不删除；写入限定在文档库与资源目录 |
| 数据库 | 自然语言只生成只读查询，后端校验后才执行，写操作与多语句被拦截 |
| QQ | 默认白名单投递；白名单外需要明确确认，确认有时效 |
| 扩展包 | 页面在 iframe 中运行；工具调用经过服务端受理与回执，不直接暴露系统内部 |
| 脚本 | 页面脚本在资源库沙箱中运行；项目脚本由文件编辑智能体在限定目录内执行 |
| 密钥 | 令牌、Cookie、登录态只存本地配置，不写入日志、不进入提示词 |

需要特别强调：**不要把服务直接暴露到公网。** 系统没有为多用户、公网访问设计鉴权与隔离；需要远程使用时，应通过受控的内网穿透或反向代理，并自行增加认证层。

## 更新与回滚

更新走配置好的发布通道：

1. 控制台检查新版本，读取发布说明与文件清单。
2. 下载更新包，按包含/排除规则替换程序文件。
3. 替换前备份旧文件，备份数量由配置决定。
4. 安装完成后重启主程序；重启参数可配置。
5. 更新失败或新版本异常时，从备份回滚到上一版本。

更新不会覆盖 `local_data/` 里的配置、记忆、作品与扩展包；但涉及配置结构变化的版本，仍建议先手动备份 `config` 与 `database`。

## 常见故障排查

| 现象 | 先查什么 | 常见原因 |
|------|----------|----------|
| 启动提示「已有一个星月智能在运行」 | 端口占用、残留进程 | 重复启动；关闭旧进程或用 `-basic-port` 换端口 |
| 前端 404 或打不开 | Web 服务是否监听、端口是否被代理占用 | 端口撞车、静态资源未嵌入、代理配置错误 |
| 对话一直不回 | 主模型是否加载、模型端口是否可达 | 模型文件缺失、显存不足、请求打到代理 |
| 记忆搜不到 | 嵌入模型是否可用、是否问错类型 | 嵌入服务失败、存的是图片却查文本 |
| 绘画/音乐无结果 | 对应模型与引擎库是否存在 | 模型缺失、DLL 未构建、GPU 不可用 |
| 没有声音 | 语音引擎库、音色配置、前端静音 | DLL 缺失、TTS 引擎未加载、浏览器静音 |
| 编译失败 | GCC、CGO、Go 版本 | 未安装 MinGW、CGO 关闭、Go 版本不符 |
| 扩展包打不开 | 包目录、metadata、入口文件 | 包损坏、入口路径错误、桌面未启动 |
| QQ 不回复 | 桥接连接、白名单、群触发概率 | NapCat 未连接、目标不在白名单、概率未命中 |
| 桌面操纵无反应 | 是否从控制台启动、UIA 是否可用 | 未人工启动、目标程序未找到、UIA 降级失败 |

排查顺序建议：**先看控制台运行状态，再看智能体实况与日志，最后才改配置。** 不要在没有证据时反复重启或删除数据目录。
