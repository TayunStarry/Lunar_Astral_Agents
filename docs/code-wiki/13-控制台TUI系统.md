# 13 控制台使用手册

> [🏠 手册门户](README.md) ｜ [◀ 上一模块](12-图像生成参数策略.md) ｜ [下一模块 ▶](14-图片标签与多模态窗口.md)

控制台是星月智能的全屏终端界面，把日志、运行状态、智能体实况与运维功能收敛到单一界面。配置取自 `lunar_config.json` 的 `release` 与 `server` 分组，字段含义见 [08-构建运行与配置](08-构建运行与配置.md)。

---

## 一、功能介绍

控制台是你与整个程序交互的主界面，解决的问题是：在一个全屏终端里同时掌握运行状态、查看日志、执行运维操作，而不用在多个窗口和命令行之间来回切换。

- **唯一的程序形态**：启动主程序后直接进入控制台，无需额外客户端。
- **替用户打开前端窗口**：控制台启动月华与琉璃两个前端窗口。
- **窗口关闭不退出程序**：关闭月华 / 琉璃窗口后，控制台仍在运行，程序不会退出。
- **运维入口集中**：资源更新、LTPX 应用市场、打包归档、端口释放、局域共享、前端管理都在这里操作。

## 二、使用方法

### 2.1 启动并进入控制台

1. 以正常桌面程序的方式启动主程序（双击可执行文件，或在终端中直接运行）。
2. 启动后进入全屏控制台，程序随后自动打开月华与琉璃前端窗口。
3. 若只想保留控制台，可关闭前端窗口，控制台继续运行。

### 2.2 屏幕切换

在主界面按对应按键进入各屏幕：

| 按键 | 屏幕 / 入口 | 可进行的操作 |
|------|-------------|--------------|
| `0` | 资源更新 管理 | 发布更新包、拉取最新、按 tag 或哈希拉取、查看版本列表（可回车直接拉取） |
| `m` | LTPX 应用市场 | 浏览远端包、查看详情、安装本地包、按关键词本地搜索、按标签远端筛选、发布本地包、刷新 |
| `1` | 核心智能 实况 | 查看思考 / 输出 / 工具调用的流式实况，切换是否自动跟随 |
| `2` | 运行状态 | 查看运行环境与模型计量双栏信息 |
| `3`~`7` | 原始 / 月华 JS / 插件 JS / Go 警告 / 绘图引擎 日志 | 查看各类日志，滚动、跳首尾、切换跟随、清空 |
| `d` | 数据导出 管理 | 导出运行期数据（上下文为 `.json`，原始日志为 `.log`） |
| `8` | 前端页面 管理 | 重启月华 / 琉璃窗口 |
| `9` | 局域共享 管理 | 配置反向代理并展示扫码二维码，供手机等远程前端接入 |
| `a` | 打包归档 管理 | 选择配置 → 确认 → 分卷打包 |
| `b` | 端口释放 管理 | 扫描端口范围并终止占用进程 |
| `z` | 退出程序 | 优雅停止全部子系统 |

### 2.3 常用键位

- 全局移动：`↑/↓`（或 `k`/`j`）；确认：`Enter`；返回上级：`Esc`。
- 键位帮助：`?`（弹出帮助页）。
- 退出程序：`z` 或 `Ctrl+C`。
- 日志与列表屏：`↑/↓`、`PgUp/PgDn` 滚动，`Home/End` 跳到首尾，`f` 切换跟随，`c` 清空。
- 应用市场屏：`↑/↓` 选择、`Enter` 详情、`i` 安装、`/` 搜索、`t` 标签筛选、`u` 发布、`r` 刷新。

### 2.4 查看日志与运行状态

1. 按 `2` 查看运行状态，了解运行环境与模型计量。
2. 按 `1` 查看核心智能实况，观察思考与输出；浏览回看时跟随会自动暂停。
3. 按 `3`~`7` 查看各类日志；上翻自动暂停跟随，按 `End` 恢复。
4. 需要留档时按 `d` 导出上下文或原始日志，文件落到本地数据目录下的日志子目录。

### 2.5 资源更新与 LTPX 应用市场

- **资源更新**：按 `0` 进入，可发布更新包、拉取最新包、按 tag 或哈希拉取，或从版本列表回车拉取。
- **LTPX 应用市场**：按 `m` 进入，可浏览、搜索、安装、发布本地工具包。
- **发布向导**：发布 LTPX 包为三步向导——选择本地包（或上传已打包文件）→ 填写描述（`#标签` 自动识别）→ 输入 Gitee 令牌（仅本次注入副本，不落盘）。

## 三、功能特性

| 特性 | 说明 |
|------|------|
| 多屏幕控制台 | 更新 / 市场 / 实况 / 运行状态 / 多种日志 / 导出 / 前端 / 局域共享 / 归档 / 端口释放等屏幕，一键切换 |
| 实时日志与流式输出 | 日志与智能体思考 / 输出 / 工具调用实时刷新，长行自动按显示宽度折行 |
| 窗口化列表 | 长列表以定高窗口展示并跟随滚动，选中项始终可见 |
| 资源更新管理 | 发布、拉取最新、按 tag / 哈希拉取、版本列表 |
| 应用市场 | 浏览、搜索、筛选、安装、发布 LTPX 工具包 |
| 数据导出 | 一键导出智能体上下文与原始日志，供离线排查 |
| 进程与端口状态 | 展示运行状态；扫描端口范围并释放被占用端口 |
| 局域共享 | 配置反向代理并展示二维码，供远程前端接入 |
| 打包归档 | 选择配置后分卷打包，便于分发与备份 |
| 退出与重启 | 正常退出会优雅停止全部子系统；前端窗口可单独重启 |

## 四、运行参数

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `server.developer` | 开发模式开关：开启后打印全部日志，关闭时仅打印警告及以上级别 | 关闭 | 排障时开启；日常使用保持关闭以减少日志量 |
| `release.gitee_owner` / `release.gitee_repo` | 发布仓库属主 / 仓库名 | 出厂配置 | 发布前填写正确的仓库 |
| `release.gitee_token` | 私人令牌 | 空 | 通常留空，发布时在控制台手动输入、不落盘 |
| `release.backup_keep` | 覆盖前备份保留次数 | 3 | 需要更多回滚余地时调大 |
| `release.program_files` | 主程序文件清单 | 出厂清单 | 决定更新是否需要「关程序 → 应用 → 重启」 |
| `release.restart_args` | 重启主程序携带的参数 | 空 | 按需配置 |
| `release.target_dir` / `release.package_dir` | 资源根目录 / LTPX 包根目录 | 空（用默认目录） | 按需调整 |

完整字段含义与其余分组见 [08-构建运行与配置](08-构建运行与配置.md)。

## 五、常见排故

| 现象 | 可能原因 | 处理办法 |
|------|----------|----------|
| 控制台乱码 | 终端代码页非 UTF-8，或字体不支持界面字形 | 改用支持 UTF-8 的终端与字体；确认程序已自动切换代码页，必要时更新到修复版本 |
| 界面不停向上滚、字被滚没 | 窗口尺寸变更后未被重新读取（旧版本） | 更新到修复版本 |
| 控制台无输出 / 一直空白 | 在后台或服务 / 计划任务等无控制台环境下运行 | 以正常桌面程序方式启动，不要放到服务或计划任务里运行 |
| 键位无响应 | 控制台窗口未获得焦点，或输入被重定向 | 点击控制台窗口后重试；避免重定向输入 |
| 前端窗口未打开 | 缺少 WebView2 Runtime | 安装 WebView2 Runtime 后重启程序 |
| 更新包应用失败 | 主程序被占用、重复实例抢占，或覆盖中途中断 | 关闭其它实例后重试；查看更新日志与备份目录排查 |
| 应用市场 / 更新列表拉不到 | 未配置令牌导致匿名额度被打满 | 在发布 / 安装流程输入令牌；稍后再刷新；核对仓库配置 |
| 日志缺失 | 低级别日志在非开发模式下不打印，或日志文件被轮转覆盖 | 开启开发模式以打印全部日志；查看本地数据目录下的日志子目录 |
