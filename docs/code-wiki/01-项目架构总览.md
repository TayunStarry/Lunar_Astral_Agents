# 01 平台总览与快速上手

> [🏠 手册门户](README.md) ｜ [下一模块 ▶](02-核心系统-钛宇-月华.md)

## 一、功能介绍

星月智能（Lunar Astral Agents）是一款运行在本地 Windows 桌面上的 AI 智能体平台，模型推理与数据处理全部在本机完成，无需连接云端服务。平台内置两位人格智能体：月华是面向日常交流的核心智能体，承担多模态对话、语音表达与前端交互；琉璃是工具集扩展系统，承担文件管理、知识库与记忆库、截图标注以及扩展包运行。两位智能体可互相调用，用户既能与月华自然对话，也能让琉璃完成资料整理、检索与二次创作。由于模型、知识库、记忆与工具均保存在本地，平台适合重视隐私、需要离线使用，或希望长期沉淀个人知识的用户。

## 二、使用方法

1. 准备运行环境：使用 64 位 Windows 10 21H2 及以上系统，确认已安装 WebView2 Runtime（Win11 通常自带）；如需更快的推理速度或语音、图像能力，可另行安装 NVIDIA CUDA 运行库、FFmpeg 与 Vulkan 运行时（均为可选）。
2. 获取程序：下载发行版本（包含主程序与运行所需目录），或按构建说明自行构建得到主程序。
3. 启动程序：运行主程序，控制台会以全屏方式显示系统界面。
4. 打开智能体窗口：程序启动后自动打开月华与琉璃两个前端窗口；单独关闭窗口不会退出程序，可在控制台内重新打开。
5. 首次对话：在月华窗口中输入文字即可开始对话；首次启动需加载模型与初始化，耗时可能略长，请耐心等待。
6. 退出程序：在控制台内按 z 键或 Ctrl+C 退出，系统会依次关闭各子系统。

## 三、功能特性

| 特性 | 说明 |
|------|------|
| 多模态对话 | 支持文字、图片、音视频等多种输入形式的对话交互 |
| TTS 语音 | 将回复合成为自然语音，支持音色、语速等效果调整 |
| 图像生成 | 依据文字描述生成图像，可调节尺寸、步数与显存策略 |
| 富文本渲染 | 对话中的 Markdown、图表、公式与代码可结构化呈现 |
| 网络搜索 | 通过内置检索智能体获取网络信息并汇总摘要 |
| QQ 群聊适配 | 可将月华接入 QQ 群聊，按配置响应群消息 |
| 知识库 / 记忆库 | 在本地沉淀知识与对话记忆，支持检索与复用 |
| LTPX 工具扩展 | 通过扩展包为智能体增加新的工具与能力 |
| 纯本地推理 | 模型推理在本机完成，数据不出本机 |
| 零 Python 依赖 | 全平台以 Go 与 C/C++ 实现，运行时无需 Python 环境 |

## 四、运行参数

平台级参数决定服务端口与运行方式；完整配置与取值说明见 [08-构建运行与配置](08-构建运行与配置.md)。

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `BasicPort`（启动开关 `-basic-port`） | 平台基础端口：月华消息终端（`/`）、琉璃桌面（`/desktop/`）与 API 共用同一端口 | 36789 | 仅在被占用时修改 |
| `ModelPort`（`-model-port`） | 模型服务端口（llama-server，承载文本、多模态、嵌入与语音识别预设） | 基础端口 + 1（36790） | 通常无需修改 |
| `ProxyPort`（`-proxy-port`） | 代理监听端口，界定 Web 服务端口范围 | 基础端口 + 5（36794） | 通常无需修改 |
| `-developer` | 开发模式启动开关，日志不限流 | 关闭 | 仅排障时开启 |

> 除上述端口与开关外，模型、图像、语音、搜索等各类参数分散在配置文件中，统一查阅 [08-构建运行与配置](08-构建运行与配置.md)。

## 五、常见排故

| 现象 | 可能原因 | 处理办法 |
|------|----------|----------|
| 程序无法启动或闪退 | 运行环境不完整、模型文件缺失，或被安全软件拦截 | 核对运行环境是否齐全，确认模型文件完整，放行程序后重试 |
| 提示找不到模型 | 模型未放入指定目录，或配置中的模型路径有误 | 按 [08-构建运行与配置](08-构建运行与配置.md) 检查模型路径与预设 |
| 窗口空白或无法打开 | 未安装 WebView2 Runtime | 安装 WebView2 Runtime 后重新启动程序 |
| 端口被占用 | 默认端口已被其它程序占用 | 使用启动开关 `-basic-port` 更换基础端口，或关闭占用端口的程序 |
| 首次启动很慢 | 首次启动需加载并初始化模型 | 等待初始化完成；后续启动会明显加快 |
