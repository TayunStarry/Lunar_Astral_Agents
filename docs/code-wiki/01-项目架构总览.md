# 01 项目架构总览

> [🏠 文档地图](README.md) | [▶ 下一章](02-核心系统-钛宇-月华.md)

基于 **Go + TypeScript + C/C++** 的纯本地化桌面 AI 智能体平台，**零 Python 依赖**。所有 AI 推理均由本地引擎完成，无需网络。

---

## 1. 人格智能体

- **月华** — 「月亮的光华」，AI 桌面智能体核心。她的智慧根植于对 Qwen 大模型的蒸馏与量化，掌管多模态对话与 TTS 语音表达。
- **琉璃** — 「如水晶般澄澈」，工具集扩展系统。她专注于工具的纯粹性与操作的直观性，掌管文件管理、知识库/记忆库、截图标注等实用工具集。

月华与琉璃如同星与月——月华以温柔智慧照亮对话空间，琉璃以澄澈纯粹夯实工具基石。

## 3. 文件夹结构

```
Lunar_Astral_Agents/
├── lunar_astral/          # 核心系统：钛宇-月华
│   ├── adapters/          # Go↔JS 桥接层（goja 运行时）
│   ├── hierarchy/         # 前端资源（embed 嵌入）
│   │   └── assets/
│   │       ├── client/    # WebView 前端 UI
│   │       ├── prompts/   # AI 角色提示词模板
│   │       └── agentSystem.js  # TypeScript 编译产物
│   ├── model/             # 模型服务层（llama 代理 + TTS 引擎）
│   ├── server/            # HTTP 服务层 + 请求处理器
│   ├── TypeScript/        # TypeScript 智能体源码
│   ├── websocket/         # WebSocket 实时通信
│   └── bridging/          # QQ 群聊适配器（NapCat）
│
├── crystal_astral/        # 扩展系统：钛宇-琉璃
│   └── assets/            # 前端静态资源（embed 嵌入）
│
├── subsystem/             # 可复用子系统
│   ├── general_config/     # 全局配置中枢
│   ├── browser_client/     # WebView 窗口 + IP 发现
│   ├── file_manager/       # 文件管理 + 知识库/记忆库 + 扩展包
│   ├── image_processor/    # 图像生成 + 截图 + 视频关键帧
│   ├── logger_general/     # 彩色终端日志
│   ├── lunar_decoder/      # 月球编码（文件加密编解码器）
│   ├── agent_search/       # 智能网络检索（Chromedp）
│   ├── qwen3_tts/          # 语音合成（C++ GGML 引擎）
│   ├── qwen_asr/           # 语音识别（纯 C 引擎）
│   └── environment_repair/ # 运维工具箱
│
└── local_data/            # 本地运行时数据
    ├── models/            # AI 模型文件（GGUF/SafeTensors）
    └── package/           # 前端共享资源库（UI 模块 + 第三方库）
```

各目录内关键文件的代码级职责见后续章节：[02](02-核心系统-钛宇-月华.md)（月华）、[03](03-扩展系统-钛宇-琉璃.md)（琉璃）、[04](04-公共子系统.md)（公共子系统）、[05](05-独立AI引擎与运维工具.md)（独立 AI 引擎与运维）。

## 4. 数据流

```
用户输入 → HTTP API → Go 服务层 → JS 智能体 (goja) → llama-server (GGUF 推理)
                                                    → TTS 引擎 (C++ GGML)
                                                    → SD 引擎 (C++ GGML)
         → WebSocket 推送 → 前端渲染 (Markdown/Mermaid/ECharts)
```

WebSocket 消息链路详见 [07-依赖关系 §5](07-依赖关系.md)。

## 5. 技术栈

| 层级 | 技术 |
|------|------|
| 前端 UI | HTML5 + CSS3 + Vanilla JS (ES6+)，玻璃拟态风格，WebView 嵌入 |
| AI 智能体 | TypeScript → goja 运行时（Go 进程中执行） |
| 后端服务 | Go 1.26，HTTP API + WebSocket |
| 文本推理 | llama.cpp (llama-server)，GGUF 格式 |
| 图像生成 | stable-diffusion.cpp，GGUF 格式 |
| 语音合成 | Qwen3-TTS，C++ GGML 引擎 |
| 语音识别 | Qwen3-ASR，纯 C 引擎 + OpenBLAS |
| 数据存储 | SQLite (go-sqlite3)，本地嵌入式 |

引擎 CLI 参数参考见 [10-llama.cpp 参数参考](10-llama.cpp-参数参考.md) 与 [11-stable-diffusion.cpp 参数参考](11-stable-diffusion.cpp-参数参考.md)。

## 6. 前端共享资源机制

所有前端 UI 统一引用两个标准依赖文件，自动获得全量第三方库能力：

```html
<link rel="stylesheet" href="/file/read/package/standard_dependency/styles.css">
<script src="/file/read/package/standard_dependency/script.js"></script>
```

- 资源一律经 `/file/read/package/` 加载，**禁止 CDN 外部资源**，由 `file_manager` 静态服务提供。
- 具体注入的库清单见 [06-前端资源库 §6.1](06-前端资源库.md)。
