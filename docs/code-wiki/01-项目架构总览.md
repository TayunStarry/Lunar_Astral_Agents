# 01 项目架构总览

## 2. 数据流

```
用户输入 → HTTP API → Go 服务层 → JS 智能体 (goja) → llama-server (GGUF 推理)
                                                   → TTS 引擎 (C++ GGML)
                                                   → SD 引擎 (C++ GGML)
        → WebSocket 推送 → 前端渲染 (Markdown/Mermaid/ECharts/KaTeX)
```

核心对话链路（月华）：

```
前端 UI (WebView) → HTTP POST /write/message → Go 服务层 → JS 智能体 (goja)
                                            → llama-server (GGUF)
                                            → TTS 引擎   (C++ GGML)
                                            → SD 引擎    (C++ GGML)
        → WebSocket 推送 → 前端渲染
```

## 3. 技术栈

| 层级 | 技术 |
|------|------|
| 前端 UI | HTML5 + CSS3 + Vanilla JS (ES6+)，玻璃拟态风格，WebView2 嵌入 |
| AI 智能体 | TypeScript → 编译为 `agentSystem.js`，在 goja 运行时中执行 |
| 后端服务 | Go 1.26，HTTP API + WebSocket |
| 文本推理 | llama.cpp (llama-server)，GGUF 格式 |
| 图像生成 | stable-diffusion.cpp，GGUF 格式 |
| 语音合成 | Qwen3-TTS，C++ GGML 引擎 |
| 语音识别 | Qwen3-ASR，纯 C 引擎 + OpenBLAS |
| 数据存储 | SQLite (go-sqlite3)，本地嵌入式 |

---

## 4. 前端共享资源机制

所有前端 UI 统一引用两个标准依赖文件，自动获得全量第三方库能力：

```html
<link rel="stylesheet" href="/file/read/package/standard_dependency/styles.css">
<script src="/file/read/package/standard_dependency/script.js"></script>
```

静态资源一律通过 `/file/read/package/` 路径加载，**禁止从 CDN 引入任何第三方资源**。

## 5. 数据存储位置

| 路径 | 内容 |
|------|------|
| `local_data/models/` | AI 模型（GGUF/SafeTensors 等） |
| `local_data/package/` | 前端共享资源库 + 星月自定义模块 |

| `local_data/lunar_config.json` | 全局运行时配置（模型路径/桥接/模型分流） |
| `local_data/archive_config.json` | 分卷打包配置样例 |
