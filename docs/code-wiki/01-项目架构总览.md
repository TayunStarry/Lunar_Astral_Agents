# 01 项目架构总览

> [🏠 文档地图](README.md) | [▶ 下一章](02-核心系统-钛宇-月华.md)

基于 **Go + TypeScript + C/C++** 的纯本地化桌面 AI 智能体平台。所有 AI 推理均由本地引擎完成。

---

## 1. 人格智能体

- **月华** — AI 桌面智能体核心（`lunar_astral`），负责多模态对话与 TTS 语音表达。
- **琉璃** — 工具集扩展系统（`crystal_astral`），负责文件管理、知识库/记忆库、截图标注等工具集与 LTPX 扩展包运行时。

两者的角色设定由提示词模板定义（月华：`lunar_astral/hierarchy/assets/prompts/`；琉璃：`crystal_astral/assets/system_prompt.md`）。

## 3. 文件夹结构

```
Lunar_Astral_Agents/
├── lunar_astral/          # 核心系统：钛宇-月华
│   ├── adapters/          # goja 桥接层（Go 能力 → JS 全局函数）
│   ├── bridging/          # QQ 群聊适配器（NapCat）
│   ├── hierarchy/         # 前端资源（embed 嵌入）
│   │   └── assets/
│   │       ├── client/    # WebView 前端 UI
│   │       ├── prompts/   # AI 角色提示词模板
│   │       └── agentSystem.js  # TypeScript 编译产物
│   ├── model/             # 模型服务层（llama 代理 + TTS 引擎）
│   ├── server/            # HTTP 服务层 + 请求处理器
│   ├── TypeScript/        # TypeScript 智能体源码
│   └── websocket/         # WebSocket 实时通信
│
├── crystal_astral/        # 扩展系统：钛宇-琉璃
│   ├── agent/             # 内置智能体引擎
│   │   ├── AutoLTP/       # Auto-LTP 桌面智能体（多角色编排）
│   │   ├── WebLTP/        # Web-LTP 网络搜索智能体（真浏览器检索流水线）
│   │   ├── StarLTP/       # LTP9 插件引擎（goja 沙箱）
│   │   └── YaraLTP/       # LTP3 插件引擎（goja 沙箱）
│   ├── kokoro_tts/        # Kokoro-82M 语音合成（ONNX Runtime，纯 Go）
│   ├── qwen_asr/          # Qwen3-ASR 语音识别（cgo + 纯 C 引擎）
│   └── assets/            # 前端静态资源（embed 嵌入）
│
├── subsystem/             # 可复用子系统
│   ├── general_config/     # 全局配置中枢
│   ├── browser_client/     # WebView 窗口 + 会话管理 + IP 发现
│   ├── file_manager/       # 文件管理 + 知识库/记忆库 + 扩展包
│   ├── multimodal_analysis/ # 多模态素材预处理（生成/截图/音视频与动态图转码）
│   ├── logger_general/     # 终端日志
│   ├── lunar_decoder/      # 月球编码（文件加密编解码器）
│   ├── lunar_goja/         # 通用 goja JS 运行时环境（fetch/WebSocket）
│   ├── media_tools/        # 图片格式转换 + GGUF 元数据解析
│   ├── agent_search/       # 智能网络检索（Chromedp）
│   ├── qwen3_tts/          # 语音合成（C++ GGML 引擎）
│   ├── qwen_asr/           # 语音识别（纯 C 引擎，独立程序形态）
│   ├── environment_repair/ # 运维工具箱
│   ├── bridge_probe/       # NapCat 消息监听调试工具
│   ├── ltp3_keygen/        # LTP3 权限密钥生成器
│   ├── ltp9_keygen/        # LTP9 权限密钥生成器
│   └── LTP9-StarLTP/       # StarLTP 引擎独立发布副本（独立 Go 模块）
│
└── local_data/            # 本地运行时数据
    ├── models/            # AI 模型文件（GGUF/SafeTensors/ONNX）
    ├── package/           # 前端共享资源库（UI 模块 + 第三方库 + LTPX/LTP3/LTP9 包）
    └── database/          # 知识库/记忆库/调度等本地数据库
```

各目录内关键文件的代码级职责见后续章节：[02](02-核心系统-钛宇-月华.md)（月华）、[03](03-扩展系统-钛宇-琉璃.md)（琉璃）、[04](04-公共子系统.md)（公共子系统）、[05](05-独立AI引擎与运维工具.md)（独立 AI 引擎与运维）。

## 4. 数据流

```
用户输入 → HTTP API → Go 服务层 → JS 智能体 (goja) → llama-server (GGUF 推理)
                                                    → TTS 引擎 (C++ GGML / Kokoro ONNX)
                                                    → SD 引擎 (C++ GGML)
         → WebSocket 推送 → 前端渲染 (Markdown/Mermaid/ECharts)

工具扩展：月华 ⇄ 琉璃（LTPX AtoA：页面智能体 / 桌面智能体 / LTP3 / LTP9 插件引擎）
```

WebSocket 消息链路详见 [07-依赖关系 §5](07-依赖关系.md)。

## 5. 技术栈

| 层级 | 技术 |
|------|------|
| 前端 UI | HTML5 + CSS3 + Vanilla JS (ES6+)，玻璃拟态风格，WebView 嵌入 |
| AI 智能体 | TypeScript → goja 运行时（Go 进程中执行，共享环境由 `lunar_goja` 提供） |
| 后端服务 | Go 1.26，HTTP API + WebSocket |
| 文本推理 | llama.cpp (llama-server)，GGUF 格式 |
| 图像生成 | stable-diffusion.cpp，GGUF/SafeTensors 格式 |
| 语音合成 | Qwen3-TTS（C++ GGML 引擎）；Kokoro-82M（ONNX Runtime，琉璃内置） |
| 语音识别 | Qwen3-ASR（纯 C 引擎 + OpenBLAS） |
| 数据存储 | SQLite（知识库）；JSON 文件分片（记忆库） |

引擎 CLI 参数参考见 [10-llama.cpp 参数参考](10-llama.cpp-参数参考.md) 与 [11-stable-diffusion.cpp 参数参考](11-stable-diffusion.cpp-参数参考.md)。

## 6. 前端共享资源机制

所有前端 UI 统一引用两个标准依赖文件，获得全量第三方库能力：

```html
<link rel="stylesheet" href="/file/read/package/standard_dependency/styles.css">
<script src="/file/read/package/standard_dependency/script.js"></script>
```

- 资源一律经 `/file/read/package/` 加载，由 `file_manager` 静态服务提供。
- 具体注入的库清单见 [06-前端资源库 §6.1](06-前端资源库.md)。
