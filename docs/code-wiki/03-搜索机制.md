## 一、这是什么

搜索机制是月华的**联网查资料**能力。它不会直接读取搜索引擎的接口数据，而是驱动真实浏览器打开搜索引擎、进入结果页、逐页阅读正文，再用一个轻量模型把读到的内容压缩成摘要，最后汇成一份带来源的检索报告交给你。

因为用的是真实浏览器，遇到人机验证、弹窗广告时可以被人工介入处理，检索结果也更接近你自己打开浏览器的所见所得。

---

## 二、核心用途

- **查实时信息**：新闻、价格、版本发布、天气以外的即时事实。
- **跨页对比**：一次打开多个结果页，汇总不同来源的说法。
- **留痕可追溯**：报告保留来源地址与关键结论，便于你自己复核。
- **喂养后续对话**：访问过的页面会被登记为 `@U` 链接句柄，之后可继续引用、追问。

---

## 三、使用方法

### 3.1 发起一次搜索

直接用自然语言说明要查什么即可，例如：

- 「帮我查一下最近一周的 AI 新闻」
- 「看看 Qwen 最新版本有什么更新，前 3 页都看一下」
- 「对比一下这两个型号的显存需求」

月华会调用「联网探索」工具执行检索，并在对话里给出报告。你可以：

- 用「前 N 页 / 前 N 个结果」限定规模；
- 指定站点或时间范围；
- 要求只给结论，或要求逐条列出出处。

### 3.2 阅读检索报告

报告通常包含：

| 部分 | 内容 |
|------|------|
| 结论摘要 | 对问题的直接回答 |
| 分点依据 | 每条结论对应的来源要点 |
| 来源列表 | 访问过的页面地址 |

### 3.3 继续追问

- 访问过的网页会登记为 `@U.00x`，可以直接写句柄追问，例如 `@U.004 这篇里提到的参数是多少？`。
- 对已登记的链接再次提问，会优先读取缓存摘要；需要最新内容时会重新打开页面。

### 3.4 遇到验证码或弹窗

搜索过程中浏览器窗口是真实可见的。如果卡在验证码或广告遮罩上，你可以直接在窗口里操作；完成后智能体会继续读取页面。

### 3.5 搜索期间模型怎么安排

搜索使用固定的轻量模型（`light_reasoning`）做检索词提炼与逐页摘要。为腾出显存，搜索开始前会卸载主对话模型，结束后按后续请求需要重新加载。这属于内建行为，无需配置。

## 四、功能特性

| 特性 | 说明 |
|------|------|
| 真实浏览器检索 | 打开搜索引擎与结果页，读取页面正文而非接口片段 |
| 多页并行阅读 | 首页恒占 1 条，其余为同时打开的详情页 |
| 正文总预算 | 全部页面正文有统一提取上限，按页均分，避免单页吃满 |
| 滚动走查 | 对长页面分步滚动采集，适配懒加载站点 |
| 统一摘要 | 由轻量模型压缩成长度受控的摘要，避免上下文爆炸 |
| 近期访问标记 | 一段时间内访问过的链接会跳过重复进入，减少无谓重读 |
| 时长软上限 | 单次检索有总时长上限，超时以已采集信息收尾，不会无限挂起 |
| 人工可介入 | 浏览器窗口可见，验证码与弹窗可手动处理 |
| 结果句柄化 | 访问过的页面登记为 `@U` 句柄，可持续引用 |

## 五、运行参数

配置位于 `local_data/lunar_config.json` 的 `web_search` 分组，字段缺省或非法时沿用默认值。

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `max_pages` | 页面条目总数：首页恒占 1 条，其余为同时打开的详情页 | `6`（文件配置示例为 5） | 3~5 足够多数场景；硬上限 10 |
| `max_results` | 结果页解析的检索结果条数 | `15` | 保持默认 |
| `summary_max_chars` | 统一摘要的硬切断字符数 | `4096` | 上限 4096，不建议再放大 |
| `max_run_seconds` | 单次检索总时长软上限（秒） | `420` | 网络较慢时可适当调大 |
| `text_total_chars` | 全部页面正文的总提取硬上限（由所有页面均分） | `30000` | 长文较多时可调大，代价是上下文更重 |
| `scroll_settle_ms` | 滚动走查中每步之间的等待毫秒数 | `120` | 懒加载站点可调到 300~500 |
| `scroll_max_steps` | 单页滚动步数上限 | `40` | 超长页面可适当调大 |
| `cache_enabled` | 近期访问标记开关：近期访问过的链接跳过重复进入 | 开启 | 需要反复核对同一批页面时可关闭 |
| `cache_ttl_days` | 近期访问标记的有效期（天） | `7` | 按需调整 |

内建行为（不可配置）：

| 项目 | 值 |
|------|----|
| 检索词提炼与逐页摘要模型 | 固定 `light_reasoning` |
| 主模型处理 | 搜索前卸载，搜索结束后按需重载 |

## 六、常见问题

| 现象 | 可能原因 | 处理办法 |
|------|----------|----------|
| 检索很慢或超时 | 网络慢、页面反复加载，或目标站点反爬 | 缩小页数范围；稍后重试；必要时手动在浏览器里放行验证码 |
| 报告内容偏少 | 页面正文提取被站点限制，或结果页结构变化 | 指定更具体的站点或关键词；换一种问法 |
| 卡在验证码 | 站点要求人机验证 | 在可见的浏览器窗口里手动完成验证 |
| 同一个链接反复被跳过 | 近期访问标记生效 | 关闭 `cache_enabled`，或等待标记过期 |
| 搜索后对话变慢 | 主模型刚被卸载，正在重新加载 | 属正常现象，等待首轮应答完成 |
| 报告与网页内容不符 | 模型摘要存在压缩损失 | 直接引用该 `@U` 句柄追问，读取页面原文核对 |
| 浏览器窗口没出现 | 系统未安装可用的 WebView2 / 浏览器组件 | 安装 WebView2 Runtime 后重试 |
