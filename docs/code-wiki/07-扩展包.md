## 一、这是什么

扩展包是星月智能的**功能装载单位**：一个扩展包通常是一个目录，里面放着页面、脚本、样式和一份元数据。安装后它会以卡片形式出现在琉璃桌面上，打开即用；如果它声明了对外工具，月华也能直接调用它。

系统本身只提供基础能力（文件、记忆、绘图、搜索等），所有「具体工具」都可以用扩展包的形式接入，不必改动主程序。

---

## 二、核心用途

- **扩展工具**：把自研的小工具、工作台、演示页面装进平台。
- **能力复用**：一次安装，桌面可打开、对话可调用。
- **离线分发**：扩展包以本地目录或压缩包形态分发，不依赖应用商店联网。
- **团队协作**：把一套页面与工具打包给他人使用。

## 三、使用方法

### 3.1 安装扩展包

有两种来源：

| 来源 | 操作 |
|------|------|
| 本地压缩包 | 在琉璃桌面用「安装扩展包」选择 `.zip` / `.ltpx` 文件 |
| 本地目录 | 直接把包目录放入 `local_data/package/`，刷新前端即可看到 |

安装后包会落到 `local_data/package/<包目录>/`。

### 3.2 打开与使用

1. 在琉璃桌面找到该包卡片，点击打开。
2. 包页面在独立覆盖层或窗口中展示。
3. 声明了「后台保活」的包，关闭覆盖层后会保留页面现场（输入内容、编辑状态）；普通包关闭即释放，下次打开重新加载。

### 3.3 用对话调用扩展包

- 包若声明了对外工具，其能力会自动登记进月华的工具链。
- 你只需用自然语言描述任务，例如「用图表工作台把这份数据画出来」，无需记工具名。
- 被调用时，包页面会自动打开并接收执行指令，过程与结果在页面中实时呈现。

### 3.4 导出与删除

| 操作 | 位置 | 说明 |
|------|------|------|
| 导出 | 琉璃桌面包管理 | 把包目录打包为压缩文件，便于分发 |
| 删除 | 琉璃桌面包管理 | 删除本地包目录，桌面卡片同时消失 |

### 3.5 新建一个模块

琉璃桌面提供「创建模块」，支持：

- **从 URL 创建**：填入页面地址或本地 HTML 文件路径；
- **从 ZIP 创建**：上传打包好的 HTML 项目；
- **从本地目录创建**：指定一个已存在的项目目录；
- **启用 Mini-LTP**：勾选后由宿主注入通用页面操作智能体，页面无需自己实现智能体。

创建时会自动生成 `metadata.json`，你也可以手动补全字段。

### 3.6 扩展包目录长什么样

```
local_data/package/<包目录>/
├── metadata.json     # 身份与能力声明（必需）
├── index.html        # 入口页面
├── icon.webp         # 卡片图标
└── js/ css/ ...      # 页面资源
```

## 四、元数据字段（完整）

`metadata.json` 的字段与含义：

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| `id` | 包的唯一标识，用于调用与路由（如 `lunar.chart-studio`） | 是 |
| `title` | 桌面卡片与列表中显示的标题 | 是 |
| `description` | 一句话说明这个包能做什么 | 建议填写 |
| `icon` | 图标：相对路径（如 `icon.webp`）、`data:image/...;base64` 或图片 URL | 是 |
| `tags` | 形态标签，决定包的运行方式（见下表） | 是 |
| `background_retention` | 后台保活：`true` 时关闭覆盖层后保留页面现场 | 否 |
| `internal` | 是否为随程序发布的内置包；`true` 时不出现在桌面网格 | 否 |
| `url` | 外部链接或页面地址（从 URL 创建时写入） | 否 |
| `path` | 本地程序路径（exe / ps1 / bat / cmd / lnk） | 否 |
| `package_name` | 包目录名（缺省由标题或 ID 推导） | 否 |

### 形态标签（`tags`）

| 标签 | 含义 | 使用场景 |
|------|------|----------|
| `Zero-LTP` | 标准页面包：页面 + 元数据 + 工具定义 | 绝大多数自研工具台 |
| `Node-LTP` | 自带智能体的专用页面包：页面内置针对该应用的智能体 | 需要理解复杂界面的工具 |
| `Mini-LTP` | 通用页面操作：由宿主注入智能体，用键鼠/滚动完成操作 | 不想额外开发智能体的页面 |
| `Self-LTP` | 页面内自主循环：由页面上的开始/停止按钮驱动多轮自操作 | 演示、游戏、长流程页面 |
| `DeepDemos` | 演示包：自包含的网页演示与游戏合集 | 展示与体验 |
| `Windows-EXE` | 外部程序封装：调用本地可执行程序 | 接入现成桌面工具 |
| `DeepSeek` | 外部 API 接入示例 | 第三方模型服务演示 |

一个包可以带多个标签，例如同时是演示包又是 Mini-LTP 包。

## 五、页面可用的共享依赖

共享依赖随程序本体内置，页面按需引用（路径前缀 `/reliance/`），无需各自内嵌，也不需要联网下载。`local_data/package/` 只放带 `metadata.json` 的扩展包。

| 能力 | 依赖 |
|------|------|
| Markdown 渲染 | marked.js |
| 数据图表 | ECharts |
| 流程图 / 时序图 | Mermaid |
| 代码高亮 | highlight.js（含主题样式） |
| 数学公式 | KaTeX（含自动渲染扩展与样式） |
| 二维码 | QRCode.js |
| 图标 | Font Awesome |
| 图片 / 音视频预览 | multimedia_preview（统一预览模态） |

只引用页面真正用到的库即可；未使用的库不会加载。

## 六、扩展包如何被月华调用

- 包在元数据里声明对外工具后，工具会被登记进月华的工具链。
- 调用时，月华只传「目标包 + 自然语言指令」，由包侧自行完成操作并回传结果。
- 页面需要能被正常打开；被调用时系统会自动打开它。
- 若包长时间无响应，会按超时兜底返回失败，不会无限挂起。

## 七、常见问题

| 现象 | 可能原因 | 处理办法 |
|------|----------|----------|
| 桌面看不到新包 | 未放入 `local_data/package/`、元数据缺失/格式错误，或未刷新 | 检查目录与 `metadata.json`，刷新琉璃前端 |
| 卡片图标空白 | `icon` 路径错误或文件不存在 | 确认图标文件与字段路径一致 |
| 包打开后白屏 | 入口页面缺失、资源路径写错，或脚本报错 | 打开浏览器控制台（开发模式）查看报错 |
| 月华不知道这个工具 | 包未声明对外工具 | 在元数据中补上工具声明后刷新 |
| 被调用时没反应 | 页面无法接收执行指令，或包未打开 | 确认包可正常打开，且页面实现了指令入口 |
| 关闭后输入内容丢失 | 未开启后台保活 | 设置 `background_retention: true` |
| 安装压缩包失败 | 压缩包结构不对（缺少顶层目录或元数据） | 确认压缩包顶层是包目录，且包含 `metadata.json` |
