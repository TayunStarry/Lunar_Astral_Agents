# 05 绘画机制

> [🏠 手册门户](README.md) ｜ [◀ 上一模块](04-观影机制.md) ｜ [下一模块 ▶](06-记忆机制.md)

## 一、这是什么

绘画机制是月华的**本地出图**能力，由本地扩散模型驱动，不联网、不上传素材。它支持四类创作：

1. **文生图**：按文字描述画风景、物品、场景与氛围图；
2. **图生图**：以一张已有图片为底，按描述改画风、换场景、换服饰；
3. **角色立绘**：画月华、琉璃或你自建的角色，支持 Q 版；
4. **合照**：把任意多个角色放进同一张画里。

图片生成后可再做 4 倍超分辨率放大。

---

## 二、核心用途

- **角色形象**：稳定画出月华 / 琉璃 / 原创角色的立绘与合照。
- **场景插图**：为故事、日记、演示配图。
- **改图**：在保留构图的前提下换风格、换背景、换服装。
- **画质提升**：对已有图片做超分放大。

---

## 三、使用方法

### 3.1 用自然语言提出需求

直接用日常语言描述即可，例如：

- 「画一张月华在雨夜街头的立绘」
- 「画一只在窗台上打盹的橘猫，暖色调，16:9」
- 「把 `@I.003` 改成雪景」
- 「画一张月华和琉璃的 Q 版合照，在咖啡馆」

月华会自动选择合适的工具，并把参数补全。你不需要记工具名。

### 3.2 角色立绘

- **内置角色**：直接说「月华」「琉璃」，会使用内置的外观底板与默认服装。
- **通用角色**：说「通用-女」「通用-男」，并补一句外观描述。
- **自建角色**：先让月华「记住这个角色」，它会创建一条可复用的角色档案（名字、性别、基础外观、全尺寸与 Q 版默认服装），之后直接叫名字即可。
- **Q 版**：在需求里加「Q 版 / 二头身」。

立绘是纯文生图，不依赖参考图，因此细节与清晰度通常最好。

### 3.3 合照

- 说明参与者即可，例如「月华、小月、还有一位穿风衣的旅人」。
- 内置与自建角色直接写名字，临时角色写外观描述。
- 可以指定环境；不指定时会随机使用预设背景。
- 加「Q 版」可整张切换为萌系比例。

### 3.4 图生图

1. 先引用一张图片句柄，例如 `@I.003`。
2. 说明要怎么改。强度可按目标选择：

| 目标 | 建议强度 |
|------|----------|
| 只改画风 / 光影 | 0.2 ~ 0.4 |
| 换服饰配色 | 0.4 ~ 0.6 |
| 换背景 / 地点 | 0.8 ~ 0.9（常用 0.85） |
| 0.95 以上 | 会重排人物姿态 |

3. 参考图是任务级状态，每次创作都会重新绑定，不会沿用上一次的图。

### 3.5 超分放大

- 对指定图片说「把 `@I.004` 放大到 4 倍」。
- 或不指定对象，直接说「把刚才那张放大」。

### 3.6 查看已有作品

让月华「看看最近的画」，会返回最近图片的句柄与描述，可继续引用、放大或改图。

## 四、功能特性

| 特性 | 说明 |
|------|------|
| 纯本地推理 | 扩散模型、VAE、提示词编码全部在本机运行 |
| 四类创作 | 文生图 / 图生图 / 角色立绘 / 合照 |
| 角色档案 | 自建角色写入本地角色库，可长期复用 |
| 方案化模型 | 扩散模型、VAE 与提示词编码成套声明，启动时按 `default_scheme` 应用 |
| 比例预设 | 1:1、4:3、3:4、16:9、9:16、3:2、2:3 |
| 超分辨率 | 4 倍重建，可对任意图片句柄执行 |
| 显存守卫 | 画图前检查可用显存，不足时先卸载聊天模型 |
| VAE 退让 | 显存不足时按「整帧 GPU → 直接卷积 → CPU」退让，避免分片造成的硬边方块 |
| 参考图推导尺寸 | 图生图与合照按参考图比例自动推导输出尺寸 |

## 五、运行参数

### 5.1 绘制相关配置（`local_data/config/painter.json`）

> 绘图相关配置统一放在 `local_data/config/painter.json`，采用扁平结构：`default_scheme`、扩散参数与各模型方案全部在顶层平铺，方案名本身就是顶层键。`general.json` 不再包含这些字段。

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| `allow_diffusion` | 是否允许运行扩散生成 | `true` | 不需要绘图时关闭以省资源 |
| `image_vram_guard` | 画图前显存守卫开关 | `true` | 保持开启 |
| `image_vram_guard_mib` | 画图前可用显存阈值（MiB） | `8192` | 按显卡容量调整 |
| `sd_offload_to_cpu` | 权重内存卸载模式：`auto` / `always` / `off` | `auto`（配置示例为 `always`） | 12GB 卡保持 `always`；≥16GB 可 `off` 提速 |
| `sd_te_on_cpu` | 提示词编码器在 CPU 运行 | `false`（配置示例为 `true`） | 显存紧张时开启 |
| `sd_vae_tiling` | VAE 分片解码策略 | `off` | 非必要不启用：分片接缝会出现硬边方块 |
| `sd_vae_tile_size` | 分片尺寸（latent 单元） | 空（引擎默认 32×32） | 启用分片时用 64×64 |
| `sd_vae_tile_overlap` | 分片重叠比例 | `0`（引擎默认 0.5） | 启用分片时用 0.25 |
| `sd_vae_backend` | VAE 解码后端：`auto` / `gpu` / `cpu` | `auto` | 保持 `auto`：整帧 GPU → 直接卷积 → CPU 三档退让 |
| `sd_vae_conv_direct` | 整帧放不下时改用直接卷积 | 开启 | 保持开启：省一半显存且与 CPU 全帧等价 |
| `sd_max_vram` | 显存预算（GiB） | 空（自动） | 显存不足时给 9~10 |
| `sd_sampler` | 采样器 | `auto`（不传参） | 保持 `auto`，对比实验再指定 |
| `sd_scheduler` | 调度器 | `auto`（不传参） | 保持 `auto` |
| `sd_flow_shift` | Flow 模型偏移 | `0`（自动） | 特殊模型才需调整 |
| `sd_diffusion_fa` | 扩散模型使用 flash attention | 开启 | 排查块状伪影时可关闭对比 |
| `sd_steps` | 兜底步数（方案未配置步数时生效） | `40` | 草图 30，常规 40，精细 50~60 |
| `sd_image_size` | 默认输出边长（像素） | `1024` | 会归一化为 32 的倍数 |
| `pixel_budget_mp` | 图生图/合照按参考图推导尺寸时的总像素预算（百万像素） | `1.6` | 超宽/超长画幅才需要调大 |
| `img2img_cfg` | 图生图的提示词引导系数覆盖值 | 不设（按 1.0） | 引导蒸馏模型必须 1.0；换非蒸馏模型才设 2~3 |

### 5.2 模型方案（`painter.json` 顶层方案键）

| 参数 | 说明 | 建议 |
|------|------|------|
| `default_scheme` | 默认启用的方案键名 | 出厂为 `quality` |
| `<name>.label` | 方案显示名 | 如「速度优先 / 质量优先」 |
| `<name>.diffusion_model` | 扩散模型路径 | 与 VAE、提示词编码模型成套匹配 |
| `<name>.variational_model` | VAE 模型路径 | 必须与扩散模型配套 |
| `<name>.prompt_analysis_model` | 提示词分析模型路径 | 与扩散模型配套 |
| `<name>.prompt_mmproj_model` | 多模态提示词投影模型路径 | **保持留空**：对出图无影响，只会多占内存 |
| `<name>.real_esrgan_model` | 4× 超分辨率模型路径 | 需要超分时配置 |
| `<name>.steps` | 方案推荐步数 | turbo 建议 8，quality 建议 40 |

方案名不固定：除 `default_scheme` 与扩散参数键外，顶层以对象形式出现的键都会被识别为方案（出厂为 `turbo` / `quality`）。未知标量键会被忽略并打印 WARN，旧版 `models` / `diffusion` / `schemes` 嵌套节不再解析、仅提示迁移。默认方案只在启动时应用一次，运行期不支持切换；需要更换模型请修改 `default_scheme` 后重启。

### 5.3 角色档案

自建角色保存在 `local_data/database/character.db` 的角色表中，字段包括：名字、性别、基础外观、默认全尺寸服装、默认 Q 版服装。

## 六、常见问题

| 现象 | 可能原因 | 处理办法 |
|------|----------|----------|
| 提示显存不足 | 尺寸过大、缺少显存预算 | 下调尺寸；设定 `sd_max_vram`；保持权重内存卸载开启 |
| 出图很慢 | 步数偏高、尺寸偏大，或显存充裕却仍在卸载权重 | 步数降到 30 左右；尺寸回到 1024；显存充裕时 `sd_offload_to_cpu=off` |
| 图糊、五官或肢体崩坏 | 尺寸过小 | 尺寸提到 1024 以上（512 只有约 1/16 像素量） |
| 画面出现纯色硬边方块 | VAE 解码退化成分片 | 保持 `sd_vae_backend=auto` 与 `sd_vae_conv_direct=true` |
| 发灰、塑料感 | 引导系数（CFG）偏高 | 引导蒸馏模型请保持 1.0（此时负面提示词不生效） |
| 图生图明显不如文生图 | 参考图本身模糊/带水印，或强度偏低 | 需要「画一张新的」请用立绘或文生图；必须保留构图时把强度抬到 0.6~0.85 |
| 改得太多或太少 | 图生图强度不合适 | 按上文强度表调整 |
| 每次构图都一样 | 使用了固定随机种子 | 清空种子后重试 |
| 画出来的人物不像 | 未使用角色立绘，而是文生图描述人物 | 明确说「画月华的立绘」，由立绘入口生成 |
