# 14 统一资源句柄与多模态引用使用手册

> [🏠 手册门户](README.md) ｜ [◀ 上一模块](13-控制台TUI系统.md)

月华在对话中需要稳定地引用**任何**资料：文本文件、图片、视频、音频、表格。所有这些资源共用**同一套句柄文法**，只以类型码区分场景；多模态窗口负责管理图片的可见范围。本手册说明句柄文法、资源收录与引用方式。

---

## 一、功能介绍

统一资源句柄让月华在对话中稳定地引用每一份已收录的资料。无论是源码、Markdown、配置，还是图片、视频、语音，都会得到一个形如 `@D.003` / `@I.007` 的句柄，之后用该句柄指代这份资料。

- **统一文法**：`@<类型码>.<序号>`，类型码区分场景；可加锚点精确定位到某节或某几行。
- **一次收录，长期可用**：句柄持久化且序号永不复用——程序重启后同一句柄仍指向同一份资料。
- **本体与句柄解耦**：资料原文由内容仓库保存；原文被回收时句柄连同目录行一并移除，失效句柄不滞留（后续解析返回「资源不存在」）。
- **同一内容只存一份**：无论来自本地上传还是渠道传入，相同内容只保留一份。
- **按结构引用**：文档按标题层级建立结构，引用时定位到具体章节后整段展开，不会出现半句截断。

句柄文法：

| 类型码 | 含义 | 示例 |
|--------|------|------|
| `@D` | 文档（源码 / Markdown / 纯文本 / 配置） | `@D.003` |
| `@I` | 图片 | `@I.007` |
| `@V` | 视频 | `@V.001` |
| `@A` | 音频 | `@A.002` |
| `@T` | 表格 | `@T.005` |

可选锚点（用于段落级引用）：

| 锚点 | 含义 | 示例 |
|------|------|------|
| `|§n` | 第 n 节（按文档结构编号） | `@D.003\|§4` |
| `|L起-止` | 第 起~止 行（1 基，含端点） | `@D.003\|L120-168` |

序号不足三位补零；超过 999 后自然变为四位。

## 二、使用方法

### 2.1 向对话注入资源

| 资源类型 | 注入方式 | 系统行为 |
|----------|----------|----------|
| 文本文件 | 发送或拖入文本类文件 | 收录为文档资源并建立结构，回执 `[已收录] @D.003 文件名.md` |
| 工作区文件 | 在消息里写 `@相对路径/文件名.ext`（无需先上传） | 按需收录为文档资源，原文件只读保留 |
| 图片 | 直接发送图片消息 | 登记为 `@I.00x`，在图片后附句柄旁注 |
| 视频 | 发送视频，或由渠道转入 | 本地化后登记为 `@V.00x`，正文中置换为「句柄 + 内容理解」 |
| 音频 | 发送语音/音频，或由渠道转入 | 转写后登记为 `@A.00x`，正文中置换为「句柄 + 语音转写」 |
| 表格 | 发送表格类文件 | 登记为 `@T.00x` |
| 工具产出 | 截图、绘图、超分结果 | 登记为对应类型句柄，窗口内可按句柄引用 |

### 2.2 引用资源

1. **载入引用**：点击消息里出现的资源图标（回执 `[已收录]` 旁），把该句柄载入输入框上方。
2. **组合提问**：在引用之后写上你的问题；发送时句柄随消息下发，系统在对应资源里按问题定位段落后再回答。
3. **直接书写**：也可以直接在消息里写句柄，如 `@D.003|§4 这段说的是什么？`。
4. **按文件名引用（无需先上传）**：写 `@文件名.ext` 或 `@相对路径/文件名.ext` 即可让系统按需收录，如 `@AGENTS.md`、`@subsystem/build_common.ps1`。
   - 同名不同路径的文件互不干扰；同一路径重复引用复用同一句柄。
   - 工作区文件只读收录，**绝不移动或删除你的项目文件**。
   - 仅支持文本类扩展名，且限制在 100MB 以内。
   - 文件内容改动后再次引用会生成新的句柄。
5. **去重与移除**：同一引用重复载入会自动去重；不需要时在输入框上方的图标条里移除。

### 2.3 引用按钮的两种形态

| 形态 | 出现位置 | 说明 |
|------|----------|------|
| 汇总引用图标 | 助手消息（`[已收录] @D.003 文件名` 回执） | 较大的圆角按钮，点击载入输入框 |
| 行内引用按钮 | 你发送的消息气泡内 | `@D.003` / `@文件名.ext` 渲染为可点击小按钮 |

> 只发文件不提问时，该气泡正文留空、只显示「文件」徽标，内容由收录回执承载。

### 2.4 让月华查阅资源

- **查看资料**：列出全部资料的句柄、类型与描述；只看图片时可列出图片句柄。
- **按关键词找资料**：跨资源定位到「哪份资源的哪一节」，再取正文。
- **看文档结构**：返回大纲，每节附带可引用的章节锚点与行区间、字数。
- **取正文**：按句柄取回完整段落；图片/视频/音频返回内容描述（不注入本体，上下文成本极低）。

引用时正文何时自动注入、何时按需读取（成本与体验的折中）：

| 资源情况 | 行为 |
|----------|------|
| 小文件（≤6000 字符且无标题结构） | 收录后在上下文构建阶段**自动注入全文** |
| 有标题结构的文档 | 按你的问题**筛出最相关的若干节**注入（预算 12000 字符），每节带锚点 |
| 大文件（超预算 / 无结构且 >6000 字符） | **只注入资源卡片**（标题、体积、节数、摘要），正文由月华按需读取 |

### 2.5 在多模态窗口中查看与管理图片

- 查看可用图片：列出图片句柄与内容描述（按登记时间倒序）。
- 查看图片内容摘要：按句柄取描述；占位文本里已有描述时通常无需取，需要细节时可带针对性提问。
- 图片超分：按句柄（或最近作品）对已有图片做超分辨率放大。
- 窗口范围：模型只能看到最近 20 张图片本身，更早的只以文字占位出现。

### 2.6 用图片作为绘图参考

1. 在含图消息里说明绘图意图（例如「把 `@I.003` 改成雪景」），并指定要参考的图片句柄。
2. 系统把该句柄对应的源图准备为本次创作的参考图，并交给绘制者执行图生图。
3. 参考图是任务级状态：每次创作开工时重新绑定，不会跨任务沿用旧图。
4. 输出尺寸随参考图比例自动推导；改画风 / 换场景 / 大改构图的强度由绘制者按意图选择。

## 三、功能特性

| 特性 | 说明 |
|------|------|
| 句柄命名 | `@<类型码>.<序号>`，不足三位补零，超过 999 变四位 |
| 序号分配 | 收录时分配、**永不复用**；程序重启后从资源名录重建计数 |
| 统一收录 | 本地上传的文件只登记不复制；工作区文件只读收录；渠道仅给链接的资源由系统下载后落盘；同一内容无论来源只存一份 |
| 内容去重 | 相同内容多次收录只保留一份实体 |
| 文档结构 | 按标题层级建立章节与行区间，引用时整段取回，不半句截断 |
| 资源名录 | 句柄、元数据与文档结构集中保存，供查阅与搜索 |
| 本体回收 | 按配额（默认 2GB、单资源 20MB）与保留等级回收原文；只回收副本，目录行随实体一并移除，失效句柄不滞留 |
| 源文件保护 | 收录一律只读进行，**绝不移动或删除来源文件** |
| 引用注入分级 | 小文件自动注入全文；有结构文档按问题选段注入；大文件只给资源卡片 |
| 失效句柄清理 | 源文件丢失/损坏的句柄在读取、列表、大纲、图片解析任一入口被触碰即移除，并返回「文件丢失或损坏，请使用其他句柄」 |
| 跨资源搜索 | 在标题、摘要、标签、文件名与段落标题中匹配关键词 |
| 图片可见性 | 句柄长期有效；「可见性」由上下文表达——最近 20 张图片是真实多模态消息，更早的只剩 `[@I.00x]（描述）` 文本 |
| 图生图参考 | 按句柄把源图准备为图生图基座，输出尺寸随参考图比例推导，参考图属任务级状态 |
| 图生图强度档位 | 改画风/光影 `0.2~0.4`；换服饰配色 `0.4~0.6`；换背景/地点 `0.8~0.9`（推荐 0.85）；`0.95+` 会重排人物姿态 |
| 图片超分辨率 | 按句柄或最近作品对已有图片放大 |

## 四、运行参数

句柄与资源名录本身无需配置参数；与资源归档、图片、多模态相关的配置项如下：

| 参数 | 说明 | 默认值 | 建议 |
|------|------|--------|------|
| 资源名录路径（`-archive-db`） | 统一资源名录所在文件 | `local_data/database/archive.db` | 一般无需修改 |
| 内容仓库配额（`-archive-quota-mb`） | 原文存量上限（MB），超限按保留等级与最久未用回收 | 2048 | 磁盘紧张时下调；回收不影响句柄 |
| 单资源体积上限（`-archive-max-blob-mb`） | 单份资料入仓上限（MB） | 20 | 大文件较多时可上调 |
| 回收周期（`-archive-gc-interval-min`） | 自动回收周期（分钟），0 表示关闭 | 30 | 磁盘紧张时缩短 |
| `video_input` | 视频解读的输入方式：`file`（写入媒体目录后引用）或 `frames`（本地抽帧为图片序列） | file | 目标模型不支持本地文件引用时改用 frames |
| 多模态模型路由 | 多模态模型名称 / 服务地址 / 密钥 | 本地同源服务 | 需指向其它服务时修改 |

与资源归档相关的其余配置字段与含义见 [08-构建运行与配置](08-构建运行与配置.md)。

## 五、常见排故

| 现象 | 可能原因 | 处理办法 |
|------|----------|----------|
| 图片不显示 | 源图地址失效、图片格式不受支持，或图片已超出窗口范围 | 重新发送图片获取新句柄；确认格式受支持；确认该图仍在最近 20 张内 |
| 句柄引用取不到内容 | 句柄序号不存在（非本程序分配），或资源已被显式删除 | 查看可用句柄清单；不要手写句柄 |
| 提示「本体已回收」 | 该资源的原文已被内容仓库按配额回收，仅剩名录与描述 | 句柄仍然有效，可继续按描述使用；需要原图时重新发送，或上调配额 |
| 文档引用只回了摘要与大纲 | 同上：正文已被回收 | 上调配额，或重新发送该文件 |
| 文档引用只回了开头几段 | 问题文本与任何段落都无词法重叠 | 把问题写得更贴近文档用词，或先看结构再按 `|§n` 定向引用 |
| 文件回执没有出现 | 文件扩展名不在文本类白名单内，或类型为媒体 | 确认扩展名受支持；媒体资源请在消息中查看对应句柄旁注 |
| 写 `@文件名` 后月华没读到文件 | 解析顺序里都未命中：名录无记录、工作区与数据目录都没有该文件 | 确认路径相对**项目根**书写；查看是否已收录；确认扩展名属文本类白名单 |
| 名录里出现多条同名资源 | 同名但**路径不同**的不同文件（预期行为） | 引用时带上目录前缀（如 `@sub/build.ps1`） |
| 用户消息里的 `@文件名` 没变成按钮 | 浏览器缓存了旧的静态前端资源 | 强制刷新前端页面（Ctrl+F5）后重新发送 |
| 导入文件后原文件不见了 | 早期版本的缺陷（会把来源文件移入仓库） | 升级后不再发生；若确认丢失，检查 `local_data/multimedia/` |
| 月华似乎「通读」了很大的文件 | 该文件无标题结构且未超 6000 字符，走整篇注入 | 属预期行为；要更省上下文可把大文件拆分为带标题的文档 |
| 图生图提示「参考图未在当前任务中正式选定」 | 早期版本的缺陷 | 升级后不再发生 |
| 导入文件内容不全 | 文本文件超过单次导入上限被截断 | 拆分文件后分别导入 |
| 动态图不能播放 | 动态图（GIF / APNG / 动态 WebP）在对话中按静态帧处理，窗口内不做动画播放 | 如需逐帧理解，改用序列帧输入方式；或转成静态图后发送 |
| 视频理解失败 | 输入方式与目标模型能力不匹配 | 把 `video_input` 在 file 与 frames 之间切换后重试 |
| 图片描述缺失 | 来源地址为空，或视觉模型调用失败 / 返回空 | 重新发送图片；或按句柄发起一次描述请求 |
| 磁盘占用增长较快 | 内容仓库按配额保留原文 | 下调 `-archive-quota-mb`、缩短 `-archive-gc-interval-min`，或及时清理不再需要的大件 |
