## 🏛️ 星尘 - 鉴权智能体

### 职能定位

**星尘**将是星月智能的安全守护者，负责：
- 用户身份认证与授权
- 访问控制管理
- 权限验证与审计
- 安全日志记录

### 核心功能

| 功能模块 | 说明 |
|----------|------|
| **身份认证** | 支持多种认证方式（用户名密码、OAuth、生物识别） |
| **权限管理** | 基于角色的访问控制（RBAC） |
| **会话管理** | 安全的会话生命周期管理 |
| **审计日志** | 完整的操作记录与追踪 |

### 技术实现

基于 `bridge_adapter` 模块构建：

| 模块 | 文件 | 职责 |
|------|------|------|
| `pkg/lunar` | `lunar.go` | Lunar协议适配 |
| `pkg/napcat` | `napcat.go` | 消息协议适配 |
| `pkg/config` | `config.go` | 配置管理 |
| `pkg/message` | `message.go` | 消息处理 |

---

## 🏛️ 星辉 - 代理智能体

### 职能定位

**星辉**将是星月智能的网络桥梁，负责：
- 统一API网关
- 请求路由与转发
- 负载均衡与容错
- HTTPS加密代理

### 核心功能

| 功能模块 | 说明 |
|----------|------|
| **API网关** | 统一入口，请求路由 |
| **反向代理** | 透明代理，负载均衡 |
| **SSL终止** | HTTPS解密与加密 |
| **请求过滤** | 请求校验与限流 |

### 技术实现

基于 `proxy` 模块构建：

| 文件 | 职责 |
|------|------|
| `proxy.go` | 代理核心逻辑 |
| `certs/` | SSL证书管理 |
