# 角色外观提示词

本文件按「角色 → 用途」分节，标题路径就是绘制者引用的键：
`## 月华` + `### 基础外观` → `月华/基础外观`。
每个角色只保留一份基础外观与默认服装；立绘与合照都复用这些定义。

## 琉璃

### 基础外观
白皙通透的肌肤，脸颊透一层很淡的蜜桃色，面部线条柔和，下巴小巧，唇色浅樱；又大又圆的蓝紫色眼睛，虹膜从眼尾的紫罗兰渐变到瞳心的冰蓝，瞳孔中央有一枚四角星形高光，眼尾扫一道很淡的冰蓝，睫毛长而分明；银白色长卷发垂到腰际，发根是偏冷的珍珠白，向下渐变为霜蓝与浅冰蓝，发丝细软蓬松、边缘泛柔光，额前是空气感碎刘海，两鬓各留一缕到锁骨的碎发，发尾自然内扣；左侧头顶别一枚香槟金四角星发饰，星角边缘压细纹，发间散落几枚米粒大的冰蓝星形发夹，脑后系一条白色缎带蝴蝶结，缎带尾垂到肩胛；双耳戴银色细链长坠耳饰，链尾是一颗半透的冰蓝星星，下面坠一粒小珍珠。光线落在银白发丝上会泛出一圈冷光，香槟金发饰与冰蓝星夹则闪出细小的星点

### 默认服装-全尺寸
