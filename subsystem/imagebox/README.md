# Imagebox 子系统文档

## 1. 系统概述

Imagebox 是 Lunar Astral Agents 的文件组合工具子系统，主要功能是将当前目录下的所有文件打包成 ZIP 格式，然后附加到 PNG 模板文件后面，生成一个可以同时作为图片查看和文件容器的组合文件。

## 2. 功能特点

- **文件组合**：将多个文件组合成单一文件，便于传输和存储
- **双重用途**：生成的文件既可以作为图片查看，又可以作为ZIP文件解压
- **自动排除**：智能排除不需要打包的文件（如输出文件、模板文件等）
- **内存操作**：在内存中创建ZIP文件，提高处理速度
- **命令行控制**：通过命令行参数灵活指定模板文件和输出文件

## 3. 核心组件

### 3.1 FileCombiner 结构体

- **PNGTemplate**：PNG模板文件路径
- **OutputFile**：输出文件路径
- **Excluded**：需要排除的文件映射

### 3.2 核心方法

- **NewFileCombiner()**：创建新的文件组合器实例
- **Combine()**：执行文件组合操作
- **createZipInMemory()**：在内存中创建ZIP文件
- **shouldExclude()**：检查文件是否应该被排除

## 4. 工作原理

1. **创建临时ZIP**：在内存中创建包含当前目录所有文件的ZIP文件
2. **读取PNG模板**：读取指定的PNG模板文件数据
3. **组合文件**：将PNG数据和ZIP数据依次写入输出文件
4. **智能排除**：自动排除输出文件、模板文件、ZIP文件等不需要打包的文件

## 5. 使用方法

### 5.1 基本用法

```bash
# 使用默认配置（template.png 作为模板，生成 combined.png）
./imagebox.exe

# 指定自定义PNG模板文件
./imagebox.exe -png ./my-template.png

# 指定自定义输出文件路径
./imagebox.exe -output ./my-output.png

# 同时指定模板和输出文件
./imagebox.exe -png ./template.png -output ./result.png
```

### 5.2 操作流程

1. **准备工作**：将需要打包的文件放置在同一目录下
2. **执行命令**：运行imagebox工具，指定模板文件和输出文件（可选）
3. **查看结果**：生成的文件可以直接作为图片查看
4. **提取文件**：将生成的文件重命名为.zip或使用解压缩工具打开提取内容

## 6. 排除规则

Imagebox 会自动排除以下类型的文件：

- **输出文件**：避免将生成的文件包含在内
- **PNG模板**：避免将模板文件包含在内
- **ZIP文件**：避免将其他ZIP文件包含在内
- **自身可执行文件**：避免将工具自身包含在内

## 7. 技术细节

### 7.1 文件结构

生成的组合文件结构如下：

```
[PNG文件数据][ZIP文件数据]
```

- **PNG文件数据**：完整的PNG文件内容，包含所有PNG头部和数据
- **ZIP文件数据**：完整的ZIP文件内容，包含所有文件的压缩数据

### 7.2 内存操作

- 使用 `bytes.Buffer` 在内存中创建ZIP文件，避免临时文件的创建和删除
- 内存操作提高了处理速度，特别适合处理小到中等大小的文件

### 7.3 文件遍历

- 使用 `filepath.Walk` 遍历当前目录下的所有文件
- 对每个文件进行检查，确定是否需要包含在ZIP中

## 8. 依赖关系

- **Go语言**：开发语言，需要Go环境编译
- **标准库**：仅使用Go标准库，无第三方依赖
  - `archive/zip`：用于创建ZIP文件
  - `bytes`：用于内存操作
  - `flag`：用于解析命令行参数
  - `io`：用于文件读写
  - `os`：用于操作系统交互
  - `path/filepath`：用于文件路径操作
  - `strings`：用于字符串处理

## 9. 注意事项

- **文件大小限制**：由于使用内存操作，处理非常大的文件可能会导致内存不足
- **PNG文件兼容性**：确保使用的PNG模板文件是有效的，否则生成的文件可能无法正常查看
- **提取方法**：要提取文件，需要将生成的文件重命名为.zip或使用支持此格式的解压工具
- **目录结构**：生成的ZIP文件会保持原始的目录结构

## 10. 应用场景

- **文件分发**：将多个文件打包成单一文件，便于网络传输
- **资源打包**：将应用程序的资源文件打包成单一文件
- **隐藏数据**：在图片中隐藏文件数据，实现简单的信息隐藏
- **数据备份**：将重要文件打包成图片格式，便于存储和识别

## 11. 示例

### 11.1 基本示例

```bash
# 当前目录包含以下文件：
# - template.png
# - config.json
# - data.txt
# - README.md

# 执行命令
./imagebox.exe

# 生成 combined.png 文件
# 该文件可以：
# 1. 直接双击作为图片查看（显示template.png的内容）
# 2. 重命名为combined.zip后解压，得到config.json、data.txt、README.md等文件
```

### 11.2 自定义模板示例

```bash
# 使用自定义模板
./imagebox.exe -png ./logo.png -output ./app-resources.png

# 生成的app-resources.png文件：
# - 作为图片查看时显示logo.png的内容
# - 解压后得到当前目录的所有文件
```

## 12. 故障排除

- **错误：无法读取PNG模板**：检查模板文件路径是否正确，文件是否存在且可读
- **错误：无法创建输出文件**：检查输出文件路径是否可写，磁盘空间是否充足
- **生成的文件无法作为图片查看**：确保使用的PNG模板文件是有效的PNG格式
- **生成的文件无法解压**：确保ZIP文件生成过程没有错误，尝试使用不同的解压工具

## 13. 性能考虑

- **内存使用**：处理大量文件或大文件时，可能会使用较多内存
- **处理速度**：文件数量越多、文件越大，处理时间越长
- **输出文件大小**：输出文件大小等于PNG模板大小加上所有文件的压缩大小

## 14. 扩展建议

- **添加压缩级别选项**：允许用户指定ZIP压缩级别
- **添加文件过滤选项**：允许用户指定包含或排除的文件模式
- **添加目录指定选项**：允许用户指定要打包的目录，而不是默认使用当前目录
- **添加密码保护选项**：为生成的ZIP文件添加密码保护
