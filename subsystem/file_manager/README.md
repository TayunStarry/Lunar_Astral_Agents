# 子系统——文件管理（file_manager）

> 📚 代码级文档参见 [Code Wiki 04·公共子系统](../../docs/code-wiki/04-公共子系统.md)，入口 [Code Wiki 门户](../../docs/code-wiki/README.md)。

本地文件存储、SQLite 知识库、向量记忆库与扩展包管理模块。

---

## 功能概述

`file_manager` 子系统提供完整的本地文件与数据管理能力，采用 Module（逻辑层）+ Server（HTTP 层）二层架构。

| 功能 | 说明 | 适用场景 |
|------|------|----------|
| 文件管理 | 文件保存 / 读取 / 删除 / 下载 / 列表 / 预览（图片/视频/文本），支持覆盖控制 | 本地资源的增删查改与上传下载 |
| ZIP 归档 | 多文件压缩 / 解压 / 目录打包 | 批量打包与解包 |
| 随机背景图 | 从图片目录随机选取背景图片 | 动态背景展示 |
| 文件整理 | 按文件类型自动分类整理目录，自动检查路径安全 | 批量文件归类 |
| SQLite 知识库 | 批量增删改查 / 建表删表 / 统计，支持事务与安全过滤 | 结构化数据的通用读写 |
| 向量记忆库 | 集合管理、消息/图片语义存储与查询、标签重建 | 自然语言内容的语义检索与记忆 |
| 扩展包管理 | 扩展包安装 / 导出 / 删除（`local_data/package/`） | 前端功能扩展资源的统一管理 |

所有文件操作统一受限在 `LocalDir`（默认 `local_data/`）根目录内，并对请求路径做规范化与越权校验，防止路径穿越与越权访问。

---

## 运行与使用方式

`file_manager` 作为一个库集成到宿主程序（星图·月华、星图·琉璃）中，HTTP 路由由宿主程序注册。文件保存、读取、知识库/记忆库操作通过对应 HTTP 端点调用，完整端点表与请求/响应格式见 [Code Wiki 04 §4.3](../../docs/code-wiki/04-公共子系统.md)，此处不重复。

## 常见问题

### Q: 文件保存在哪里？

所有文件保存在配置子系统指定的 `LocalDir` 目录下（默认 `local_data/`），上传文件通过请求头指定相对于该目录的路径。

### Q: 知识库和记忆库有什么区别？

- **知识库**（KnowledgeDB）：普通 SQLite 数据库，适合结构化数据（表/行/列）的批量增删改查。
- **记忆库**（MemoryDB）：基于嵌入向量的语义记忆存储，适合自然语言消息的语义检索，支持图片记忆与集合管理。

### Q: 事务失败会自动回滚吗？

是的。若启用事务，所有操作在单个事务内执行，任一操作失败会立即回滚，先前已成功的操作也会被撤销。
