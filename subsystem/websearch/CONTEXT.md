# 搜索模块 - 领域术语

> 本文档定义搜索模块中的核心概念，不含实现细节。

## 搜索模式

| 术语 | 英文 | 定义 |
|------|------|------|
| 轻量摘要 | Simple Search | 多引擎回退搜索，只返回标题+摘要，不抓取正文。最快最轻 |
| 网页搜索 | Webpage Search | 搜索+抓取正文+相关性过滤+LLM总结。常规模式 |
| 深度搜索 | Depth Search | 子问题拆解+并行搜索+研究校验+综合报告。最深入 |

## 深度搜索内部概念

| 术语 | 英文 | 定义 |
|------|------|------|
| 子问题拆解 | Query Decomposition | LLM 将用户问题拆分为 2-4 个互补的子问题，便于并行搜索 |
| 研究校验 | Gap Check | LLM 检查已收集的信息是否足以回答用户问题，不足则触发补充搜索 |
| 补充搜索 | Supplementary Search | 研究校验发现信息缺口后，针对缺口执行的新搜索 |
| 查询降级 | Query Degradation | 完整查询无结果时，逐步简化查询词（去掉时间限定→只保留核心实体→最简关键词） |
| 相关性过滤 | Relevance Filtering | 关键词匹配判断搜索结果是否与查询相关，官方网站跳过严格过滤 |

## 搜索知识库

| 术语 | 英文 | 定义 |
|------|------|------|
| 搜索知识库 | Search Knowledge Base | 独立 SQLite 数据库（data/search_knowledge.db），永久存储所有搜索结果，只写不改不删 |
| 新鲜度校验 | Freshness Check | 双级 LLM 语义判断：查询级（这个查询是否仍有效）+ URL 级（这个网页内容是否仍有效） |
| 结果命中 | Cache Hit | 查询在知识库中有匹配结果 |
| 来源类型 | Source Type | 对搜索结果的分类标记（官方/百科/社区/第三方/未知） |

## 搜索引擎

| 术语 | 英文 | 定义 |
|------|------|------|
| 搜索引擎回退 | Engine Fallback | 主引擎失败时按优先级依次尝试备用引擎：Bing → 百度 → 搜狗 → DuckDuckGo |
| SPA 渲染 | SPA Rendering | 对单页应用（如 Vue/React 站点）使用无头浏览器提取 JS 动态内容 |
| 官方网站优先 | Official Site Priority | 搜索引擎标记为官网的结果跳过严格相关性过滤，优先保留 |

## 输出

| 术语 | 英文 | 定义 |
|------|------|------|
| 结构化搜索结果 | Structured Search Result | 包含标题、URL、来源类型、发布时间、正文的格式化输出，供 Agent 消费 |
| 综合报告 | Synthesis Report | 深度搜索的最终输出，LLM 基于所有搜索结果生成的结构化报告 |
