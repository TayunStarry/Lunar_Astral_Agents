# project_archiving 项目开发文档

## 1. 项目概述

`project_archiving` 是一个基于 Go 1.24.4 开发的文件打包工具，专门用于将项目文件按照预设的打包计划进行分卷压缩。该工具核心依赖外部 7-Zip 命令行工具实现压缩功能，通过配置文件管理多种打包策略，支持灵活的分卷大小和压缩级别设置。

**项目结构：**
```
project_archiving/
├── main.go                          # 程序入口
├── build.ps1                        # PowerShell 构建脚本
├── go.mod                           # Go 模块定义
├── icon.ico / icon.syso             # Windows 图标资源
├── local_data/
│   └── lunar_config.json            # 打包配置文件
└── component/
    ├── config.go                    # 配置结构体与全局参数
    ├── config_loader.go             # 配置文件加载与处理
    ├── source.go                    # 源文件获取逻辑
    ├── execute.go                   # 主流程执行控制
    ├── create.go                    # 压缩与分卷创建
    ├── clean.go                     # 旧分卷清理
    ├── check.go                     # 工具函数（7z 路径查找、文件存在性检查）
    ├── progress.go                  # 压缩进度显示
    └── utils.go                     # 辅助工具函数
```

## 3. 文件读取实现方式与技术细节

### 3.1 文件扫描流程

文件扫描由 [create.go](file:///d:/Lunar_Astral_Agents/subsystem/project_archiving/component/create.go) 中的 `createVolume` 函数协调，整体流程如下：

```
1. 接收源文件/目录列表
2. 转换为绝对路径并验证存在性
3. 确定基准目录（第一个源的父目录）
4. 对目录进行递归扫描，对单个文件直接处理
5. 应用排除规则过滤
6. 计算相对路径
7. 生成临时文件列表
```

### 3.2 目录递归扫描

**扫描实现（[create.go](file:///d:/Lunar_Astral_Agents/subsystem/project_archiving/component/create.go#L18-L53)）：**

```go
func scanDirectory(dir string, baseDir string) ([]string, error) {
    var files []string
    entries, err := os.ReadDir(dir)
    if err != nil {
        return nil, err
    }
    for _, entry := range entries {
        fullPath := filepath.Join(dir, entry.Name())
        isDir := entry.IsDir()
        // 检查排除规则
        if IsExcluded(entry.Name(), isDir) {
            fmt.Printf("跳过排除项: %s\n", fullPath)
            continue
        }
        if isDir {
            // 递归扫描子目录
            subFiles, err := scanDirectory(fullPath, baseDir)
            if err != nil {
                fmt.Printf("WARNING: 无法扫描目录 %s: %v\n", fullPath, err)
                continue
            }
            files = append(files, subFiles...)
        } else {
            // 计算相对路径
            relPath, err := filepath.Rel(baseDir, fullPath)
            if err != nil {
                fmt.Printf("WARNING: 无法计算相对路径 %s: %v\n", fullPath, err)
                continue
            }
            files = append(files, relPath)
        }
    }
    return files, nil
}
```

**技术要点：**
- 使用 `os.ReadDir` 读取目录条目（Go 1.16+ 高效 API）
- 递归遍历所有子目录
- 使用 `filepath.Rel` 计算相对于基准目录的路径
- 错误处理采用"警告并继续"策略，不会因单个目录扫描失败而中断

### 3.3 排除规则匹配

**匹配实现（[config_loader.go](file:///d:/Lunar_Astral_Agents/subsystem/project_archiving/component/config_loader.go#L170-L191)）：**

```go
func IsExcluded(name string, isDir bool) bool {
    patterns := GetExcludePatterns()
    for _, pattern := range patterns {
        isDirPattern := strings.HasSuffix(pattern, "/")
        patternWithoutSlash := strings.TrimSuffix(pattern, "/")
        if isDir && isDirPattern {
            if matched, _ := filepath.Match(patternWithoutSlash, name); matched {
                return true
            }
        } else if !isDir && !isDirPattern {
            if matched, _ := filepath.Match(patternWithoutSlash, name); matched {
                return true
            }
        } else if !isDirPattern {
            if matched, _ := filepath.Match(patternWithoutSlash, name); matched {
                return true
            }
        }
    }
    return false
}
```

**匹配逻辑：**
- 使用 `filepath.Match` 进行通配符匹配（支持 `*` 和 `?`）
- 目录模式（以 `/` 结尾）只匹配目录
- 文件模式（不以 `/` 结尾）匹配文件和目录
- 匹配的是文件名/目录名，不是完整路径

### 3.4 文件列表生成

为避免 Windows 命令行参数长度限制，项目使用临时文件列表方式：

```go
listFile := filepath.Join(os.TempDir(), "7z_file_list.txt")
```

**技术细节：**

## 4. 文件压缩规则与算法

### 4.1 压缩引擎

项目使用 **7-Zip** 作为压缩引擎，通过 `exec.Command` 调用 7z 命令行工具：

**7z 路径查找（[check.go](file:///d:/Lunar_Astral_Agents/subsystem/project_archiving/component/check.go#L13-L37)）：**

```go
func find7zPath() (string, error) {
    paths := GetSevenZipPaths()
    for _, path := range paths {
        if fileExists(path) {
            return path, nil
        }
    }
    cmd := exec.Command("where", "7z")
    output, err := cmd.Output()
    if err == nil {
        path := strings.TrimSpace(strings.Split(string(output), "\n")[0])
        if path != "" {
            return path, nil
        }
    }
    return "", fmt.Errorf("未找到7z命令行工具")
}
```

**查找策略：**
1. 首先检查配置文件中的 `sevenzip_paths`
2. 若未找到，使用 Windows `where` 命令在 PATH 中查找
3. 默认路径包括：
   - `./local_data/package/archive/7z.exe`（项目自带）
   - `C:/Program Files/7-Zip/7z.exe`
   - `C:/Program Files (x86)/7-Zip/7z.exe`

### 4.2 压缩命令构建

**命令参数（[create.go](file:///d:/Lunar_Astral_Agents/subsystem/project_archiving/component/create.go#L134-L144)）：**

```go
cmdArgs := []string{
    "a",                       // 添加到压缩包
    fmt.Sprintf("-v%dm", partSizeMB),  // 分卷大小
    fmt.Sprintf("-mx=%d", compressionLevel), // 压缩级别
    "-mmt",                    // 多线程压缩
    "-bb1",                    // 基础日志级别
    "-bso1",                   // 标准输出
    "-bsp1",                   // 进度输出
    out7z,                     // 输出文件
    "@" + listFile,            // 文件列表
}
```

**参数详解：**

| 参数 | 说明 | 示例 |
|-----|------|------|
| `a` | 添加到压缩包（add） | - |
| `-v{size}m` | 分卷大小（MB） | `-v2048m` |
| `-mx={level}` | 压缩级别（0-9） | `-mx=5` |
| `-mmt` | 启用多线程压缩 | - |
| `-bb1` | 日志级别 1（基本输出） | - |
| `-bso1` | 标准输出流启用 | - |
| `-bsp1` | 进度输出流启用 | - |

### 4.3 压缩级别详解

| 级别 | 含义 | 压缩方式 | 适用场景 |
|-----|------|---------|---------|
| **0** | 不压缩（仅存储） | Copy | 已压缩文件（如视频、图片） |
| **1** | 最快 | Fastest | 对速度要求高的场景 |
| **2-3** | 快速 | Fast | 平衡速度与压缩率 |
| **4-6** | 正常 | Normal | **默认级别 5**，适合大多数场景 |
| **7-8** | 最大 | Maximum | 对压缩率要求高的场景 |
| **9** | 极限 | Ultra | 固实压缩，最高压缩率但耗时最长 |

**默认配置：级别 5**（正常压缩），在速度和压缩率之间取得平衡。

### 4.4 压缩格式

- **格式：** 7z（7-Zip 原生格式）
- **算法：** LZMA2（7z 默认压缩算法）
- **特点：**
  - 高压缩比
  - 支持固实压缩（Solid Compression）
  - 支持多线程压缩
  - 支持分卷压缩

## 5. 压缩后文件特征

### 5.1 文件格式

**输出格式：** `.7z` 分卷压缩包

**命名规范：**
```
{OutputPath}.7z.001
{OutputPath}.7z.002
{OutputPath}.7z.003
...
```

**示例：** 若 `OutputPath` 为 `Lunar-Astral-Agents`，则生成：
```
Lunar-Astral-Agents.7z.001
Lunar-Astral-Agents.7z.002
Lunar-Astral-Agents.7z.003
```

### 5.2 分卷大小

**默认大小：** 2048 MB（2 GB）

**配置方式：**
- 命令行参数：`-part_size_mb <大小>`
- 配置文件：`project_archiving.defaults.part_size_mb`

**实际大小特征：**
- 除最后一个分卷外，每个分卷大小精确等于指定的 MB 数
- 最后一个分卷大小取决于剩余数据量
- 分卷大小以 1 MB = 1,048,576 字节计算

### 5.3 文件大小估算

文件大小受以下因素影响：

| 因素 | 说明 |
|-----|------|
| **源文件总大小** | 原始文件大小的总和 |
| **压缩级别** | 级别越高，文件越小（通常） |
| **文件类型** | 文本文件压缩比高，二进制文件压缩比低 |
| **固实压缩** | 相似文件打包在一起时压缩率更高 |

**典型压缩比参考：**

| 文件类型 | 压缩比（级别 5） |
|---------|----------------|
| 文本文件（.txt, .json） | 60-80% |
| 代码文件（.js, .html） | 65-75% |
| 二进制文件（.exe, .dll） | 40-60% |
| 已压缩文件（.zip, .jpg） | 0-5% |

### 5.4 其他特征

- **工作目录：** 7z 命令在基准目录下执行，压缩包内使用相对路径
- **权限保留：** Windows 下不保留 Unix 风格权限
- **时间戳：** 保留文件原始修改时间
- **恢复记录：** 默认不包含恢复记录

## 6. 文件分卷策略

### 6.1 分卷机制

分卷由 7-Zip 的 `-v` 参数实现：

```go
fmt.Sprintf("-v%dm", partSizeMB)
```

**分卷规则：**
1. 第一个分卷包含前 `part_size_mb` MB 的压缩数据
2. 后续分卷依次填充，每个不超过指定大小
3. 最后一个分卷包含剩余数据
4. 分卷编号从 `.001` 开始，按三位数字递增

### 6.2 分卷大小限制

| 配置项 | 默认值 | 限制 |
|-------|--------|------|
| **最小值** | 无硬性限制 | 建议 >= 1 MB |
| **默认值** | 2048 MB | 适合大多数场景 |
| **最大值** | 受文件系统限制 | FAT32: 4GB, NTFS: 16TB |

**注意事项：**
- 若目标文件系统为 FAT32，分卷大小不能超过 4096 MB
- 分卷大小以 MB 为单位，内部转换为字节时乘以 1,048,576

### 6.3 分卷命名规范

**格式：** `{基础名称}.7z.{序号}`

**示例：**
```
Lunar-Astral-Agents.7z.001    <- 第一卷
Lunar-Astral-Agents.7z.002    <- 第二卷
Lunar-Astral-Agents.7z.003    <- 第三卷
```

**序号规则：**
- 三位数字，从 001 开始
- 超过 999 时自动扩展为更多位数

### 6.4 旧分卷清理机制

**清理逻辑（[clean.go](file:///d:/Lunar_Astral_Agents/subsystem/project_archiving/component/clean.go)）：**

```go
func cleanOldParts(outBase string) {
    dirName := filepath.Dir(outBase)
    baseName := filepath.Base(outBase)
    entries, err := os.ReadDir(dirName)
    for _, entry := range entries {
        if entry.IsDir() {
            continue
        }
        fname := entry.Name()
        fullPath := filepath.Join(dirName, fname)
        // 匹配并删除旧分卷
        if strings.HasPrefix(fname, baseName) && strings.Contains(fname, ".7z.") {
            os.Remove(fullPath)
        }
    }
    // 删除完整的 .7z 文件
    full7z := filepath.Join(dirName, baseName+".7z")
    if fileExists(full7z) {
        os.Remove(full7z)
    }
}
```

**清理规则：**
1. 匹配条件：文件名以 `baseName` 开头 **且** 包含 `.7z.`
2. 清理范围：所有匹配的分卷文件 + 完整的 `.7z` 文件
3. 执行时机：在创建新压缩包之前
4. 错误处理：删除失败时打印警告但不中断流程

```
  │     └─ 输入: @文件列表
  │
  ├─ 5. 执行命令
  │     ├─ 启动 7z 进程
  │     ├─ 实时读取 stdout/stderr
  │     ├─ 解析进度百分比
  │     ├─ 显示彩色进度条
  │     └─ 等待进程完成
  │
  └─ 6. 清理
        └─ 删除临时文件列表 (defer)
```

### 8.1 配置文件结构

```json
{
  "project_archiving": {

    "plan-2": ["路径1", "路径3"],

      "compression_level": 压缩级别,
      "package_plan": "默认打包计划"
    }
  }
```

### 8.2 命令行参数

| 参数 | 类型 | 默认值 | 说明 |
|-----|------|--------|------|
| `-config` | string | `local_data/lunar_config.json` | 配置文件路径 |

| `-part_size_mb` | int | `2048` | 分卷大小（MB） |
| `-compression_level` | int | `5` | 压缩级别（0-9） |

| `-system_dev_mode` | bool | `false` | 调试模式 |

### 8.3 使用示例

**基本使用：**
```bash
# 使用默认配置
project_archiving.exe

project_archiving.exe -output_path "backup" -part_size_mb 1024

# 使用不压缩模式
project_archiving.exe -compression_level 0 -part_size_mb 4096

# 使用 plan-1 打包
project_archiving.exe -package_plan "plan-1"
```

```powershell
# 默认构建（Windows amd64）
```

| `TargetArch` | amd64, arm64 | amd64 | 目标 CPU 架构 |
| `SkipCheck` | switch | false | 跳过环境检查 |

```powershell
$env:GOOS = $TargetOS
$env:GOARCH = $TargetArch
```

构建产物输出到 `../../project_archiving.exe`（项目根目录）。

## 10. 技术要点总结

| 模块 | 技术选型 | 说明 |
|-----|---------|------|
| **配置管理** | JSON + flag | 支持配置文件和命令行参数，命令行优先 |
| **文件扫描** | os.ReadDir + 递归 | 高效目录遍历，支持排除规则 |
| **压缩引擎** | 7-Zip CLI | 外部进程调用，支持分卷和多线程 |
| **进度显示** | 正则解析 + ANSI 颜色 | 实时解析 7z 输出，彩色进度条 |
| **路径处理** | filepath 包 | 跨平台路径操作，相对路径计算 |
| **临时文件** | os.TempDir | 系统临时目录，自动清理 |
| **错误处理** | 警告继续 / 致命退出 | 扫描失败警告，关键失败退出 |

## 11. 注意事项

1. **7-Zip 依赖：** 必须安装 7-Zip 或在项目路径下提供 7z.exe
2. **路径前缀：** 配置文件中的路径相对于项目根目录，需注意 `../../` 前缀
3. **分卷完整性：** 解压时需要所有分卷文件在同一目录
4. **文件大小：** 目标文件系统需支持分卷大小（FAT32 限制 4GB）
5. **编码问题：** 文件名使用系统默认编码，非 UTF-8 系统可能有问题
6. **权限要求：** 需要临时目录写入权限和目标目录写入权限
7. **Go 版本：** 需要 Go 1.24.4 或更高版本
