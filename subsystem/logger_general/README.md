# 子系统——彩色终端日志（logger_general）

> 📚 代码级文档参见 [Code Wiki 04·公共子系统](../../docs/code-wiki/04-公共子系统.md)，入口 [Code Wiki 门户](../../docs/code-wiki/README.md)。

轻量级彩色终端日志输出模块，为所有子系统提供统一的日志输出规范。

---

## 功能概述

`logger_general` 是平台的**基础设施层**，为各子系统提供统一、一致的彩色终端日志输出。

| 特性 | 说明 |
|------|------|
| 分级日志 | Info / Warn / Error / Fatal 四级输出 |
| ANSI 彩色 | 不同级别使用不同颜色，终端可读性高 |
| 开发模式 | Info 级别仅在开发模式下输出，生产环境零噪音 |
| 子模块支持 | 每条日志标注模块名 + 子模块名，快速定位来源 |
| 零外部依赖 | 仅采用 Go 标准库 |

### 日志级别与颜色

| 级别 | 颜色 | 输出条件 | 说明 |
|------|------|---------|------|
| **Info** | 青色 | 仅开发模式 | 调试信息，生产环境自动静默 |
| **Warn** | 黄色 | 始终输出 | 警告信息，非致命异常 |
| **Error** | 红色 | 始终输出 | 错误信息，需要关注 |
| **Fatal** | 粗体红 | 始终输出 | 致命错误，输出后终止进程 |

---

## 运行与使用方式

`logger_general` 作为库被各子系统引用。开发模式下开放 Info 级别输出，关闭开发模式则仅控制台输出 Warn/Error/Fatal。开发模式开关通常在程序入口处由配置子系统统一设置。各日志函数的调用与参数说明见 [Code Wiki 04 §4.5](../../docs/code-wiki/04-公共子系统.md)，此处不重复。

## 常见问题

### Q: 为什么 Info 日志没有输出？

Info 级别仅在开发模式下输出。请确认已开启开发模式；在星月智能平台中，该开关由 [general_config 子系统](../general_config/README.md) 的开发者模式标志控制。

### Q: 日志颜色在 Windows 终端中不显示？

Windows 10+ 的 Windows Terminal 和 PowerShell 7+ 默认支持 ANSI 颜色。如使用旧版 cmd.exe，可能需要启用 ANSI 转义序列支持。

### Q: Fatal 日志输出后程序会退出吗？

是的。Fatal 会终止进程；如需记录错误但不退出，请使用 Error 级别。
