# 知识库查询接口

**功能**：根据查询向量和知识库文件路径，返回基于相关性排序的结果，最多返回topK个结果

**请求方式**: POST
**路径**: `/knowledge/query`

## 请求参数

| 参数名       | 类型    | 必填 | 说明                                                |
| ------------ | ------- | ---- | --------------------------------------------------- |
| `filePath`   | string  | 是   | 知识库文件路径，相对于 local_data 目录              |
| `queryVector`| array   | 是   | 浮点数数组，长度为256                               |
| `topK`       | integer | 否   | 返回结果数量，默认为15                              |

## 请求体示例

```json
{
  "filePath": "knowledge/example.json",
  "queryVector": [0.1, 0.2, ..., 0.5],
  "topK": 15
}
```

## 响应示例 (200 OK)

```json
[
  {
    "role": "system",
    "content": "这是一个相关的知识库条目",
    "imageUrl": "",
    "uuid": "uuid-2025.12.31-23:59:59"
  },
  {
    "role": "system",
    "content": "这是另一个相关的知识库条目",
    "imageUrl": "",
    "uuid": "uuid-2025.12.31-23:59:58"
  }
]
```

## 错误响应

| 状态码 | 说明                   |
| ------ | ---------------------- |
| `400`  | 请求参数错误           |
| `403`  | 访问被拒绝             |
| `500`  | 服务器内部错误         |

```json
{
  "error": {
    "code": 400,
    "message": "KnowledgeQuery请求[ERROR] -> 缺少文件路径"
  }
}
```

## 处理流程

1. 验证请求参数，确保filePath和queryVector有效
2. 检查文件路径安全性，防止路径遍历攻击
3. 尝试打开知识库文件
4. 如果文件不存在，初始化新的知识库文件
5. 读取文件中的HistoryDocument结构
6. 对每个文档计算与查询向量的余弦相似度
7. 跳过没有嵌入向量的消息
8. 根据相似度降序排序，返回topK个KnowledgeMessage

## 注意事项

- 如果知识库文件不存在，会自动初始化文件并返回空数组 `[]`
- 查询向量必须为256维浮点数数组
- filePath参数必须相对于local_data目录，不允许访问外部文件
- 返回结果中不包含权重信息，只包含纯KnowledgeMessage数组
